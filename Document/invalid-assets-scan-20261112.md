## 6. 遗留问题

### 6.1 `.pytest_cache` 无法删除（需管理员）

```text
icacls .pytest_cache  → Access is denied. (exit 5)
```

当前会话非管理员，`takeown` / `icacls /reset` / `Remove-Item` 均被拒；仓库内 `.dsh-acl-recovery/` 的既有记录显示前次 ACL 修复同样被 refused（`writeDac=false`）。该目录内容为 0 字节，不占空间。

提权后清理：

```powershell
takeown /f "D:\WorkShop\Touhou_RL\.pytest_cache" /r /d y
icacls "D:\WorkShop\Touhou_RL\.pytest_cache" /grant "$env:USERNAME:(F)" /t
Remove-Item -LiteralPath "D:\WorkShop\Touhou_RL\.pytest_cache" -Recurse -Force
```

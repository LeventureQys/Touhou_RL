# 2026-11-02 v3.7.3：方向信息在不在像素里（round27）

上一段（P0 栅栏重判）解决的是"真机数据能不能证明同帧"。这一段换到合成学习线，回答 [synthesis-round25](../Update/Alpha/v3.7.3/reports/synthesis-round25.md) 里悬着的那个问题：**R21 把缺口画出来了，训练反而更差，是画得不够，还是策略不用？**

## 1. 为什么这个问题值得单开一轮

R20 的结论是"F1 的缺口在致命前从未渲染"，R21 因此加了一条预告带，结果 F1 留出从 3/3/3 掉到 2/2/2。此后 R22–R25 依次排除了空间通道、辅助任务、数据规模，最后把结论写成"卡在镜像方向"。

但"卡在镜像方向"有两种完全不同的病因：

- **信息不在**（任务构造坏了）：那再怎么调网络都是浪费，应该先修任务；
- **信息在、策略不用**（目标/读出问题）：那应该改目标或读出，不是加预告。

这两条路后面的工作完全不同，所以值得单独测。判据先写死：一个**不需要学习的直读器**（能不能从像素直接读出方向）、一个**小 CNN**（能不能学）、以及**无预告对照**（证明读的是预告带）。

## 2. 测法：让"读取"和"学习"分开

- 直读器：取 playfield，按预告带颜色 `(44,58,74)` 与缺口边缘色 `(96,148,128)` 找缺口两缘，按青色 `(90,225,255)` 找自机列，比较二者位置。它不读 world、不读标签，纯像素。
- 小 CNN：输入下采样到 96×112 的 playfield，标签是 `sign(gap_center − player_x)`；**只训练 base 世界，测试镜像世界**——这正是策略失败的迁移。
- 数据：480 个生成世界（240 组 × base/mirror）+ R18 的 12 个有效世界（不参与训练）。
- 两条自证：①"仅用自机位置"的逻辑回归必须接近随机（否则数据集有捷径）；②把预告带颜色替换成背景后直读器必须全部读不出（否则读的不是预告带）。

## 3. 三次执行，两次被自己的控制项打回

**第一次（27）**：直读器 12/12 + 120/120 全对——信息显然在。但自证①拿到 **0.80**：我生成世界时写的是 `start = gap ∓ offset`，自机位置因此与标签相关。这正是 R24 记录过的"98.5% 可解码＝玩家 x>192"陷阱，数据集作废。

**第二次（27b）**：改成独立采样 + `|gap−start| ≥ 30` 过滤。自证①仍然 **0.83**——过滤器本身在屏幕边缘制造了"某个标签不可能"，相关性没除掉。作废。

**第三次（27b 重跑）**：把自机限制在 `x ∈ [110,274]`（任何 x 两个标签都可行），自证①终于 0.492。但训练日志里出现 **负损失**（−283,965）——我把 ±1 标签直接喂给了 `BCEWithLogits`（它要 0/1）。网络根本没在训练，于是"没学到"这个结论是假的。修标签 + 加断言后重跑。

**第四次（27d，正式）**：所有数字来自这一次。

这一段最值得记的不是最终数字，而是：**两次失败都是预注册里那两条"自证项"和我自己加的损失断言抓住的**。如果没有位置基线和遮挡控制，"信息在"这个结论可能被一个脏数据集支持，而"学不到"可能被一个坏损失函数支持，两者都会写进结论。

## 4. 结果

| 测量 | 结果 |
|---|---|
| 直读器（无学习） | R18 有效世界 **12/12**、生成世界 **480/480**；无预告 0/492；遮挡后 0/492 |
| CNN 只训 base → 测镜像 | 0.854 / 0.854 / 0.871（均值 0.860，门槛 0.90，**未过**） |
| CNN 两个朝向都训练 → 按组留出 | **0.896 / 0.906 / 0.917** |
| 线性层直接读像素 → 测镜像 | 0.808 |
| 12 个有效世界留出 | 0.50（自机在 x=56/328，训练分布外 → 外推失败） |
| 训练集拟合 | 0.933–0.938 |

读法：

1. **"信息没画出来"不成立。** 预告渲染上的方向信息清楚到一个二十行函数就能读，492/492。
2. **关系是可学的**，只要训练分布里两个朝向都出现：混合朝向时按组留出 0.90 左右，连线性层都能到 0.81。
3. **严格两关没过**，但失败原因是分布：只训 base 时模型部分依赖绝对位置（0.86）；边缘位置的留出世界（x=56/328）完全在训练分布外（0.50）。这不是"读不出"，同一批世界直读器 12/12。

## 5. 这条结果改变了什么

- **停止"再加预告"**：预告已经足够。R21 的负结果不能用"预告不够"解释，再加帧只会重复 R21。
- **下一个单因子改成"关系型读出/目标"**：把"缺口相对自机"显式化（例如直接回归 `gap_center − player_x`，而不是分类"屏幕左/右"），并且训练分布必须同时覆盖两个朝向与边缘位置。
- **真机路径不变**：round27 是合成渲染，不产生可部署权重，也不改变 P0/P3 的门。

## 6. 还没做的

- 无特权教师（把 V2 的 `s.gap` 遮住）还没测——那是 P3 真实数据有没有合法标签源的前置门。
- `frame_proof=exact` 的预注册与 `capture_dataset.py` 接入还没做。
- 本轮的 CNN 不是策略：它只说明"这份像素上关系可学"，不说明 v3-st+GRU 能学到、更不说明闭环里会用。

## 7. 一句话

**方向信息一直在像素里，缺的是"要求模型去比较"的目标。** 这比"镜像盲"更具体，也更容易被执行：改读出/改目标，而不是继续加渲染。

## 8. 第二步：谁能在真实会话里产出标签（round28）

round27 只证明了"合成渲染里有方向信息"，但 P3 要的是**真实会话能产出的标签**。所以紧接着测了一个更硬的问题：把教师手里的世界参数拿掉，还有哪个族能工作？

方法是三种运行：baseline（复现 R19 的 14/28 与 28/28）、masked（教师模块读特权字段就抛错，世界自身动力学照常转发）、corrupted（教师相信一套错参数，世界按真的走）。

结果很干净：

| | F1 | F2 | F3 |
|---|---|---|---|
| V2 baseline | 12/12 | 4/4 | 12/12 |
| V2 参数喂错 | **0/12** | 4/4 | **0/12** |
| 旧教师 baseline | 0/12 | 4/4 | 10/12 |
| 旧教师 参数喂错 | 0/12 | 4/4 | 10/12 |

- V2 的 28/28 里，**24 例靠的是被告知世界参数**（`coverage`/`window`），参数一错就全灭；
- F1 的墙/缺口在原始渲染里致命前根本不出现（R20），只有研究预告带能看到（R21）——所以 F1 的**渲染和标签都是研究专用的**；
- F3 的耗尽窗口在真机没有对应对象；旧教师虽然不读参数，但 `34..104`、`cx>128` 是为这一族写死的时刻表，换窗口就错 2 例。state-only 不等于可迁移；
- **只有 F2 两种模式都 4/4**，而 F2 只有 4 例（2 组）。

这条结论改变了 P3 的范围：真实像素数据按当前课程只能建在 F2 上，要么把 F2/F5 这类"对象可观测"的课程扩到可用规模，要么明确收窄 P3 并说清楚不覆盖六族。把 F1/F3 的教师轨迹当真机标签，等于把世界参数偷偷带进监督。

下一步就是目标里的第 ③ 步：`frame_proof=exact` 的预注册与 `capture_dataset` 接入方案——它决定"F2 类标签能不能在真机上真的采下来"。

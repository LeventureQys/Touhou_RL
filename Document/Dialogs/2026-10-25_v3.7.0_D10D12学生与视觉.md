# 2026-10-25 v3.7.0 D10–D12：学生与视觉骨架

## 1. 边界

D11（视觉前端）需要真机画面。本轮做的是**合成光栅 + 小 CNN + 按场景划分评估**，把“图像→动作”的路径打通，并明确标注未接触真机像素。

## 2. 交付

- `vision.py`：`render_state` 把危险盒（1.0）与自机（0.5）画进 96×112 灰度图。
- `student.py`：`collect_teacher`（控制器跑场景 → 图像/动作对）、`StudentNet`（两层卷积 + 线性头，18 类）、`train_and_evaluate`、`closed_loop_student`。
- CLI `student`。
- 测试：`test_escape_vision.py`（5 项）。

## 3. 第一版评估是错的，保留记录

第一版按**样本**随机划分，测试一致率 0.667。同场景相邻帧几乎相同，这种划分把答案泄进测试集。

改为按**场景**划分（11 训练 / 3 测试）后：

| 指标 | 值 |
|---|---:|
| 样本 | 404（274 / 130） |
| 训练损失 | 2.20 → 0.61 |
| 训练一致率 | 0.770 |
| **测试一致率** | **0.777** |
| 随机基线 | 0.056 |

数字反而更高：说明第一版的 0.667 主要是划分噪声，不是过拟合信号。这条留在报告里，提醒“先看划分再看数字”。

## 4. 混淆与闭环

混淆集中在 `17→8`（idle+focus 被认成右上，各 13 次）与 `4↔8` 相邻方向，符合“单帧缺速度信息”的预期。

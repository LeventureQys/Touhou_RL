## 1. 背景与目标（无需任何对话历史）

这是视觉学生 v1.0.3 的评估口径与数据切分层。当前有两个必须修的缺陷（已由用户裁决）：

1. **弹量指标取错通道**：`touhou_rl/vision_train.py:158` 用 `predicted[:, 13]`，但按 `touhou_rl/obs.py:136-157` 的 24 维布局，索引 13 是 `stage_clear_flag`（实测在全部 72,472 帧上恒为 1.0 的死通道），索引 14 才是 `min(1, active_count/700)`。所以历史报告里的「子弹数误差 15.1 颗」是伪指标。
2. **danger 相关只有一个口径**：`touhou_rl/vision_train.py:167-180` 把（帧×128 格）展平后算一次 Pearson。实测「只给每帧总弹量」的平凡预测器就能拿到 0.557，因此该口径不能作为 A-01 的主判据。需要新增 **per-frame corr**（逐帧 128 格 Pearson）。

同时，R3 数据曲线需要在**同一验证集**上比较 25%/50%/100% 三档训练数据，因此需要分层、可嵌套的训练集子采样。

**你的目标**：把上面三件事做成独立、可单测的模块。你**不**需要改训练脚本（S3-3 会调用你的函数）。

## 4. 实现契约（跨 SubStage 契约 C2，签名与返回值不得改动）

### 4.1 `touhou_rl/vision_metrics.py`（纯 numpy，**不得 import torch**）

```python
from __future__ import annotations
import numpy as np

BUCKETS = ((0.0, 15.0), (15.0, 30.0), (30.0, 60.0), (60.0, 120.0), (120.0, float("inf")))
BUSY_THRESHOLD = 0.2
DANGER_SCALE = 8.0
```

#### `player_position_mae_px(pred, truth) -> tuple[float, float]`

- `pred`, `truth`: `[N, 24]` float（归一化的 `self_feat`）。
- 单帧误差（**必须与 v1 的 `val_player_pos_px` 同口径**，否则 70.97 不可比）：
  `err_i = (|pred[i,0]-truth[i,0]| * 384.0 + |pred[i,1]-truth[i,1]| * 448.0) / 2.0`
- 返回 `(float(err.mean()), float(np.percentile(err, 95)))`，保留 4 位小数。
- `N == 0` → 返回 `(0.0, 0.0)`。

#### `danger_metrics(pred_log, truth) -> dict`

- `pred_log`: `[N, 128]` 或 `[N, 16, 8]`（内部先 `reshape(N, -1)`）；`truth`: `[N, 16, 8]` uint8 计数。
- 目标：`tgt = log1p(truth / 8.0)`，展平为 `[N, 128]`。
- 返回键（**全部必须有**）：

| 键 | 定义 |
| --- | --- |
| `danger_corr` | `pred.ravel()` 与 `tgt.ravel()` 的一次 Pearson（v1 口径）。任一侧方差为 0 → `0.0` |
| `danger_corr_perframe_mean` | 逐帧 Pearson 的均值；无效帧（任一侧 128 格为常量或 NaN）不计入；全无效 → `0.0` |
| `danger_corr_perframe_median` | 同上取中位数；全无效 → `0.0` |
| `danger_corr_perframe_valid` | 参与统计的帧数（int） |
| `danger_iou` | busy 二值化后的 IoU：`busy = tgt > 0.2`，`busy_pred = pred > 0.2`；`|P∩T| / |P∪T|`，逐帧算再对**并集非空的帧**取均值；全空 → `0.0` |
| `danger_cell_acc` | `(busy == busy_pred)` 的全格平均（v1 口径，保留可比） |
| `danger_mae_log` | `|pred - tgt|` 的全格平均 |

- 所有浮点值保留 4 位小数；`NaN` 不得出现在返回值里（必须是 `0.0` 或有效数）。
- `N == 0` → 所有浮点键 `0.0`、`danger_corr_perframe_valid` 为 `0`。

#### `bullet_count_mae(pred, truth) -> float`

- `|pred[:,14] - truth[:,14]|.mean() * 700.0`，保留 1 位小数。**索引必须是 14，不是 13。**
- `N == 0` → `0.0`。

#### `ray_mae(pred, truth) -> float`

- `|pred[:,16:24] - truth[:,16:24]|.mean()`，保留 4 位小数。

#### `self_mae(pred, truth) -> float`

- `|pred - truth|` 全部 24 维的平均，保留 4 位小数。

#### `policy_metrics(pred, teacher, bullets) -> dict`

- `pred`: `[N,18]` 模型输出；`teacher`: `[N,18]` px 单位真值；`bullets`: `[N,64,6]`（`float16` 或 `float32`）。
- 最近弹距离：`dx = bullets[:,:,0]*192.0`，`dy = bullets[:,:,1]*224.0`，`valid = bullets[:,:,5] > 0.5`，`dist = where(valid, sqrt(dx^2+dy^2), inf).min(axis=1)`。
- `chosen = pred.argmax(axis=1)`；`top1 = (chosen == teacher.argmax(axis=1))`；`regret = teacher.max(axis=1) - teacher[arange(N), chosen]`。
- 返回 `{"top1": float, "regret_px": float, "by_danger": [ {...}, ... ]}`，`by_danger` 按 `BUCKETS` 顺序，**空桶也要出现**：
  `{"bucket": "0-15"|"15-30"|"30-60"|"60-120"|"120+", "frames": int, "top1": float, "regret_px": float}`；空桶的 `top1`/`regret_px` 写 `0.0`。
- 桶标签生成：`f"{int(low)}-{int(high)}"`，上界 `inf` 时 `f"{int(low)}+"`。
- `top1` 保留 4 位，`regret_px` 保留 3 位（与 v1 一致）。

#### `heatmap_hit_rate(logits, truth) -> float`

- `logits`: `[N, 28, 24]`；`truth`: `[N, 24]`。
- 真值格：`gx = round(truth[:,0]*24 - 0.5)`，`gy = round(truth[:,1]*28 - 0.5)`（夹到 `[0,23]` / `[0,27]`）。
- 命中定义：argmax 格与真值格的行差 ≤ 1 **且** 列差 ≤ 1。返回命中比例，保留 4 位。

#### `all_state_metrics(pred_self, pred_danger_log, truth_self, truth_danger, *, heatmap_logits=None) -> dict`

聚合函数，返回 v1 同名键 + 新增键，**键名必须与 `../设计文档.md` §7.2 的 summary 字段一一对应**（去掉 `val_` 前缀）：

```
{"self_mae","player_pos_px","player_pos_p95_px","ray_mae","bullet_count_mae",
 "danger_mae_log","danger_corr","danger_corr_perframe_mean","danger_corr_perframe_median",
 "danger_corr_perframe_valid","danger_iou","danger_cell_acc"}  # heatmap_logits 非 None 时再加 "heatmap_hit_rate"
```

### 4.2 `touhou_rl/vision_split.py`

```python
def stratified_prefix(
    train_indices: Sequence[int],
    stage_of: np.ndarray,        # 长度 = 数据集总帧数，stage_of[i] = 第 i 帧的 stage
    fraction: float,
    seed: int = 7,
) -> list[int]:
```

规则（必须逐条实现）：

1. `fraction` 必须在 `(0, 1]`，否则 `ValueError(f"fraction must be in (0, 1], got {fraction}")`；
2. `fraction == 1.0` 时返回 `sorted(train_indices)`（集合必须与原训练集完全相同）；
3. 按 stage 升序分组（`stage_of[index]`）；每个 stage 内先把索引升序排序；
4. 对每个 stage 用**同一个** `np.random.default_rng(seed)` 依次做 `permutation`（**stage 顺序固定，保证同 seed 可复现**）；
5. 每个 stage 取前 `round(fraction * n_stage)` 个（`round` 用 Python 内置 `round`，`.5` 按银行家舍入；若结果 > `n_stage` 则夹到 `n_stage`）；
6. 拼接后 `sorted(...)` 返回 `list[int]`；
7. **嵌套性**：同 `seed` 下 `set(stratified_prefix(x, 0.25)) <= set(stratified_prefix(x, 0.5)) <= set(stratified_prefix(x, 1.0))` 必须成立（这是取"同一 permutation 的前缀"的直接结果，不得用独立采样破坏它）。

### 4.3 `VisionDataset.stage_of(indices) -> np.ndarray`

- 在 `touhou_rl/vision_data.py` 的 `VisionDataset` 上**新增**方法：

```python
def stage_of(self, indices: list[int] | np.ndarray) -> np.ndarray:
    """每个索引所属 stage（来自分片 meta 的第 2 列）。返回 int64 数组，形状同 indices。
    indices 是**数据集全局索引**（0..total-1）；stage_of[i] 即全局索引 i 的 stage，
    因此调用方若需要按索引查表，应传 range(total)。"""
```

- 实现要求：**只读 `meta`**（不得解码 PNG）；用 `_locate(index)` 定位分片后再读该分片的 `meta`；同一次调用内对同一分片最多读一次（用本地 dict 缓存）。
- 不得修改 `VisionDataset` 的任何现有方法签名或语义。

## 5. 必须写的单元测试（`touhou_rl/tests/test_vision_metrics.py`）

至少 12 条，全部纯 numpy、总时长 < 20 s：

1. `test_position_mae_matches_v1_formula`：构造 `pred`/`truth` 使 `Δx=0.01, Δy=0.02`，断言返回值 = `(0.01*384 + 0.02*448)/2`（`pytest.approx`）。
2. `test_position_mae_p95_and_empty`：`N=0` 返回 `(0.0, 0.0)`；常数误差输入下 p95 == mean。
3. `test_bullet_count_uses_index_14`：构造 `truth[:,13]=1.0`、`truth[:,14]=0.5`，`pred` 全 0；断言结果 = `0.5*700 = 350.0`（若误用索引 13 会得到 700.0，本测试就是防这个）。
4. `test_bullet_count_index13_is_ignored`：只改 `truth[:,13]`（1.0 → 0.0），结果必须不变。
5. `test_danger_corr_global_matches_numpy`：随机输入，与手算 `np.corrcoef` 比对（`rel=1e-6`）。
6. `test_danger_perframe_excludes_constant_frames`：其中 2 帧目标全 0（常量）→ `danger_corr_perframe_valid == N-2`，且 median 不为 NaN。
7. `test_danger_perframe_all_invalid_returns_zero`：所有帧都是常量 → 三个浮点键为 `0.0`，`valid == 0`。
8. `test_danger_iou_perfect_and_empty`：预测与目标完全一致 → IoU == 1.0；预测全 0、目标全 0 → `0.0`（并集为空不计入）。
9. `test_danger_metrics_accept_both_shapes`：`[N,128]` 与 `[N,16,8]` 输入结果完全相同。
10. `test_policy_metrics_bucket_labels_and_empty_buckets`：`bullets` 全 invalid（`[:,:,5]=0`）→ 只有 `120+` 桶有帧、其余 4 个桶 `frames=0` 且 `top1/regret_px` 为 `0.0`；桶标签字符串精确匹配 `["0-15","15-30","30-60","60-120","120+"]`。
11. `test_policy_metrics_regret_and_top1`：手算小例子（2 帧、18 候选）验证 `top1` 与 `regret_px`。
12. `test_heatmap_hit_rate_tolerance`：真值在 (14,12)，argmax 在 (15,13) 判命中、(16,12) 判未命中。
13. `test_stratified_prefix_is_nested`：构造 3 个 stage、每 stage 100 索引；断言 0.25 ⊂ 0.5 ⊂ 1.0（集合包含）且 `fraction=1.0` 等于输入集合。
14. `test_stratified_prefix_is_stratified`：3 个 stage 各 100，`fraction=0.5` 时每个 stage 恰好 50 个。
15. `test_stratified_prefix_rejects_bad_fraction`：`0.0`、`1.5`、`-0.1` 均抛 `ValueError`。
16. `test_stage_of_matches_meta`：用 `VisionShardWriter` 写 7 帧（`shard_size=3`，两帧不同 stage），`dataset.stage_of([0,4,6])` 与写入值一致，且不触发 PNG 解码（用 `monkeypatch` 替换 `vision.decode_png` 为抛异常的函数，断言不被调用）。

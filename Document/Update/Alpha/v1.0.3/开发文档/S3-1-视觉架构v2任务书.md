## 1. 背景与目标（无需任何对话历史）

项目要让 AI 只看游戏画面就会玩东方 Project（TH08）。当前视觉学生 v1 的自机位置误差是 **70.97 px**（目标 < 10 px）。原因在代码里是可见的：`touhou_rl/vmodels.py:112` 把所有分区的特征图统一 `adaptive_avg_pool2d((2,2))`，场地流只剩下 4 个空间格；`touhou_rl/vmodels.py:122-126` 再从 256 维全局向量直接回归坐标。

**你的目标**：新建 v2 架构——场地流保留空间分辨率、坐标用 heatmap + 加权期望、HUD 两路用独立编码器——同时**不破坏 v1**（旧 checkpoint 必须仍能加载，旧单测必须仍通过）。

你**不需要**跑训练。训练侧集成是 S3-3 的工作。

## 4. 实现契约

### 4.1 `VisionNetConfigV2`（`touhou_rl/vmodels2.py`，必须是 `@dataclass`）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `depth` | `1` | 帧堆叠深度，卷积输入通道 = `3*depth` |
| `playfield_hw` | `(224, 192)` | 场地流模型输入 (H, W) |
| `hud_score_hw` | `(34, 216)` | 比分 HUD 输入 (H, W) |
| `hud_status_hw` | `(126, 216)` | 状态 HUD 输入 (H, W) |
| `pf_width` | `32` | 场地流首层通道数 |
| `hud_width` | `16` | HUD 流首层通道数 |
| `trunk_hidden` | `256` | 融合后宽度 |
| `state_hidden` | `256` | self 头隐层宽度 |
| `candidate_hidden` | `64` | 候选嵌入宽度 |
| `heatmap_gauss_sigma` | `1.5` | 目标高斯 σ（单位为格） |
| `danger_rows` / `danger_cols` | `16` / `8` | danger 网格 |
| `state_head` | `True` | 关闭后 `decode_state` 抛 `RuntimeError` |

必须提供 property：

- `region_sizes -> dict[str, tuple[int,int]]` = `{"playfield": playfield_hw, "hud_score": hud_score_hw, "hud_status": hud_status_hw}`
- `region_names -> tuple[str, ...]` = 上面三个键，**顺序固定**
- `heatmap_hw -> tuple[int,int]` = `(playfield_hw[0]//8, playfield_hw[1]//8)`（默认 `(28, 24)`）

字段必须全部可被 `json.dumps` 序列化（tuple 会被转 list，加载时要转回 tuple）。

### 4.2 网络结构（逐层，必须按此形状实现）

```
playfield 分支（独立权重）
  Conv2d(3*depth → pf_width, k=5, s=2, p=2) + ReLU        -> (112, 96)
  Conv2d(pf_width → pf_width*2, k=3, s=2, p=1) + ReLU      -> (56, 48)
  Conv2d(pf_width*2 → pf_width*3, k=3, s=2, p=1) + ReLU    -> (28, 24)
  Conv2d(pf_width*3 → pf_width*3, k=3, s=1, p=1) + ReLU    -> (28, 24)
  ├ heatmap_head : Conv2d(pf_width*3 → 1, k=1)             -> conv 输出 [B,1,28,24]，对外 squeeze(1) 成 [B,28,24]
  ├ danger_head  : AdaptiveAvgPool2d((16,8)) + Conv2d(pf_width*3 → 1, k=1)
  │                                                        -> [B, 1, 16, 8]
  └ global_pool  : AdaptiveAvgPool2d((2,2)).flatten(1)     -> 4*pf_width*3 = 384
                   Linear(384 → 128) + ReLU                 -> [B, 128]

hud_score 分支（独立权重，hud_width=16）
  Conv2d(3*depth → 16, k=5, s=2, p=2)+ReLU   -> (17, 108)
  Conv2d(16 → 32, k=3, s=2, p=1)+ReLU        -> (9, 54)
  Conv2d(32 → 48, k=3, s=2, p=1)+ReLU        -> (5, 27)
  AdaptiveAvgPool2d((2,8)).flatten(1)        -> 768
  Linear(768 → 64)+ReLU                      -> [B, 64]

hud_status 分支（结构与 hud_score 相同、权重独立）
  ...                                        -> (16, 27)
  AdaptiveAvgPool2d((8,4)).flatten(1)        -> 1536
  Linear(1536 → 64)+ReLU                     -> [B, 64]

fusion
  trunk = ReLU(Linear(256 → trunk_hidden)(concat[pf(128), score(64), status(64)]))

heads
  self_head : ReLU(Linear(trunk_hidden → state_hidden)) → Linear(state_hidden → 22)
  candidate_embed : Embedding(18, candidate_hidden)
  score_head : ReLU(Linear(trunk_hidden+candidate_hidden → candidate_hidden)) → Linear(→1)
```

细节要求：

- 三个分支必须是**三个独立的 `nn.Module` 实例**；`hud_score` 与 `hud_status` 不得共享任何参数（单测会检查它们的 `state_dict` 键前缀不同且参数张量不共享 `data_ptr`）。
- 形状随 `pf_width`/`hud_width`/`playfield_hw` 变化时必须自动成立（不要硬编码 384/768/1536，用 `pf_width*3*4` 与 `hud_width*3*pool_cells` 推导）。
- `AdaptiveAvgPool2d((16,8))` 的边界近似（≤0.875 特征格）是**可接受的设计近似**，不要试图用裁剪/插值"修正"。

### 4.3 公共函数（模块级，训练与部署必须共用）

```python
def decode_position(heatmap_logits: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
    """[B,H,W] logits -> (rx[B], ry[B]) in [0,1]，soft-argmax 加权期望。
    p = softmax(logits.flatten(1), -1)
    col = (p * arange(W).repeat(H)).sum(-1);  row = (p * arange(H).repeat_interleave(W)).sum(-1)
    rx = (col + 0.5)/W;  ry = (row + 0.5)/H
    """

def heatmap_target(rx: np.ndarray, ry: np.ndarray, grid_h: int, grid_w: int,
                   sigma: float = 1.5) -> np.ndarray:
    """[N] rx/ry -> [N, grid_h*grid_w] float32 归一化高斯目标（numpy，供 S3-3 调用）。
    gx = clip(rx*grid_w - 0.5, -1.0, grid_w); gy = clip(ry*grid_h - 0.5, -1.0, grid_h)
    target = exp(-((x-gx)^2+(y-gy)^2)/(2*sigma^2)); target /= target.sum(axis=1, keepdims=True)
    """
```

`decode_position` 必须是 `decode_state` 内部与指标计算共同使用的**唯一**实现。

### 4.4 `VisionScorerV2` 公共 API（必须与 v1 同名同签名）

| 成员 | 返回 |
| --- | --- |
| `__init__(config: VisionNetConfigV2 \| None = None)` | 默认 `VisionNetConfigV2()` |
| `.config` | 构造用的 config 实例 |
| `features(regions) -> Tensor` | `[B, trunk_hidden]` |
| `score(regions, features=None) -> Tensor` | `[B, 18]` |
| `decode_state(regions, features=None) -> dict` | 见下表 |
| `act(regions, deterministic=True)` | `(actions[B,4] int64, zero[B], value[B], zero[B])`；`actions[:,1]=1`、`actions[:,3]=0` |
| `num_parameters() -> int` | 参数量 |

`decode_state` 返回键（**跨 SubStage 契约 C1，不得改名**）：

| 键 | 形状 | 说明 |
| --- | --- | --- |
| `self_feat` | `[B, 24]` | 0:2 = heatmap 解码坐标；2:24 = `self_head` 输出 |
| `danger_log` | `[B, 128]` | `log1p(danger/8)`，**行主序展平**（16×8） |
| `heatmap_logits` | `[B, 28, 24]` | 原始 logits（`Conv2d(...,1,...)` 的输出必须 `squeeze(1)` 后再暴露，**不得**返回 `[B,1,28,24]`） |

错误行为：`regions` 缺分区 → `KeyError(f"missing regions {sorted(missing)}; got {sorted(regions)}")`；`state_head=False` 时 `decode_state` → `RuntimeError("this model was built with state_head=False")`。

### 4.5 checkpoint 派发（改 `touhou_rl/vmodels.py`）

- `save_vision_checkpoint(path, model, extra=None)`：payload 增加 `"arch"`，由模型类型推断 —— `VisionScorerV2` → `"v2"`，其它 → `"v1"`。**函数签名不变**。
- `load_vision_checkpoint(path, map_location="cpu")`：
  1. `kind != "vision_scorer"` → `ValueError("not a vision checkpoint")`（沿用）；
  2. `arch` 缺失 → 视为 `"v1"`；
  3. `"v1"` → `VisionScorer(VisionNetConfig(**config))`；`"v2"` → `VisionScorerV2(VisionNetConfigV2(**config))`（tuple 字段需 `tuple(...)` 还原）；
  4. 其它 → `ValueError(f"unknown vision arch {arch!r}")`；
  5. `frame.H/W` 校验沿用 v1 逻辑（`vision.VISION_H/W`）。
- 为避免循环 import，`vmodels.py` 在函数内部 `from .vmodels2 import VisionScorerV2, VisionNetConfigV2`。

## 5. 必须写的单元测试（`touhou_rl/tests/test_vmodels2.py`）

至少 8 条，全部在 CPU 上跑、总时长 < 60 s：

1. `test_v2_shapes_and_keys`：`depth=1`，batch=2，`decode_state` 三个键的形状/ dtype 正确；`self_feat` 的 0:2 落在 `[0,1]`；`danger_log` 是 `[B,128]`。
2. `test_v2_param_budget`：默认配置下 `450_000 <= num_parameters() <= 650_000`。
3. `test_v2_act_contract`：返回 4 元组；`actions.dtype == torch.int64`；形状 `[B,4]`；`[:,1]==1`；`[:,3]==0`；`value` 形状 `[B]`。
4. `test_hud_branches_are_independent`：`hud_score` 与 `hud_status` 子模块的参数张量无共享（比较 `data_ptr` 集合不交），且 `state_dict` 键包含不同前缀。
5. `test_heatmap_target_peaks_at_label`：`heatmap_target([0.5],[0.5],28,24)` 的 argmax 落在 `(14,12)` 或相邻格；每行和为 1（`atol=1e-5`）；`rx=0/1` 时不出 NaN。
6. `test_decode_position_recovers_peak`：构造 one-hot logits 在 (10,7)，`decode_position` 返回的 `ry/ rx` 与 `(10.5)/28`、`(7.5)/24` 相差 < 1e-4。
7. `test_decode_position_is_smooth`：把 one-hot 换成两侧各 0.5 的 two-hot，返回值必须落在两格之间（证明是加权期望而不是 argmax）。
8. `test_checkpoint_dispatch_and_backward_compat`：v2 存读往返后 `score` 输出 `allclose(atol=1e-6)`，payload 含 `"arch": "v2"`；用手工构造的 v1 payload（不含 `arch` 键）加载成功并返回 `VisionScorer` 实例；`arch="v9"` 抛 `ValueError`。
9. `test_depth3_input_channels`：`depth=3` 时 `[B,3,224,192,3]` 输入能前向（验证通道数 = `3*depth`）。
10. `test_danger_head_regional_alignment`：构造一个只有某一格 danger 目标的合成 batch（例如目标放在 `(row=8,col=4)` 对应的场地位置），用随机初始化模型跑 `danger_log`，断言「argmax 落在目标格 ±1 格内」的概率 > 0.5 属不可控 —— **改为**只断言输出形状与有限性，并断言 `AdaptiveAvgPool2d` 输出格数与配置一致（不做质量断言，质量由 S3-6 的实验判定）。

> 第 10 条的取舍要写进完成报告：随机初始化模型无法验证定位质量，只验证形状与可微性；`backward()` 能跑通且所有参数 grad 非 None（`state`/`policy` 两条损失路径各测一次）。

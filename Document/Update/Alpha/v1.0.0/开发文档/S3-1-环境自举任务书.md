- 依赖前置：无

- 所属阶段：Stage 3 开发

## 1. 背景与目标

`third_party/th08` 子模块在干净克隆状态下缺少两样私有输入：VC7 工具链前缀（`scripts/prefix`，被 `.gitignore` 忽略）与 canonical 目标二进制（`resources/th08.exe`，被忽略）。没有这两样，上游 `scripts/build.py` 的 VC7 链路无法运行。

本 SubStage 目标：把这两样私有输入以**可复现、可校验、幂等**的方式落到子模块的 gitignored 路径，并产出机器可读的环境报告。

| 目标来源 | `D:\Games\[th08] 东方永夜抄 (日文版)\[th08] 东方永夜抄 (日文版)\th08.exe` | 正版日语 1.00d，840,704 B |

## 4. 函数契约

### 4.1 `Get-Th08Context [-RepoRoot <string>]`

- 输入：可选 `RepoRoot`，缺省由 `$PSScriptRoot` 上溯两级推导。
- 输出 `[pscustomobject]`，字段严格为：`RepoRoot, Th08Root, ToolsDir, TargetExePath, PrefixDir, BuildDir, PlayDir, EvidenceDir, ReportsDir, ScriptsDir`。
- 失败：`Th08Root` 或 `ScriptsDir` 不存在 → `TH08-E01`。

### 4.2 `Assert-Th08Target -Path <string> [-ExpectedSize 840704] [-ExpectedSha256 '330FBDBF58A710829D65277B4F312CFBB38D5448B3DF523E79350B879213D924']`

- 行为：`Test-Path -LiteralPath` → 取 `Length` → `Get-FileHash -Algorithm SHA256`（统一大写）→ 比对。
- 输出：`[pscustomobject]@{Path; Size; Sha256; Verified=$true}`
- 失败：文件缺失 / 尺寸不符 / 哈希不符 → `TH08-E02`，消息中必须带实际值。

### 4.3 `Get-Th08PeInfo -Path <string>`

- 行为：读文件前 1 MiB（或全文件，文件 <1 MB），解析 `e_lfanew` → `PE\0\0` 签名 → `Machine`(偏移 +4)、`NumberOfSections`(+6)、`SizeOfOptionalHeader`(+20)、`OptionalHeader` 的 `Magic`(0x10b=PE32)、`ImageBase`(+28)、`Subsystem`(+68)。
- 输出：`[pscustomobject]@{IsPe32; Machine; Subsystem; ImageBase; Size}`
- 失败：非 MZ / 非 PE / 可选头 magic 非 0x10B → `TH08-E05`。

### 4.4 `Assert-Th08PeInfo -Path <string> [-ExpectedMachine 0x014C] [-ExpectedSubsystem 2] [-ExpectedImageBase 0x00400000]`

- 行为：组合 4.3 并断言三项；输出同 4.3；失败 `TH08-E05`。

### 4.5 `Initialize-Th08Environment -Context <object> -PrefixSource <string> -TargetSource <string> [-Force]`

- 行为（严格按序）：
  1. 校验来源前缀完整性：存在 `PROGRAM FILES\MICROSOFT VISUAL STUDIO .NET\VC7\BIN\CL.EXE`、`mssdk\include\d3dx8.h`、`mssdk\lib\d3dx8.lib`、`ninja\ninja.exe`。任一缺失 → `TH08-E01`。
  2. 若 `<PrefixDir>` 不存在或 `-Force`：`Copy-Item -Recurse -Force` 复制前缀；复制后重新做第 1 步校验。
  3. 若 `<TargetExePath>` 缺失或 `-Force`：用 `Copy-Item -LiteralPath` 复制目标。
  4. `Assert-Th08Target -Path <TargetExePath>`。
  5. 写 `build/reports/env-report.json`（schema `th08-env-report/1`：`createdAt, prefix{source,destination,files,bytes,checks{cl,d3dx8Header,d3dx8Lib,ninja}}, target{path,size,sha256}, ok`）。
- 输出：上述报告对象。
- 失败：E01/E02，且**不得**写入 `ok:true` 的报告。

## 5. 入口脚本行为

`Prepare-Environment.ps1`：

```powershell
param(
  [string]$PrefixSource = 'D:\WorkShop\th08-main\th08-main\scripts\prefix',
  [string]$TargetSource = 'D:\Games\[th08] 东方永夜抄 (日文版)\[th08] 东方永夜抄 (日文版)\th08.exe',
  [switch]$Force
)
```

- 必须 `Import-Module (Join-Path $PSScriptRoot 'Th08Pipeline.psm1') -Force`。
- 成功：输出三行摘要（前缀文件数/字节、目标哈希、报告路径），`exit 0`。
- 失败：捕获异常，输出 `TH08-E??` 原文，按设计文档 §6.2 映射 `exit 2`（E01）或 `3`（E02）。
- 中文路径与方括号：所有文件 API 用 `-LiteralPath`；输出使用 UTF-8 编码写文件，控制台输出避免强依赖代码页。

## 7. 禁止事项

- 禁止修改 `third_party/th08` 中任何受版本管理的文件（`src/`、`scripts/*.py`、`config/`、`.gitignore` 等）。
- 禁止把私有前缀/目标复制到 `Document/`、`tools/` 或任何会被提交的路径。
- 禁止运行 `create_devenv.py` 或联网下载工具链。
- 禁止在报告中写入零售数据的绝对路径以外的敏感信息；报告文件本身位于 gitignored 的 `build/`。

## 8. 自测要求

1. 正向：`powershell -NoProfile -ExecutionPolicy Bypass -File tools\th08\Prepare-Environment.ps1` → `exit 0`，报告存在且 `ok:true`。
2. 边界：`-TargetSource` 指向不存在的文件 → `exit 3`，异常消息含 `TH08-E02`。
3. 异常：临时重命名 `ninja.exe` 后以 `-Force` 执行（若前缀已就位，需先备份该文件），应报 `TH08-E01`；完成后恢复文件。
4. 把上述三条命令与输出尾部（≤6 行/条）记录到 `Document/Update/Alpha/v1.0.0/Stage3/完成报告.md` 的 S3-1 小节。

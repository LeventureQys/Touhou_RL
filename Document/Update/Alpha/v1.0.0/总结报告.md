## 4. 关键决策（详见 `设计文档.md` §7）

- **DD-01/DD-12**：运行体是 VC7 原生重建 `bugfix` 构建；normal 只作精确性证据；开发期出现并发会话占用运行目录，经用户裁决"直接接管"后独占。
- **DD-02/DD-03**：私有工具链前缀与 canonical 目标从既有副本复制（未联网下载 VS.NET 2002 介质）；数据以复制方式装配，正版目录只读。
- **DD-13**：复现性判据改为 `.text` 的 `codeSha256`（PE 时间戳使整文件哈希不可比）。
- **DD-14/DD-17**：退出走游戏内菜单（标题 `Esc`→`Z` 走 Quit），运行器区分 `natural`/`wm-close`/`forced`。
- **DD-15/DD-16/DD-18**：DPI 感知 + `__COMPAT_LAYER=HIGHDPIAWARE` 保证 1:1 640x480 截图；每步重解析窗口句柄；启动前清理旧日志。
- **窗口标题编码**：TH08 用 ANSI/Shift-JIS 设标题，`windowTitle` 以 `GetWindowTextA` + CP932 解码为准，`windowTitleUnicode` 仅诊断。

## 5. 复现步骤（零上下文三步）

```powershell
# 1. 环境自举（幂等；私有前缀 + canonical 目标）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\th08\Prepare-Environment.ps1
# 2. 双构建（串行、-j 1；normal 供精确性证据，bugfix 为运行体）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\th08\Build.ps1 -BuildType both -Fresh
# 3. 装配运行目录并实际跑一遍（含单测与两次运行）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\th08\Verify.ps1
```

单独游玩：`... -File tools\th08\Run.ps1 -Profile l2-gameplay`；菜单退出：`-Profile l2-menuexit`。
所有命令必须用 `-ExecutionPolicy Bypass`（本机禁脚本），且运行期间只允许一个 `th08.exe`。

## 7. 已知限制

1. 运行体依赖**私有零售数据与本地私有工具链**（不可分发），且 `normal` 构建因零售版本身份校验无法运行。
2. 暂停菜单项未做导航验证；游戏内退出/重开需先定位菜单项。
3. 菜单退出曾出现一次按键丢失（已用双确认兜底）；高频自动对局仍建议加"画面变化校验 + 重试"闭环。
4. MIDI 输出未验证（WAV 模式正常）。
5. 一个工作区同时只能有一个写者：VC7 构建与游戏进程均须独占（`Invoke-Th08Build` 已加并发守卫）。

## 8. v1.1 建议（按价值排序）

1. **状态导出通路**：用 `config/mapping.csv` + `build/th08.map` 定位 `g_GameManager`/`g_Player` 等全局，做只读内存快照，产出 RL 观测（与本次"跑通"同构，风险最低）。
2. **画面反馈闭环**：注入按键后校验画面变化，失败重试，替换现在的固定等待。
3. **确定性回放**：接入上游 replay 校验（108 份录像 / 12,311,460 次演算）作为回归门禁。
4. **运行目录会话隔离**：`build/play-<session>` 后缀，避免再次出现 E-01 类并发冲突。
5. **暂停菜单导航**：定位 `GameManager::isInGameMenu` 菜单项，支持游戏内重开/退出。

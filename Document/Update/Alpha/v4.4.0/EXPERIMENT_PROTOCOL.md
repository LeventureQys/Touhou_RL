# 实验协议草案｜冻结闭环与开环的配对比较

状态为**待在运行机登记**。以下给出建议首版数值、计算办法与偏离处理。研究负责人须在查看新评测结果前把实际窗口清单、权重摘要、样本数、动作库、随机流、分析器版本、预算写入不可变运行清单。协议修订产生新编号，并标出修订者是否已经见过旧批结果。

## 1. 任务和取样

- 冻结抽样框：在训练材料上先标定两个可识别的战斗阶段（例如道中弹幕段、Boss 攻击段），并为每阶段写下可机械判断的时间范围、镜头/攻击事件、起点前安全接管条件及哈希覆盖。对每个新祖先独立等概率抽一个阶段，在预列合格起点中均匀抽一个。窗口及两臂运行顺序都由公布算法和固定种子生成。资格条件只读前缀和剧本边界，提前排除已知距转场不足 600 帧的起点。特权教师、固定动作或 A 在新窗口的成败均不得决定入选。记录抽样框大小、每步排除数、自然频率与本次 1:1 阶段混合的差异。
- 正式主分析每祖先恰有一个窗口和一个独立策略随机流。开发时可多窗多 RNG。若项目需要穷举有限磁带库而无法视作独立抽样，则另报这批窗口的条件性结果，不外推到新祖先。

## 2. 各臂怎样产生动作

| 臂 | 允许读取的输入 | 配置与用途 |
| --- | --- | --- |
| A-live | 当前真实状态和危险物、决策序号 | 冻结 R38 的 A 权重及 106 维特征顺序，按原分布采样。开发阶段校验历史采样器和新适配器给定同一流的输出 |
| A-open | 冻结的训练供体编号、决策序号 | 目标局开跑前已存好 300 个动作的表。运行中只顺序读取，无目标状态、像素、命中或重选逻辑 |
| Constant | 固定 #12 | 用历史训练结果固定动作；确定性时每窗一次即可。保留按实际帧长计出的 0.5 决策 |
| Teacher | 同起点的真实状态，受相同动作限制 | 训练侧选择并冻结一个特权教师，只输出 18 个合法候选；重新验证强制射击、无 bomb、两帧保持下的有效性。完整动作教师的 100/100 不能作本任务的正对照结果 |
| Random | 预分配的均匀随机数 | 开发参考，18 路每决策独立均匀采样。研究主比较只用 A-live 与 A-open |
| B/C | 冻结像素栈、HUD、自身实际动作历史、由这些输入生成的记忆 | E3 启用。B/C 行为契约一致，差别只有 BC 初始化。新干净窗口上同步重测 A 和基线 |

**开环序列的可执行做法。** 预先按阶段登记训练供体起点。每个目标配对拥有独立随机流，在开跑前以该流在匹配阶段的独立训练供体上运行冻结 A，并保存实际发送的动作。供体早死后用训练库中另一个同阶段、已活到相应步的轨迹，从相同决策索引接续；备选依固定哈希序选择。没有可用供体时用 #12 补至 300 步。不能按供体是否成功或目标表现挑“最佳序列”。两臂的原始策略噪声可预生成相同随机数，协议固定采样器、候选顺序、随机数到候选的映射和软件版本。动作表预生成后登记 SHA；目标起点只提供事先的阶段标签与试验编号。

保存原供体长度、每次接续区间、#12 补齐帧、跨阶段缺货数和全序列 SHA。评估两臂在前 30/100/300 步的动作频率、切换率、持续时长和 focus 占比，区分“预定表”和“目标实际活到的部分”。**建议质量门**为开发阶段 #12 兜底步数占全部计划步数 ≤10%，同阶段对应供体覆盖两个阶段，无越权读取；正式前固定规则。达不到时扩训练供体或采用新的预注册开环构造，已有运行保留为敏感性分析。再以只从训练动作拟合的一阶转移策略作开发对照，检查增益是否只来自拼接破坏动作连贯性。H1 描述相对这套可部署开环库的收益；危险物的具体作用另做 H2。

**正对照和时序回放分工。** 已知录像的逐帧动作仅供检验引擎重放及裁判。合法教师以每两帧一动作接管，在开发中应在两个阶段均给出至少一条完整的真实成功轨迹；逐窗公布失败。如果一个阶段所有教师尝试都失败，先在该阶段的开发窗找一个可行控制器或修复测量，再冻结正式设计。不得看到正式集结果后移除该阶段。

## 4. 主指标、估计与功效

每局 `Y=1` 表示从接管后完整执行 600 帧、无死亡、可核验。死亡当帧计为失败。二级指标 `T` 是 600 帧内实际存活完整帧数除以 2，上限 300；这就是该有限时域的表现。另报每窗中位数、下四分位数、每 60 帧存活曲线、死亡原因、有效/无效尝试和耗时。若有与死亡无关的提前终止，按[裁判契约](SYSTEM_DESIGN.md)标注，单列最坏/最好情形，不能直接给 300。

每祖先一个配对，`b` 为仅 A-live 成功的**对数**，`c` 为仅 A-open 成功的对数，`N` 为有效完整配对数。公开四格原始计数、两臂成功率及配对差 `Δ=(b−c)/N`。对独立同分布配对的边际同质零假设，当 `m=b+c>0`，单侧精确 McNemar 用 `P[Binomial(m,0.5)≥b]`；零不一致时 p=1。该检验不要求两臂独立，要求配对之间的抽样假设成立。同一冻结供体库、同一权重下的推断说明其条件范围。

- **支持具有实际价值的反馈收益**：配对有效、主检验单侧 p≤0.05，且观察到的 Δ≥5 个百分点。5pp 是本计划建议的推进门。只宣称存在正收益并报告点估计；宣称“真实收益至少 5pp”还需区间下界支持。
- **排除预定收益幅度**：报告配对风险差的保守双侧 95% 区间。分别对 b/N、c/N 作 97.5% 双侧 Clopper–Pearson 区间，交叉相减得到 `[L_b−U_c,U_b−L_c]` 并裁到 [−1,1]。只有上界 <5pp 才宣称排除了该幅度。若区间支持明显负值，单独报告可能伤害。其余为未定。
- **开发集和复训**：先在每个祖先内平均，再让祖先等权；记录各个阶段、种子、差值及原始分母。多次训练共用窗口时保留同一对照关系，探索性区间按训练种子与祖先两层/交叉配对重采样。只有三个训练种子时同时展示每个种子的原始效果，避免用窄区间概括训练稳定性。[RL 小样本评测研究](https://papers.neurips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)

**为什么建议 256 对。** 下表是在假定不同祖先独立时、满足上述“单侧检验 + 观察差≥5pp”两项的概率。`p10/p01` 分别是仅闭环/仅开环成功的概率。属于设计情景，项目尚未测得这些概率。

| 独立对数 | p10/p01 = 0.15/0.05 | 0.20/0.10 | 0.10/0.05 |
| ---: | ---: | ---: | ---: |
| 64 | 46.1% | 35.2% | 16.4% |
| 128 | 78.3% | 61.8% | 35.1% |
| 256 | 97.0% | 88.6% | 51.7% |

复算时先令 `M~Bin(N,p10+p01)`，再令 `B|M~Bin(M,p10/(p10+p01))`。对每个 M 枚举满足精确尾概率和 `(2B−M)/N≥0.05` 的 B，并求两层概率之和。正式运行前先用开发配对估算真实不一致率、检查新祖先供给与预算，可一次性调整 N 并封存依据。真差异只有 5pp 时，256 对在所列情景仍约一半机会过门。只拿到 8 或 16 个祖先时，应给逐祖先结果和不确定性。多抽策略随机数只会改善这些窗口自身的估计。

## 5. 失败、泄漏和补充分析

1. 合法失败（包括最后一帧死亡）占用原定位置。技术无效保留原因，以原 pair_id、种子和双臂配置重放，至多一次；原记录不可覆盖。仍无效的配对留在待判分母，不挑新的容易窗口。正式批次只有全部计划配对有效才运行上述主门；不完整报告有效配对表与将待判对全部有利/不利时的 Δ 界。
2. 封存失败、观察时间不足、动作库依赖目标数据、policy 输入中混入裁判或确认祖先曾进训练，相关批次不能用于确认。修复后重新编号，已有结果保留。成功/死亡发生后不重试以改变结果。
3. E1 的 H2 干预、动作频率对照、训练曲线和极端轨迹属于开发诊断。推荐增加同阶段匹配的非危险物替换对照，分开检查近弹、激光、贴边三个子群；观测替换可能产生物理上不一致的组合，需检查分布并结合真实分支。报告全部预列子群和样本数，新的解释需要新的窗口检验。
4. 数据管理员记录首次访问时间、读取者、用途与确认批摘要。在任何正式输出可见后改变主指标、样本量、补齐或删窗规则，都需在下一个独立批次检验。未盲的研究者可调试开发集，评测机仅接收冻结清单。

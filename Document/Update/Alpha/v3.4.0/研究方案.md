# v3.4.0 研究方案：搜索保留、价值学习、DAgger 与策略蒸馏

- 日期：2026-10-24
- 前置：v3.3.0 已验收失败；目标仍为 TH08 Lunatic `frames_mean > 4000`
- 性质：**研究方案，不是执行授权**。必须先通过 Stage 0 离线门，再进入真机阶段。

## 1 结论

不再把“纯 PPO 策略替代搜索”作为主路线。仓库实测显示：random 2787.7、冻结基线 1856.1、六次 BC/PPO 训练 1214–1894、v3.3 TTC+危险图+PBRS 1353.3，而搜索教师为 6400.8 的删失下界。失败共同表现为熵坍缩、低换向率、常数动作或贴墙。

根因是：单实例低吞吐 + 终端死亡信号 + 长时信用分配 + 400k 决策不足以把一次搜索内化成一次前向。因此新路线保留搜索，把学习用于价值预测、风险预测和搜索加速。

## 2 推荐架构

```text
规则/几何短视搜索教师
        ↓
离线学习 V(s) / Q(s,a) / 可达性
        ↓
短视 MPC/beam search + learned value
        ↓
学生状态 DAgger 标注
        ↓
策略/value 蒸馏
        ↓
风险高时搜索兜底，风险低时策略快速执行
```

不建议第一步实现完整 MuZero。已有弹幕/碰撞几何可直接用于短 rollout；PETS 也说明不确定性动力学 + trajectory sampling 可以显著提高样本效率，但本项目应先用规则动力学而不是学习 world model。

## 3 Stage 0：离线价值可学习性门

### 3.1 数据

使用已有 `raw_safety_snapshot`、`teacher_action`、逐局 `frames`，路径：

- `Document/Update/Alpha/v2.0.0/rollouts/**/episode-*-decisions.jsonl`
- `Document/Update/Alpha/v3.3.0/step2-privileged/evidence/`

每条样本构造：

- 当前特权状态 `s`；
- 18 个候选动作；
- 未来 10/20/40 帧的 clearance/碰撞标签；
- trajectory return-to-go 或剩余生存帧数。

### 3.2 训练两个离线模型

1. `V(s)`：预测当前状态的剩余生存帧数/成功概率；
2. `Q(s,a)`：预测候选动作执行后未来 H 帧安全概率或 clearance。

推荐先用监督回归/排序，不直接上 IQL；数据质量和标签口径先可验证。

### 3.3 通过门

| 指标 | 通过标准 |
|---|---:|
| 留出集 V 排序 Spearman | ≥ 0.60 |
| Q 安全/危险 AUC | ≥ 0.75 |
| Q 最大动作与教师动作一致率 | ≥ 50% |
| 死亡前 10 决策的风险排序 | 显著高于随机 |

Stage 0 失败则不启动在线训练；先修状态/标签。

## 4 Stage 1：搜索 + learned value

每个决策时刻枚举 18 个候选：

```text
s_a = short_rollout(s, a)
score(a) = immediate_clearance(a) + λ * V(s_a)
a* = argmax score(a)
```

只执行 2–4 帧，再重新规划。报告：

- `frames_mean / median / p10`；
- 每局搜索耗时；
- 18 个候选的 value gap；
- risk-high 时搜索调用率；
- 与原始 beam teacher 的对照。

通过门：在同一 20 局协议下，`frames_mean > random` 且至少不低于冻结基线；若达到 3000，再进行 30 局确认。

## 5 Stage 2：DAgger

学生运行自己的状态分布，教师在**学生访问状态**上重新标注：

- 全 18 维候选值，不只 argmax；
- clearance、TTC、未来危险占据；
- teacher/student action gap。

最多 3 轮，每轮：30 局采集 → 聚合 → 训练 → 20 局评估。数据并集必须保留，不能只取最近轮，也不能用人类数据稀释学生状态。

通过门：`frames_mean ≥ 3000`，并且学生状态下的 teacher-value MAE / action-gap 误差逐轮下降。

## 6 Stage 3：蒸馏与部署

训练像素策略预测：

```text
full 18-action teacher values
+ future danger map
+ TTC / bullet state
+ ranking or margin loss
```

部署分三层：

1. 搜索教师：上限基准；
2. 策略 + 搜索兜底：先争取 `frames_mean > 4000`；
3. 纯策略：只有混合模式稳定通过后才验收。

## 7 为什么比当前路线更合适

- DAgger 的原论文指出，序列决策违反 i.i.d. 假设，学生诱导状态分布必须回灌专家标注：[Ross et al., AISTATS 2011](https://proceedings.mlr.press/v15/ross11a.html)。
- Learning by Cheating 采用 privileged teacher → pixel student，而不是从像素随机做 RL：[Chen et al., CoRL 2019](https://arxiv.org/abs/1912.12294)。
- IQL 在离线数据上用 expectile value + advantage-weighted BC，避免训练时查询数据集外动作：[Kostrikov et al.](https://arxiv.org/abs/2110.06169)。
- Cal-QL 解决离线初始化后在线微调的 Q 值尺度与遗忘问题：[Nakamoto et al., NeurIPS 2023](https://arxiv.org/abs/2303.05479)。
- PETS 通过不确定性动力学与轨迹采样提高样本效率；本项目先用确定性规则弹道替代 learned dynamics：[Chua et al., NeurIPS 2018](https://arxiv.org/abs/1805.12114)。
- AlphaZero/MuZero 的共同启示是：搜索负责长时规划，网络学习 policy/value 以改善或加速搜索，而不是简单地用一次前向完全替代搜索：[AlphaZero](https://arxiv.org/abs/1712.01815)、[MuZero](https://arxiv.org/abs/1911.08265)。

## 8 下一步唯一建议

先做 Stage 0 离线 V/Q 门，不再直接消耗 4 小时 PPO。它可以在 1–2 小时内回答：

> 现有状态与标签是否足以学习“哪个候选动作更有未来生存价值”？

如果通过，再做 Stage 1 的搜索+价值真机对照；如果失败，说明需要先修数据/状态契约，而不是继续调 PPO。

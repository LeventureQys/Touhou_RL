- 性质：本文件是**预注册**。门禁口径、数据切分、判据在任何训练结果产生之前写定；跑完后只填结果，不改判据。

## 1 本阶段要回答的问题

> 现有特权状态（`raw_safety_snapshot` 的弹幕池 + 自机）与现有标签口径，是否足以学出“哪个候选动作更有未来生存价值”？

如果 Stage 0 不通过，那么 Stage 1 的搜索+价值真机实验没有意义，应先修状态/标签契约，而不是继续调 PPO。

## 2 数据

### 2.1 语料

| 语料 | 路径 | 角色 |
|---|---|---|
| v2.0.0 决策轨迹 | `Document/Update/Alpha/v2.0.0/rollouts/**/episode-*-decisions.jsonl` | 混合行为（学生策略 + 工程教师），有真实死亡 |
| v3.1.1 教师演示 | `third_party/th08/build/rl/step2-teacher-demos/episode-*-decisions.jsonl` | 密集（1–2 帧/决策）的搜索教师状态，用于“Q argmax 与教师一致率” |

### 2.2 有效样本口径

一行样本只有在下列条件全部成立时才进入数据集：

1. `raw_safety_snapshot.schema == "v200-raw-safety-snapshot/1"`；
2. `complete is True`（三次抓帧时间戳一致；`world_complete` 一律为 false，不作为条件）；
3. `player_state ∈ {0, 3}`（正常 / 无敌，不含死亡与出生过程）；
4. `player_position`、`bullets.position/velocity/half` 形状一致且全为有限值；
5. `executed_action`、`teacher_action` 为 4 个整数，且 `move ∈ [0,8]`、`focus ∈ {0,1}`。

被丢弃的行按原因计数，写入报告；丢弃率 > 10% 时在报告里单列偏差分析。

### 2.3 每条样本的字段

- `s`：`entity_obs.from_snapshot` 的三件套（`bullets[320,9]`、`meta[5]`、`grid[3,16,16]`），与 v3.3.0 观测契约 `v313-entity-obs/1` 完全一致——Stage 0 只评估“现有状态”，不允许再改观测。
- `a_teacher`：`focus*9 + move`（18 路候选，冻结顺序，同 `entity_obs.candidate_index`）。
- `a_exec`：`executed_action` 的同一映射。
- `episode_end_frame`：该局最后一行的 `frame + frame_delta`（`frame stalled` = game over）。
- `remaining = episode_end_frame - frame`：剩余生存帧数（V 的回归标签，右删失按实际结束计）。

## 3 标签

### 3.1 几何候选标签（Q 的标签）

对每个候选 `a ∈ [0,18)`，让自机按 `a` 的方向**每帧一步**匀速前进（速度/边界与 `options.py`、`chunk_safety.py` 同一常量），弹幕按记录速度直线运动，逐帧算**线段-线段最近距离**，得到未来 H 帧的最小表面间距 `clearance(a,H)`：

- `H ∈ {10, 20, 40}` 帧（研究方案 §3.1 的 10/20/40）；
- `clearance` 上限 60 px（与 `ChunkSafetyConfig.clearance_cap` 同口径），碰撞时为负值，报告里截到 `[0, 60]`；
- `safe(a,H) = clearance(a,H) > 0`；
- 若 `remaining < H`（该局在 H 帧内已 game over），则该行所有候选在 H 上判 `safe=False`、`clearance=0`：人已经死了，不存在“安全候选”。

### 3.2 生存标签（V 的标签）

- 回归：`remaining`（归一化为 `remaining / 8000`）；
- 分类：`survive_60 = remaining ≥ 60`、`survive_240 = remaining ≥ 240`。

### 3.3 标签口径自检（诊断项，不设门）

用**实际执行动作**的几何 `clearance(a_exec, 20)` 去预测“60 帧内死亡”：AUC。它回答“几何标签是否与真实危险同向”。AUC ≤ 0.55 时，Stage 0 的任何通过都要打上“标签可能无效”的注记。

## 4 模型

两个独立模型，共享同一状态编码器结构（不共享权重）：

```text
bullets[320,9] --MLP(9->64->64)--> masked max ⊕ masked mean (128)
grid[3,16,16]  --Conv(3->32)->Conv(32->64)->GAP--> (64)
meta[5]        ----------------------------------> (5)
                      concat (197) -> 256 -> 256
V:  -> 1（剩余帧回归）+ 2（survive_60 / survive_240 的 logit）
Q:  -> 18×3（候选 × 视界，log1p 归一化 clearance 回归）
```

- 优化器：AdamW，`lr=1e-3`，`weight_decay=1e-4`，batch 256；
- V：MSE + 0.5·BCE（两个生存头），10 epoch；
- Q：MSE（54 维全监督），12 epoch；
- 早停只看留出集损失；`seed=11`；
- 设备：`cuda`（RTX 4070 SUPER）。

## 5 切分（防泄漏）

- 按**整局**切分，绝不按样本切分；
- 把所有 `episode-*-decisions.jsonl` 按 `目录/episode-stem` 排序，取序号 `% 4 == 3` 的整局作为留出集（约 25%）；这样两套语料都会被切到，且同一局的不同决策不会跨训练/留出；
- 留出集不参与任何训练或模型选择；报告写明留出集包含哪些局。

## 6 门禁（预注册，逐项判定）

| 编号 | 判据 | 通过标准 | 失败标准 |
|---|---|---|---|
| S0-0 | 数据完整性 | 有效行 ≥ 90%，且两套语料都进入数据集，留出集 ≥ 10 局 | 任一不满足 |
| S0-1 | V 排序（留出集，逐局 Spearman 后取均值） | ≥ 0.60 | < 0.60 |
| S0-2 | Q 安全判别 AUC（留出集） | H=10/20/40 分别为 ≥ 0.75 | 任一 H < 0.75 |
| S0-3 | Q argmax 与教师动作一致率（留出集的教师局） | ≥ 50% | < 50% |
| S0-4 | 死亡前风险排序（留出集） | AUC(risk, remaining<60) ≥ 0.70 且置换检验 p < 0.01 | 任一不满足 |
| S0-5 | 标签口径（诊断） | 记录即可 | 不判失败 |

`risk` 取 V 的 `survive_60` 头的 `1 - p`。S0-4 的对照集：`remaining < 60` 为正类；`remaining > 300` 中随机抽同样数量为负类（`seed=11`），避免同一局内大量近邻样本主导 AUC。

**总判定**：S0-0 与 S0-1…S0-4 全过 → Stage 0 通过，Stage 1 才可预注册；任一不过 → Stage 0 不通过，停止，先修状态/标签。

# v3.6.0 执行计划·T1d 补遗：REGION 条件化比较（修正分层变量后重做）

- 日期：2026-10-25
- 依据：[T1c 补遗](<./执行计划-T1c补遗.md>)、`evidence/region-stratified.json`（T1c 判定 `invalid`）
- 性质：**预注册补遗**。T1c 的结论是"分层失败、作废"，不是"REGION 无效"。本轮只修正分层变量，其余（分数、标签、CV、判定三值、置换）逐项沿用 T1c。
- 写定后才跑。

---

## 1 T1c 为什么作废（实测，不是猜测）

T1c 用 **clearance 的十分位**分层，结果层内 baseline AUC = **0.6629** > 0.55 的停止线。诊断出的原因：

| 现象 | 数值 |
|---|---|
| D1 决策总数 | 21,156 |
| clearance 恰为上限 60.0 的决策 | **10,296（48.7%）** |
| clearance 的不同取值 | 10,565 |
| 十分位切点 | `7.81, 12.06, 20.12, 30.68, 55.55, 60, 60, 60, 60` |
| 分位桶大小 | `2116, 2115, 2116, 2115, 2116, 282, 0, 0, 0, 10296` |

也就是说：**48.7% 的样本堆在上限**，导致第 6–8 个分位桶是空的、第 9 桶是一个 10,296 个样本的原子；而低端 4 个桶各自跨越 4–25 px 的 clearance 区间。层太宽的地方恰好是 clearance 最有区分度的地方，所以"层内 clearance 已经抹平"这个前提根本没成立。

**结论：T1c 从来没真正做过条件化。** 这是分层变量的实现问题，不是 REGION 的结论。

---

## 2 修正（唯一变化：分层规则）

| 项 | T1c | T1d |
|---|---|---|
| 分层变量 | clearance | clearance（不变） |
| 分桶 | 十分位（训练折分位数） | **固定宽度 3 px**，区间 `[-3, 60]` → 21 个桶 |
| 小桶处理 | 无 | 样本 <200 的桶并入相邻桶（按 clearance 距离） |
| 桶有效性 | 无 | **每个桶单独检查层内 baseline AUC ≤0.55**，不合格的桶**丢弃并计数** |
| 聚合 | 阳性数加权 | 阳性数加权，仅在**保留桶**上 |
| 作废条件 | 层内 baseline >0.55 | **>20% 的阳性落在被丢弃的桶里** → `invalid` |

3 px 的依据：`pilot` 的命中半径量级是 0.825（自机）+ 弹丸 half + 0.5 pad ≈ 3–5 px，所以 3 px 是"一个命中宽度"，比它更细的分层没有物理意义。

其余全部沿用 T1c §2：区域分数 = `region20`（玩家连通分量面积，8 px 网格、t=20）；标签 = `death_60`；LOEO 9 折；置换 200 次、局内打乱、`seed=3610`。

## 3 判定（与 T1c 相同，三值）

| 条件 | 判定 |
|---|---|
| 层内 AUC ≥0.60 且置换 p<0.05 | `rescued` |
| 层内 AUC ∈ [0.55, 0.60) 或 p≥0.05 | `weak` |
| 层内 AUC <0.55 | `dead` |
| >20% 阳性落在被丢弃桶，或保留桶阳性 <100 | `invalid` |

`dead` 的含义与前次相同：**在 clearance 相同的条件下，区域分数对 60 帧死亡没有信息**。若本轮仍为 `dead`，REGION 在该表示上停止投入，改为只做"出口方向 + 暴露时间"这类多步量的新表示。

## 4 停止线与伪通过

1. 不得再改分桶宽度、分数或标签；若本轮仍 `invalid`，则记录"条件化在该语料上不可实现"并停止，不再尝试第五次。
2. 不得把被丢弃桶的阳性悄悄计入分母。
3. 若 `rescued`，**本轮不改 REGION 的判定**，只写进 v3.6.1 的重做提案（门禁需另立）。
4. 不得用 D2/D3 的 `min_clearance_60` 替代 `death_60`。

## 4 自我更正记录（读完上面再看这里）

本版本有 **6 处**结论或实现被自己的后续数据推翻/修正，全部保留痕迹、注明日期，没有静默改数：

1. **门禁映射 bug**：首版把增量门挂在策略自己的主标签上（REGION 自评 `in_region_60` 会判 pass）。改为按预注册门禁标签求值 → REGION 从 pass 变 fail。
2. **"ALL 比 BASE 差"的解读**：D1（二值稀有事件标签）下 −0.021 被写成"并集稀释"；T1b 用三组并集否证 → 真实原因是**没有任何块携带生存增量**。
3. **REGION 条件化**：T1c 作废后没有就地调参，而是另写 T1d 预注册；T1d 仍 invalid 后按停止线**停止第四次尝试**。
4. **`current_spell` 读错**：4 字节读法把 retry 菜单读成 `spell` 事件（v3.5.0 S0 的 3 个 spell 事件是假事件）。改为 i16。
5. **幽灵弹**：每个快照多一颗 (0,0)/(0,0) 的"活跃"弹，让"首步完整"检查**假通过**。修复后幽灵不影响任何已提交特征（逐列论证）。
6. **T2 主指标符号**：POWER 的"越高越好"被按"下降"计算（8 倍提升算成 −750%）。改为按指标方向取值，未改阈值。

## 6 本版本没有做的事

- 没有训练任何策略网络（T1 用岭回归，T2 用规则控制器），**因此没有 checkpoint**——可复现产物是"配置 + 种子 + trace"；
- 没有把任何一条策略接进控制环：T1 通过的只有 ENEMY/POWER，T2 一条幅度不足、一条安全不达标；
- 没有用生存指标判定发弹量或 power 战术（v3.6.1 已把这一错配写成显式的范围修正）；
- 没有为了让某条策略通过而改阈值、改视界、改分层或改主指标方向；
- 没有把 `unknown` 字段（子弹归属、符卡相位、激光）当成特征使用。

### 6.4 一句话交接

> v8.0.0 的净结果是：**在 v4.5.0 的三个冻结 `S` checkpoint 上，把「放雷」从一个被禁用的动作变成一个外部脚本规则（最近子弹 < 40/60/80 px 且还有雷时，该决策首帧按雷），4 臂 × 3,600 = 14,400 episode、300 决策 / 600 帧，得到 A0 484/3,600 = 13.4444%（CP95 [12.3462%, 14.6024%]，存活帧均值 216.9714）→ A1/A2/A3 各 3,600/3,600 = 100.0000%（CP95 [99.8976%, 100.0000%]，均值 600.00）。**

> **机制上唯一的解释是「起手那颗雷」：决策 0 的最近子弹距离在 3,600 条上最大只有 36.3780 px（均值 25.2279），三条规则在 10,800 条放雷 episode 上的第一颗雷全部落在决策 0；每局只有 3 颗雷、一颗就够撑满 ≥ 66% 的 episode（A1 最后一次被接受的按雷中位在第 0 个决策）；按键后第 2 帧才扣雷（16,902 次接受的按键延迟恒为 2）。**

## 6 偏差与异常

1. **工单的前提错了（已由执行代理纠正）**：我按"boss 窗口每片约 800 行"设计 b1，实际 `decision_frame>=2900` 是 **5,150/5,150/5,146 = 15,446 行（78.12%）**，差 6.44×。
   执行代理按纪律**没有改定义**，并指出后果：b2 的等量随机抽样里 78.21% 也是 boss 行，两者重叠 12,080 行，只差 3,366 行 → **b1 vs b2 的对照功效被定义本身削弱**。
2. **b2 的 Tier A 只在 1/3 根**，另外两根 35.6% / 62.0%；同 checkpoint 根间离散远大于臂间差，n=3、每格一条确定性 rollout → 无法把训练效应与个体噪声分开。
3. **b1 与 b2 都只训 1,000 步**：这是"轻微微调"，不足以代表"boss 专项训练"；下一轮若要做真正的专项消融，需要换 `decision_frame>=11600` 这类小窗口定义（需重新授权口径）。
4. **A/B/C 三批的基线是引用**（`.tmp_v832_s2c3/A`、`.tmp_v832_s2c4/A`），本轮未重跑，逐行复算确认与记录一致。
5. **`boss_summary.boss_life_last=0` 有两种含义**（真空页 / 真的 0 血），本轮已统一改成"从 decision-log 取最后一个 `boss_count>0` 的样本"，两处都登记；`ckpt_l1/seed10` 正是这个坑（空页 0、末次 boss 行 54）。

## 3 测量标准（**必须遵守，否则结论不可信**）

| 量 | 值 |
| --- | ---: |
| 同一模型跨环境种子（n=15） | **sd 459.3**，极差 1,284 |
| 同一配方跨初始化种子（n=4） | 均值 1,601.7 – 2,115.7（**极差 514**） |
| 同一模型跨环境种子极差（最坏） | **965** |

- **要分辨 500 帧需 n=15/臂**（非中心 t，α=0.05、power=0.8）；n=3 只能分辨 ≥1,410 帧。

- **同配方对照必须跑满 ≥3 个训练种子**（s1 10/15 vs s3 0/3，p 仍只 0.07）。
- 早期行为**几乎确定性**：前 105 个决策在 15 个种子上逐位相同；`vertical_frac = 0`。**运行间方差来自环境。**

## 4.5 反事实采集配方（**已验证，可直接扩采样**）

这是本会话最后、也最可复用的一条：**离线语料没有"同状态不同动作"的对，但引擎能造出来。**

### 配方

```
tools/rl/v8_32_pulse_eval.py run ... --pulse-start <D> --pulse-len 0   # 闸门：必须与无扰动基线逐位相同
# 然后对 c = 0..17：
tools/rl/v8_32_pulse_eval.py run ... --pulse-start <D> --pulse-len 1 --pulse-cand <c>
```

- `--pulse-len 1` = 只强制**一个决策**（2 帧），随后完全交还策略 → 真正的单步反事实。
- **内建逐位闸门**：策略在 `<D>` 自己选的那个 `cand` 就是"零扰动"，它必须与 `--pulse-len 0` 逐位相同。
  （点 300 是 `cand 0`、点 400 是 `cand 12`，两次都逐位复现。）
- 每点 **19 次启动**（1 闸门 + 18 分支）。

### 已验证的两个点（入口 64、seed 1000、基线 1,270 帧）

| 点 | 存活范围 | 极差 | 按 move 组间极差 | 后继轨迹去重 |
| --- | --- | ---: | ---: | ---: |
| 决策 300 | 1,048 – 2,230 | **1,182** | 344 | 11 种 |
| 决策 400 | 1,046 – 2,408 | **1,362** | 874 | 18 种 |

### 三条必须遵守的约束

1. **价值是状态点属性**：两点逐 `cand` 的 Spearman **ρ = −0.355**（p=0.149）→ **排序不跨点迁移**。
   例：SE 不聚焦在第一点 +960、第二点 −192；聚焦在第一点 −222、第二点 +1,084。
   → **不能学全局动作排序，只能学 `V(s,a)`。**
2. **等值类不可迁移**：第一点 7 个动作共享同一条后续轨迹，第二点 18 条全不同。学习时必须把等值类合并为一个样本。
3. **单分支含混沌放大**：单步 → 数百帧后差异巨大。估价值必须**每点多次重复**。

### 扩采样的预算估计

若要点 20 个 × 每点 3 重复 × 19 次 = **1,140 次启动**（约 12–15 小时引擎时间，按每次 ~40 s 计）。
这才能支撑一个"状态条件价值函数"的训练集。**这是下一阶段第一件该做的事。**

## 4 任务卡草案（本轮验证对象，冻结后写 `nat01/task_card.json`）

**任务 `S1N-MB1`**（Stage 1 / Normal / Border Team / 自然开局 / 首个中 boss）

| 项 | 定义 |
| --- | --- |
| 入口 | 自然 `RESET`：`stage=0`、`difficulty=normal`（引擎参数 `1`）、`team=0`、`seed ∈ dev 根`；入口帧 = 0，入口决策 = 0 |
| 成功事件（Tier A） | 首个 boss 代被击破：该代 `life` 由 6,000 降到 0（历史帧 3,652–3,900，20/20 成立） |
| 阶段成功（Tier B） | 在帧 2,936 仍存活且该帧出现 boss 代（"抵达首 boss"） |
| 合法失败 | `deaths` 相对入口 +1（首死即终止） |
| 截断 | Tier A：4,500 帧；Tier B：3,200 帧。到顶未死未完成 → `truncated` |
| 终止优先级 | `death > success > truncated > error` |
| 时钟 | 决策 = 2 帧（学生臂，obs-v3 契约）；教师臂 4 帧提交（teacher-v1 契约）。**比较单位统一用游戏帧** |
| 射击 | 外生 SHOOT 脉冲（学生臂 period 48；教师臂 period 24，按其契约） |
| 资源 | 自然开局资源；无续关、无外部补给 |
| 判分读数 | 身份以 `HAZARDS` 行（slot + flags1）为准；`ENEMIES` 分页只作诊断，不作判分 |

**Tier B 的意义**：它是 Tier A 的前置子目标，也是 S2 学习试点的第一条可结算曲线（学生当前 0/20）。

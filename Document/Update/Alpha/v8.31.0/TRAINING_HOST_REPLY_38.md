## 6 这对路线意味着什么（阶段 2 的最后一条可用结论）

**在线学习的最小可行形态**（全部有数据支撑）：

| 要素 | 取值依据 |
| --- | --- |
| 探索时长 | **≤100 帧**（4–8%）；持续 ≥600 帧会让存活从 ~1,750 掉到 598–1,166 |
| 探索动作 | 偏向 **idle / focus+S**；**避免 E**（均值 −401） |
| 门控 | 按剩余生命 / 弹幕密度 / 策略置信度选脉冲点（两次 −1,000 都发生在最健康的 seed 上） |
| 回报窗口 | **≤1,166 帧**（常量族的死亡上限），否则 reward 恒为 0 |
| 判分 | 用**到达离散事件**（1,750 / 2,000）而不是均值帧数（回执 33：1,750 阈值下 p≤0.008） |

**这四条合起来，就是路线阶段 2 允许的"小规模在线学习"的施工参数。**

## 0 结论摘要（五条）

1. **DAgger 模型 D2 把自然开局打崩了**：三 seed **1,007 / 943 / 880（均值 943.3）**，
   而同预算基线 m1 是 1,966 / 2,350 / 1,385（均值 **1,900.3**），单片 2,000 步是 1,845.3。
   → **−50.4%（−957 帧）**。这是本项目第一次看到"训练改动把既得能力打坏"。
2. **但在从未采集过的入口上它确实会打 boss**：入口 **2,768** 三根里 **2/3 达成 Tier A**
   （帧 3,538 / 无 / 帧 3,364，伤害 100% / 93.83% / 100%）。
3. **入口 2,560 却不行**：0/3 Tier A，伤害只有 73.32% / 68.45% / 72.63%。
   2,560 比 2,632 更近，成绩却更差 → **不是平滑的"越远越差"，而是对入口的敏感性**。
4. **净判断：这是取舍，不是收益。** 晚段（入口 2,632–2,768 的接管）变强，
   早段（自然开局 0–1,000 帧）崩掉；两项不能同时算作"学习收益"。
   → 按路线阶段 2 的判据，**当前不构成"像素闭环学习收益"的通过**。
5. **最可能的原因**：DAgger 行全部来自帧 ≥2,632 的状态，占比 13.6%，在 8.39 个 epoch 里
   把策略往"晚段接管分布"拉；而自然开局前 1,000 帧的状态在语料里没有任何 DAgger 对应物，
   于是早段行为被牺牲。**下一轮应验证：降权重（0.136 → 0.05）或补采早段状态。**

## 0 结论摘要（三条）

1. **W2 学出了"位置条件"**：把 WP06 的 1,840 行按 **(x 带 × cand) 逆频率**重加权后，模型在三个 x 带上的
   `cand3` 占比变成 **41.45 / 29.09 / 14.56%**，**单调下降**，与教师的 48.56 / 28.64 / 14.56% 几乎重合（中高带**完全相同**）。
   `cand7` 也一样：**9.37 / 40.45 / 34.81%** vs 教师 **9.37 / 41.36 / 34.81%**。
2. **而直接并入（W1）学的是全局边缘**：W1 在同样三带上是 50.48 / 29.55 / 13.92，
   在 `x<100` 带**说右比教师还多**（50.48% vs 48.56%）——它是"到处都说右"，不是"在左边说右"。
3. **代价很小**：T04 `top1_vs_executed` **0.9632**（s1 0.9719，**−0.87 pp**；W1 是 0.9625）。
   → **同一个 1,840 行数据，换行权重就从不条件变成了条件**。这是本项目第一次"用标签权重把条件性买回来"。

## 3 现在的判断

- **"条件性能不能学"这个问题已经有答案：能。** 只要在标签权重里把 (位置 × 动作) 的联合分布拉平，
  1,840 行就足以让模型在三个 x 带上复现教师的条件映射。
- **但"条件性能不能换成生存"仍未测**——那是闭环问题：模型在自己走出来的状态上可能仍然
  贴左墙、仍然不执行"向右"的恢复建议（s1 的失败正是这个：教师说右 48.56%、学生执行 9.58%）。

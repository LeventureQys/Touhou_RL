## 0 结论摘要（四条）

1. **"贴右墙"这个前提是错的**：自然开局段（入口 64）的 1,840 个学生状态里，
   **x ≥ 300 的行一行都没有**（max px = 263.2，中位 33.4，x < 100 占 **79.5%**）。
   学生不是被推到右墙，而是**整段贴在左侧**（x = 8.0 的钳位有 86 行）。
2. **教师"说右"的真实含义是"从左墙救回来"**，而且随 x 单调变化：

| x 带 | 行数 | 教师 `cand3`（右） | 教师 `cand7`（左） | 教师 `cand0`（中立） |
| --- | ---: | ---: | ---: | ---: |
| **`px ≤ 8.001`（左钳位）** | **86** | **100.0%** | 0% | 0% |
| x < 100 | 1,462 | 48.56% | 9.37% | 16.14% |
| 100–200 | 220 | 28.64% | **41.36%** | 5.91% |
| 200–300 | 158 | 14.56% | 34.81% | **24.68%** |
| 300–340 / 340–370 / ≥370 | **0 / 0 / 0** | — | — | — |

   → `cand3` 随 x **单调下降**（[0,50) 50.3% → [250,300) **2.6%**），`cand7` **反向上升**（2.6% → 43.3%）。
   **同一句"向右"在不同 x 上是相反的意思**——这解释了 W1 为什么会把 +32.88 pp 学成一个全局右偏：它把"左墙恢复"与"中右侧该往左"混成一个真值。
3. **学生根本没执行教师的恢复建议**：在 x < 100 的 1,462 行里，教师说右 48.56%，而学生执行右只有 **9.58%**、执行 idle 28.80%。
   → 失败在**执行**，不在标签；这也再次说明"再补同类数据"不能解决（WP06 已证：加了 1,840 行，模型只学到全局偏置）。
4. **判据按预设落到"位置条件不成立"，但形式不同**：右墙带**分子为 0**（不是差值小），执行代理并列记录 `cand3_wall = null`、`diff_pp = null`、`diff_pp_arith = −43.26`，**没有把空带当 0%**。主代理采纳，不事后改预设。

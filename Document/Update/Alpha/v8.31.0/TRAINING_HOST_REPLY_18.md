## 0 结论摘要（五条）

1. **加权实现是干净的**：`--dagger-weight W` 在两端都有等价性证明——
   **W=1.0 重训与 D2 逐位相同**（max_abs_diff **0.0**，state `9c5a6588…`），
   **W=0.0 重训与 m1 逐位相同**（max_abs_diff **0.0**，state `a4de64c9…`）；三个 W>0 的 `batch_indices` 与 D2 同一 sha。
2. **离线曲线单调、但保留度不单调**：dagger `top1_vs_chosen` 0.1175(W=0) → 0.6829(0.05) → 0.8601(0.15) → 0.9692(1.0)；
   T04 保留度 1.0000 → 0.9885 → **0.9986** → 0.9809。**W=0.15 双向支配 W=0.05**，且保留度比 D2 还高。
3. **闭环判决：W=0.15 也没能两端兼得。**
   自然开局 **1,029 / 1,102 / 1,399（均 1,176.7）**——比 D2 的 943.3 好，但**远低于** m1 的 1,900.3 与 1,845 门槛（**−668.6**）。
   接管：2,768 **100% / Tier A 3/3**（三模型最好）、2,632 **70.18% / 0-3**（D2 90.92%、m1 89.13%）、2,560 **52.23% / 0-3**（D2 71.47%）。
4. **"离线保留 99.86%"完全没有预测到"闭环 −38%"**：这是"离线不预测闭环"的**第四次**独立复现，
   而且这次落差最大——离线只差 0.14 pp，闭环差 723 帧。
5. **真正的结论不是"哪个 W 好"，而是"这个策略族太脆"**：
   3,116 行按 0.15 加权只占约 2.3% 的损失权重，却把自然开局从 1,900 打到 1,177。
   → 在量化这份脆性之前，任何"学习收益"的结论都不可靠。**下一轮先测纯 T04 的种子方差。**

## 6 偏差与异常

1. **m1 在入口 2,632 的数字被纠正**：本回执采用 s2i 原始产物复算的 **100.0 / 78.33 / 89.07（均 89.13%，Tier A 1/3，零血帧 3,962）**；
   先前工单里写的 96.10 属于 m1 在 **2,704** 的 s10 那一根。
2. **m1 在 2,560 / 2,768 没有产物**（扫过全部 `.tmp_v832_*/result.json`），那两格只用 D2 作参照。
3. **W=0.05 没有做闭环**：它在离线端被 W=0.15 双向支配，按证据优先级跳过，已记录。
4. **W 的语义**：W 是损失权重乘子，行仍参与采样（除 W=0 时零权行按设计移出池，否则不可能 ≡ m1）。
5. **单次训练**：每个 W 只训一次，T04 保留度的非单调无法区分"真实效应"与"训练噪声"。

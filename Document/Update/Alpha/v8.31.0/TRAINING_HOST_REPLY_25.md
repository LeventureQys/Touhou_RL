## 0 结论摘要（五条）

1. **三路观测都在用，`play` 是主通道**：置零后自然开局均值——
   `play` **−1,209 帧（−3.05 sd，强依赖）**、`hud` **−803（−2.02 sd，强依赖）**、`act_hist` **−555（−1.40 sd，弱依赖）**。
   没有一路是"几乎未被使用"。→ **策略没有忽略像素**。
2. **`play` 置零后的画像与 DAgger 一模一样**：5/5 种子恰好 **891 帧**、`W` 100%、竖直 0.00%；
   DAgger 是 910.6 帧、E 61%、竖直 0.12%。→ **D2 的退化在行为上等价于"看不见画面"**（行为等价，不是因果证明）。
3. **类别平衡不是杠杆（我原先的假设被否）**：`m1` 在**教师状态上的离线动作分布已与教师一致**
   （竖直 3.46% vs 教师 3.82%、focus 25.07% vs 25.54%、L1 0.0286），
   而它在**闭环**里竖直只有 0.28%。→ **罕见动作的丢失发生在"它自己走出来的状态"上，不在损失函数里**。
   加权重训把竖直推到 4.8–5.9%、focus 30%，代价是 top-1 **−9.7 ～ −11.9 pp**、与教师 L1 **放大 6 倍**——那已经是离开教师分布。
4. **所以真正的病仍是协变量偏移，而 DAgger 采错了状态区**：
   采集点在入口 **2,560 / 2,632 / 2,704（boss 战）**，而策略的崩溃发生在**自然开局 500–700 帧**（锁死 E、贴右墙）。
   → **DAgger 从未覆盖它真正失败的状态**。
5. **下一步是对症的**：在**自然开局段**（入口 64 / 16，cap 2,500）采学生状态 → 教师重标注 → 重训。这是本轮唯一有明确机制支撑的方向。

## 6 偏差与异常

1. **消融多跑 1 次**：`A/1000` 因执行代理的形状断言写错（hud 实为 `(1,1,56,160)`）在首个决策前中止（0 帧）；
   修正后用 `A/1000b` 补测 → 总启动 17 次、超上限 1 次；中止那一对账本行**未删改**，故 34 行而非 32 行。

3. **`play` 置零 5/5 种子恰好 891 帧**：经查世界确实分叉（score/events 自第 232 决策起不同），是**策略坍塌**而非引擎退化。
4. **`cw00` 与 m1 文件 sha 不同**（元数据不同）、张量逐位相同——门槛用的是张量级。
5. **类别 9（focus + idle）在语料里 0 行**：加权时按 cap 处理，已记录。

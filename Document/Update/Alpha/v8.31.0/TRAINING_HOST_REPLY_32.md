## 0 结论摘要（四条）

1. **11 个早期行为特征，没有一个与存活相关**（n=15）：最强的两个是 `x_sd`（ρ=+0.443，置换 p=**0.0998**）
   与 `edge_frac`（ρ=+0.437，p=0.1054），**连未校正的 0.05 都过不了**；Bonferroni 后 **0/11 存活**。
2. **原因找到了：早期行为是"几乎确定性"的。** 同一模型 15 个种子的**前 105 个决策逐位相同**
   （cand、`player.x/y`、score 全同），种子从**第 105 个决策**才开始咬合；
   早期动作集固定为 {0,2,3,6,7,11,12,15,16}，**从不使用 N/S（竖直）**，第一颗炸弹固定在决策 18 / 帧 36。
3. **因此"同一模型 1,281–2,565 帧"的方差来自环境**（弹幕 RNG 在决策 105 之后的混沌分叉），
   **不是**来自可辨认的行为差异。→ 任何"让它这样走会活得久"的行为假设，在 n=15 下都**测不出来**。
4. **这条结论把整条线闭合了**：我们一直在测 100–300 帧量级的干预效应，而环境噪声的 sd 是 **396.9**（n=3 的 SE 265）；
   这也是为什么四次假设全部为负、三次干预都更差——**不是方向错，是效应小于噪声，且噪声无法通过换种子消除**。

## 6 这对路线意味着什么

**路线阶段 2 的判据要求"用任务表现决定结论"，而任务表现的噪声（sd 397，需 n≈15）已经与本阶段能达到的效应量同量级。**
在这个约束下，继续在"模仿 + 微调"这条线上做 100–300 帧量级的改进，**原理上不可判定**。

所以下一步必须是**能产生远大于 397 帧效应的改动**，或者**把噪声压下去**：

| 方向 | 为什么它能超过噪声 | 代价 |
| --- | --- | --- |
| **1. 在线学习（RL）** | 直接优化生存，可能产生 2–5× 的跃迁（如 1,900 → 5,000+）；且不再受"教师能力"约束 | 大：需新训练回路 + 大量引擎交互 |
| **2. 换任务/换阶段** | 例如"稳定到达首 boss（帧 2,936）"是**离散事件**，0/15 → n/15 的跃迁不受帧数噪声影响 | 中：判分口径改造 |
| **3. obs-v4（位置标量）** | 消除"同一句右在不同 x 上意思相反"的歧义 | 中：9 个文件 + 补采集；但 pos 是特权状态，**不算像素收益** |

**我的建议**：先做 **2**（把判分从"帧数"换成"离散到达事件"），因为它是**唯一能立刻把信噪比拉开**的改动，
而且不需要新模型、不需要新数据；它也会让阶段 3 的"接通自然第一面"有一个可判的里程碑。

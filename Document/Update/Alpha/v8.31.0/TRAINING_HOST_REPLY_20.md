## 4 统计预算

| 量 | 值 |
| --- | ---: |
| SE(n=3) | **265.2 帧** |
| SE(n=10) | 145.2 帧 |
| 分辨 500 帧所需 n（每臂） | **15**（共 30 次启动；power 0.821，n=14 时 0.792） |
| 分辨 500 帧在 n=10 下的 power | 0.634 |
| n=3 能分辨的最小差异（power 0.8） | **1,410 帧** |

- 算法：两样本双侧 t 的非中心精确解（`df=2n−2`、`ncp=Δ√(n/2)/sd`）；
  自检锚点 d=0.5 → n=64（power 0.8015），并用 40 万次蒙特卡洛复验（0.8017）。
- **sd 自身的不确定性**：10 个样本的 sd 95% CI ≈ [316, 838] → 所需 n 的点估计 15、**区间约 8–46**。
  报计划时应按 15 起并留余量。

## 7 偏差与异常

1. **执行代理自己披露了一处统计实现错误**：power 函数最初写成 `Φ(t·√(ν/W))`（应为 `Φ(t·√(W/ν))`），
   两份独立实现"互相一致"却都错（给出 65/18 而非 64/17）；修正后靠教科书锚点（d=0.5 → 64）与 40 万次 MC 确认。
   验收脚本用**不同数值路径**（t 密度积分 + Gauss-Legendre）独立复算。教训：两份实现一致 ≠ 正确。
2. **重复性判据首版误报**：把本侧独有字段（`model`/`init_seed`）算进 diff，误报 False；改为只比较既有记录过的字段后为 True。
3. **10 个样本估 sd 仍不稳**（CI [316, 838]），所需 n 的区间 8–46。
4. 本轮只标定**自然开局**这一个端点；接管 Tier A（离散计数）的方差结构不同，未标定。

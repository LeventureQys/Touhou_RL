## 0 结论摘要（四条）

1. **动作在死亡时段确实有强信号**：18 个固定动作的存活从 **598 到 1,166 帧**，**极差 568 帧**（cap 600 时只有 66）。
   **P1（≥400）成立。**
2. **我上一轮的"前 600 帧安全窗"是截断假象**：cap 一放开，**18/18 全部在 598–1,166 帧内死亡**（0 个到达 cap）。
   "17/18 打满 664" 只是窗口太短。
3. **P2 失败是我自己设计的缺陷**，不是数据结论：我把阈值定在"活过 1,200 帧"，而 **0/18 能活过 1,200**（最大 1,166），
   于是 2×2 表的存活列全 0、Fisher p 恒等于 1.0——**算术恒等，不是"无差别证据"**。执行代理在跑之前就把这个缺陷写进了 `prior.json`。
4. **对在线学习的含义（这才是真正有用的）**：
   - **信号存在**（568 帧的确定性分化），所以 RL 有东西可优化；
   - 但**"持续单一动作"整体比策略差约 700 帧**（策略 ~1,900 vs 常量族 598–1,166）→ 长窗口的常量探索是**强 OOD 高致死区**；
   - 所以探索必须是**短脉冲（≲100 帧）或带 teacher 回退**，而判分窗口要落在**能死的区间**（≤1,166），不能用 1,200。

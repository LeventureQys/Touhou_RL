## 0 一句话策略

路线给的是"从当前最早影响真实成绩的缺口开始，优先建立一个可复验的像素闭环学习结果"。
训练端据 §13.4 的既有结论（短任务卡 seed-12 专属且零余量、学习器近恒定）判断：
**最早的真实缺口在"自然开局前 1,500 帧"这一段**——教师在这里 20/20 过关且 0 死亡，而当前学生在这里首死。
因此本轮不重开中局短任务，改为**把任务锚点移到自然开局**，先建立一个"教师可在多个独立根上复现完成、当前学生失败、退化基线也失败"的任务卡。

## 5 预算与账本

| 额度 | 本轮上限 | 说明 |
| --- | ---: | --- |
| 引擎启动 | **≤ 24** | S1 三臂 × ≥3 根 = 9；留 15 次给复验与失败重跑 |
| 引擎帧 | **≤ 120,000** | 单局按 ≤4,500 帧估，12 局 ≈ 54,000，留一倍余量 |

| 墙钟 | 按轮内实际 | 不设硬上限，但每轮必须收束出证据 |

每次启动前 reserve、结束后 settle，账本按累计值硬拒超额，不留未结预留。账本与本轮证据同目录。

**预算纪律**：先算一次真实试跑的吞吐（帧/s、GiB/千帧），再定启动数；不够就缩根数而不是缩口径。

## 6 证据与真实性规则

1. **可复算**：每个结论必须能指向"原始文件 + 重算脚本 + 退出码"。回执里的关键数字要由独立脚本从原始行/帧重算。
2. **不混口径**：跨工具比较只比"游戏帧"这类共同单位；决策节拍（2 帧 vs 4 帧）、射击脉冲周期不同的，必须单列。
3. **历史与实测分栏**：历史数字只作参照，不得写进"本轮实测"栏。
4. **负结论同样入账**：教师失败、退化基线意外成功、gate=false，都要原样记录并解释，不改写。
5. **不删除、不覆盖**既有资产与证据；新实验一律新目录，登记进 `ASSET_SYNC.md` / `ASSET_SYNC.sha256`。
6. **禁止模拟**：不得用 mock / 合成轨迹 / 假 checkpoint 冒充真实结果；资产缺失就报缺失。

## 0 结论摘要（四条）

1. **Tier A 现在可判了：0/3——但这是"打到 boss 旁边"的第一次。**
   checkpoint 臂（`ckpt_l1`，入口 2,632）在 3 根上都进入 boss 战：`boss_life` 从 6,000 打到
   **54 / 1,335 / 1,579**（= **99.1% / 77.8% / 73.7%** 的血量），半血帧 3,284 / 3,274 / 3,270（spawn 2,932 之后约 340 帧）。
   没有一根观测到 `boss_life=0`：seed 10 在 4,282 帧 `ENEMY_REMOVED`（生命 102 帧不变、无击杀得分跳变 → 倾向超时离开），seed 11/12 在 3,624 / 3,620 阵亡。
2. **DPS/生存的缺口被量化了（主代理从日志复算）。**
   每帧伤害：教师 **6.2–8.4**（6,000 血用 716–964 帧）；策略 seed11 **6.74**、seed12 **6.43**（与教师同档，但只打了 692/688 帧就死，需要约 900–960 帧）、seed10 **4.41**（活得久但 DPS 只有教师的 ~六成，boss 1,350 帧后超时离开）。
   → **2/3 根差 200–250 帧生存，1/3 根差约 30% DPS**。这是"打不动"还是"活不久"的精确定位，不是笼统的"策略太差"。
3. **数据轴也饱和了：加 episode 不解决问题。**
   只训练 seed10（6,592 行）vs 训练 seed11+12（13,180 行）→ 在**留出片**上的 donor top-1 **0.6359 vs 0.6361（+0.0002）**；
   而同一 checkpoint 跨片抖动是 **1.2–1.3 pp**，即这个差比抖动**小约 60 倍**。
   加上上一轮的预算饱和（2k→16k：0.5933→0.6211→0.6359，16k 的 fit=1.0000 已记忆），
   → **BC 的离线代理指标已到天花板 ~0.636；继续加步数或加片都不会再动它**。
4. **闭环同向：三片合训自然开局 1,900.3，落在单片 2,000 步（1,845.3）与 8,000 步（1,917.7）之间。**
   对 2k **+55.0 帧（+3.0%）**、对 8k **−17.3 帧（−0.9%）**，逐种子方向不一致、n=3 无 CI → 不构成效应。
   与 §0-3 的离线饱和一致：**当前 BC 配方在闭环上的收益已经用尽**。

## 6 偏差与异常

1. **seed 10 的 `boss_life_last=0` 是"最后一页无 boss"的空列表读数**，不是击杀：最后一个仍列出 boss 的帧是 4,280、读到 54。
   本轮已在 `results.json.notes` 与验收里写明，未把它当 Tier A。
2. **Tier A 的冻结口径要求"可观测的 `boss_life=0`"**，而 boss 在 54 血时被移除（无尸体帧）→ 记为 null。
   若要判"击杀"，需要 HUD/事件侧新读数或改 cap，超出本轮 6 次启动预算，未擅自改口径。
3. **本轮未重跑恒动作臂的 boss 读数**（旧 runner 无 `enemies`），所以"血量削减"这个分级指标**暂时没有退化臂对照**，不能声称它有区分力。
4. **M1 没有 donor**（三片全进训练），闭环只能用 dev 种子；离线部分只用 M2 的留出片。
5. **工单里"M2 ≈18 epoch"是估算误差**，实际 6,000×32/13,180 = **14.57 epoch**（已记入 `deviations`）。

1. 不主张 Tier A 达成：**0/3**，没有一根观测到 `boss_life=0`。

## 0 结论摘要（三条）

1. **离散到达判分（"是否活过 X 帧"）确实比均值帧数灵敏**：
   在 **1,750 帧**阈值上，s1 是 **10/15**，而 W2 **2/15（p=0.0078）**、左墙守卫 **1/15（p=0.0017）**、D2 **0/15（p=0.0002）**。
   这与配对 t 的结论一致，但**不依赖分布形状**，且更适合作为"到达里程碑"的判分。
2. **但它没有消除复训方差**：同为纯 T04 的四个初始化种子，
   s1 **10/15**、m1 **2/3**、s2 **1/3**、s3 **0/3**（1,750 阈值）——**同一配方可以差到 0/3 vs 10/15**。
3. **所以判分粒度的改进只对"大效应"有用**（如 RL 可能带来的 2–5× 跃迁），
   对"配方微调"这一档仍然无效。**阶段 2 的结论不变：不通过。**

## 2 Fisher 精确检验（vs s1，取最灵敏的两个阈值）

| 阈值 | s1 | 对照 | 对照到达 | p |
| ---: | --- | --- | --- | ---: |
| 1,500 | 12/15 | 左墙守卫 | 5/15 | **0.0253** |
| 1,500 | 12/15 | W2 | 11/15 | 1.0 |
| 1,750 | 10/15 | D2 | 0/15 | **0.0002** |
| 1,750 | 10/15 | W2 | 2/15 | **0.0078** |
| 1,750 | 10/15 | 左墙守卫 | 1/15 | **0.0017** |
| 1,750 | 10/15 | s3（同配方复训） | 0/3 | 0.0686 |
| 1,750 | 10/15 | s2（同配方复训） | 1/3 | 0.528 |

- **对"不同配方"的对照**（D2 / W2 / 守卫）：1,750 阈值给出 p ≤ 0.008。
- **对"同配方复训"**（s2 / s3）：p = 0.53 / 0.07 —— **仍然分不开**，尽管 0/3 vs 10/15 看起来差别很大（n=3 太小）。

## 3 这意味着什么

| 用途 | 离散判分是否够用 |
| --- | --- |
| 比较**大改动**（DAgger 注入、守卫、将来的 RL） | **够用**：1,750 阈值下 p ≤ 0.008，且不依赖帧数分布 |
| 比较**同配方的训练种子** | **不够**：0/3 vs 10/15 也能 p=0.53（n=3），需要每配方 ≥3 训练种子 × 多环境种子 |
| 作为**阶段 3 的里程碑**（"到达首 boss 2,936"） | **适合**：0/15 → n/15 是清晰的事件跃迁 |

**所以建议**：把"到达 1,750 / 2,000 / 2,936" 作为**主判分**（而不是均值帧数），但**同配方对照必须跑满 3 个训练种子**。

## 6. 不能声称什么 · 偏差清单 · 合规

### 6.1 不能声称什么

1. **不能声称 P1 成立、不能声称「蒸馏成功」**：15.5000 % < 19.4444 %，且 P2 的达成率只有 20.10 %。

3. **不能声称「把 R5 的分段形状蒸馏进去了」**：60 px / 40 px 两段**零训练行**。本轮蒸馏的是「80 px 段」，而它在这批态上近乎常数。
4. **不能把本轮当「纯学习结果」**：一半监督来自**手写规则先验**（R5 80 px）。它与 v8.3.0 的纯反事实标签策略**不是同一类对象**，不能混谈，也不能用作「学习能力」的度量。
5. **不能声称「辅助损失把放雷提前到决策 73–130」**：盘上不可复现。三档 `first_bomb_decision` 中位数都是 **0**（600 档只有 1 条 episode 在决策 1），honoured 首放也在决策 0。真实差别是**第 3 颗 honoured 中位 186 → 206（更晚）**与**按键率下降**。（这条是该说法来自某次中途快照的观察，本文件以实测为准。）
6. **不能写「20 s ≈ 8 %」**：v8.6.0 预注册里是这么写的（见 §6.2 第 3 条），盘上是 **15.5000 %**。
7. **不能声称通关 / 整面**：单锚点段（PARK frame 8,663），300/600/900 决策 × 2 帧。
8. **不能把 3,600 条当独立样本**：4 个窗口是固定效应（w12 在 900 档 0/900）、3 个种子是固定效应；12 个 (seed, window) 格也不是独立样本（预注册 §5 同此）。

### 6.6 一句话交接

**这一轮把「规则监督」这件事测清楚了：监督确实进了 bomb 头（98 % 吻合），但因为冻结标签集的 `bombs_remaining` 恒为 3，实际进模型的只有 R5 的 80 px 一段——它在 76.9 % 的态上本来就成立。于是 20 s 从 19.44 % 掉到 15.50 %（p = 5.94e−06，CP95 [14.33, 16.72] %，**P1 不成立**），30 s 从 0.61 % 升到 2.81 %（**4.59 倍**，p = 8.8e−14），10 s 不动；行为上首雷仍在决策 0，只有第 3 颗晚了 20 个决策、按键率降到三分之一。按预注册的判定式这触发 `S-fail`，但它的机制措辞「规则监督与反事实标签冲突」只对 20 s 成立。要让「分段规则」真的被蒸馏，唯一的路是先让训练态覆盖 `bombs_remaining ∈ {2,1}`——这正是 v8.6.0 的 P0。**

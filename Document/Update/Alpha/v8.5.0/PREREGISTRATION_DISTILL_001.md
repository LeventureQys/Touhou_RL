# 预注册 v850-DISTILL-001：把 R5 规则蒸馏进 36 动作策略（规则监督 + 反事实标签联合训练）

冻结时刻：2026-11-22（Asia/Shanghai），**在任何 v8.5.0 训练之前**。
状态：**FROZEN**。

---

## 0. 现状与要解决的问题

| 段长 | 不放雷 | 80 px 规则 | **R5 分阶段规则（80/60/40）** | 36 动作策略（纯反事实标签） |
| --- | ---: | ---: | ---: | ---: |
| 10 s | 13.44% | 100% | （按定义同 100%） | **99.94%** |
| 20 s | 0.17% | 71.11% | **77.05%**（+5.94 pp，p=5.1e-09） | **19.44%** |
| 30 s | 0% | 13.33% | **19.38%**（n=970，收尾中） | 0.61% |

- 纯反事实标签（H=120）学到的是「放雷永远不差」，于是开局就把三颗雷打光。
- **R5 的规则**说明了正确形状：**第一颗早放（80 px）、第二颗更严（60 px）、第三颗最严（40 px）**。
- 但规则是写死的、不含「候选方向」的选择；策略才是能同时决定「往哪躲 + 何时放雷」的东西。

⇒ 本轮把**规则作为额外监督**，与反事实标签**联合**训练，目标是**同时拿到规则的放雷时机与策略的躲闪能力**。

---

## 1. 设计（单因子：训练目标里加不加规则监督）

| 项 | v8.3.0 | **v8.5.0** |
| --- | --- | --- |
| 动作空间 | 36（18 候选 × bomb） | **不变** |
| 反事实标签 | 5,166 状态 × 36 路，H=120 | **完全复用**（不重采） |
| **新增监督** | — | **bomb 头的规则监督**：对每个状态，用 R5 规则（按 `bombs_remaining` 取 80/60/40 px）算出「该不该放」，作为 bomb 头的额外 BCE 目标 |
| 损失 | `BCE(36 路)` | **`BCE(36 路) + λ · BCE_bomb(规则)`**，**λ = 0.5**（预先固定，不做扫描） |
| 训练 | Adam 1e-3、batch 256、200 epoch、3 种子 | **不变** |
| 评测 | 300/600/900 决策 | **不变** |

> **为什么 λ 先固定 0.5**：本轮只回答「加规则监督是否有用」，不回答「λ 多少最好」。λ 扫描留给下一轮（若 S-ok）。

## 2. 判据

| # | 终点 | 判据 |
| --- | --- | --- |
| **P1（主）** | **600 决策（20 s）活满率** | **> 19.44%**（v8.3.0 的纯标签策略）；单侧 Fisher + CP95 |
| **P2** | 与 **R5 规则（77.05%）** 的差距 | 报差距；**≥ 70%** 才算「蒸馏成功」 |
| **P3** | 300 与 900 决策 | 与 v8.3.0（99.94% / 0.61%）及 R5（100% / 19.38%）并排 |
| **P4（描述）** | 放雷行为：用雷分布、首次/末次放雷决策、雷耗尽比例 | 只报 |

### 2.1 停止条件

| # | 条件 | 动作 |
| --- | --- | --- |
| **S-fork** | 保真门失败 | 整轮作废 |
| **S-ok** | P1 与 P2 都成立（≥70%） | 判「蒸馏成功」；下一轮做 λ 扫描（0.2 / 0.5 / 1.0）并把段长推到 1,200 决策 |
| **S-partial** | P1 成立但 < 70% | 判「规则监督有用但不够」；下一轮**只用规则监督训练 bomb 头**（候选头冻结在 v8.3.0），即二元放雷头方案 |
| **S-fail** | P1 不成立 | 判「规则监督与反事实标签冲突」；下一轮改用**两阶段**：先按规则训 bomb 头、再冻结它训候选头 |

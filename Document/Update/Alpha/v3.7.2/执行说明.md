# v3.7.2 执行说明与后续能力验收

## 已实现的网络关系

```text
真实画面因果历史 → 原 v3-st（冻结） → 256维视觉特征
                                      ├ 原18类logits ──────────┐
                                      └ 路线方向头 → 宏观残差头 ├→ 最终18类动作
                                                             ┘
```

路线头预测值参与残差网络输入，不是只在训练时计算一个无关辅助损失。推理没有弹池、未来真值、教师路线输入。旧网络权重与 checkpoint 格式不改，附加头使用独立 sidecar 并绑定基座 SHA256。

**区别于本次审核中发现的问题：** 宏观监督直接作用于最终动作概率，教师检查完整逐帧路径，不再仅依赖 intent 标签或粗格首次占用时间作为路线证明。但是，这还没有证明冻结视觉特征足以学习该能力。

## 教师与数据口径

- 教师默认90帧完整逐帧检查，包含输入沉降、边界、自机与危险几何；空间分支保留有多样性。
- “存在一条90帧存活路径”不能单独教会提前撤离：如果18个首动作都有后继，正例集合损失没有方向偏好。
- 为此支持调用者声明安全目标与到达截止时间：在截止前进入目标半径，并有路线活到规划终点；目标可靠性与截止标定仍需外部参考/人工审查，不由粗closure自证。
- 未找到路线≠真实无解；不做“所有未见证动作是必死”的BCE监督。unknown/budget不产生硬负标签。
- 当前线性外推条件下的路线见证只对该模型成立，不承诺未发弹、转弯/加速弹的未来。
- 不直接用旧64弹截断archive伪造完整弹池。正式paired格式必须有完整hazard offsets、coverage_complete与model_known，且来源元数据区分real_pixels和synthetic_pixels。

## 离线使用

先从已审查的真实画面与完整同步弹池建立paired archive；具体字段和归一化见 `python -m touhou_rl.macro_cache --help` 及模块docstring。现有旧archive不能直接改名当paired archive。

```powershell
python -m touhou_rl.macro_cache --paired paired.npz --baseline third_party/th08/build/rl/runs/v104-v3-E5-s7/policy.pt --out macro-cache.npz
python -m touhou_rl.macro_train --cache macro-cache.npz --baseline third_party/th08/build/rl/runs/v104-v3-E5-s7/policy.pt --out runs/v372-macro --epochs 30
```

训练按episode/template分组划分，校验基座SHA及cached logits和特征一致性。仅在显示标记的`local_valid`样本做KL保持，不把未知样本强行当安全回归标签。新增附加头不会改动旧骨干；训练输出不是自动部署批准。

## 显式部署入口

```powershell
python -m touhou_rl.evaluate --vision-checkpoint third_party/th08/build/rl/runs/v104-v3-E5-s7/policy.pt --macro-checkpoint runs/v372-macro/epoch-001.pt --episodes 1 --out runs/v372-eval
```

以上是接口示例，须使用训练报告选出的实际epoch路径。默认没有`--macro-checkpoint`时保持原部署；附加头启用时明确不混用旧EMA/hysteresis。示例会启动游戏，仅在允许前台游戏输入时运行；本次尚未执行。

**严禁将 evidence 下人工随机特征冒烟权重当成游戏训练结果部署。** 冒烟只验证加载真实基座、初始化等价、梯度/分组训练、落盘与加载链路。

## 继续工作的严格顺序

1. 审查可达目标/截止标签：先通过“脚下安全但必须立即横移”的参考场景，不只生存正例。
2. 采集/整理完整同步paired像素数据：至少含提前撤离、局部诱惑、撤离返身、窄缝、空场与局部避弹回归，模板种子族不跨切分。
3. 真实像素离线学习，报告原模型对照、留出组、撤离提前量及局部回归；如果冻结特征无法学习，报告失败而不是扩大为骨干已优化。
4. 真机前先沿用v3.7.1共同输入和实际逻辑帧协议，网络与基座对照只改变附加头，shoot/bomb保持不变。
5. 同时验证动作、输入生效、延迟、首死和死亡数；最终能力状态只能由结果决定。

## 当前完成边界

完成目标是“小版本建立及策略正式网络接入”，不是声称“已训练出更强模型”。工程、教师受控测试、真实像素训练、真机改善分开结算。真实像素训练与公平真机改善目前均为`not_run`，不覆盖旧默认模型。

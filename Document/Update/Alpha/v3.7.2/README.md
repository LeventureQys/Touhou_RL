# v3.7.2 小任务：宏观可行走廊与现有网络接入

## 目标与边界

保留现有 v3-st 视觉骨干及旧 checkpoint，不将 v3.7.0 小型合成 CNN 当作当前正式视觉网络。新增可独立启用的宏观策略接入：训练时以经过逐帧验证的路线为监督，推理时只读取现有网络像素特征和网络输出。旧部署默认行为不变。

本版不承诺仅通过软件接线就取得真机死亡率改善；分别验收工程接入、受控行为、真实像素学习及真机效果。不得把合成特征拟合写成网络已掌握真机弹幕。

## 最小工作包

1. **M1 宏观教师**：独立模块，使用实际移动模型、输入沉降及逐帧危险检查；保留不同空间分支。输出可验证的正例路线、首动作见证集合、覆盖/未知状态。有限 beam 未找到路线不等于真实无解，不作为负标签或硬 veto 依据。未知、裁剪、超预算不制造安全承诺。
2. **M2 网络正式接入**：在现有 v3-st 的 frozen features / policy logits 上新增小型宏观残差与目标头，初始化严格保留旧动作；不改变旧模型 state_dict。路线监督必须影响最终 candidate logits，不能只有辅助头。
3. **M3 训练与落盘**：提供离线 feature-cache 训练入口、分组切分、checkpoint 身份校验和推理 loader。缓存来源必须注明真实像素或合成；没有真实像素训练证据不得默认接管旧部署。
4. **M4 验证**：原模型等价性、梯度到新增头不污染骨干、路线监督确实改变最终动作、未知标签不训练、动作编码不变、保存/加载复现、宽幅弹幕/过渡碰撞/边界/未知专项。

## 行为门禁

- 脚下安全但前方宽幅弹幕会封路：验证实际路线，不看 intent 标签。
- 有可靠绕行时，不能仅因为近端 clearance 较大而把所有绕行分支剪掉。
- 未找到路线必须报 unknown/budget，不把未知当不可行。
- 局部碰撞为硬约束；不能为宏观收益穿过子弹。
- Shoot/bomb 不由宏观网络另行改变。

## 效果门禁

- 工程 pass 不等于能力 pass。
- 训练缓存按完整 episode/template 分组，不逐帧随机拆分。
- 真实像素学习：与同一 backbone checkpoint 的原 logits 比较，报告留出集及局部回归，不只训练集准确率。
- 真机验证沿用 v3.7.1 公平输入/逻辑帧协议；没有正式结果就保留 `not_run`。
- 在没有合格教师及真实像素配对数据时，交付可运行代码和清楚的后续采集接口，不伪造 checkpoint 效果。

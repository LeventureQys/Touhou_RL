# 预注册 v8180-EARLYBOMB-001：在**死亡前 60–120 帧**采样，学「提前放雷（1 颗/次）」而不是「死亡炸弹（2 颗/次）」

冻结时刻：2026-11-22（Asia/Shanghai），**在任何 v8.18.0 采集之前**。
状态：**FROZEN**。

---

## 0. v8.17 把问题定位到了「时机分辨率」

v8.17 的两面：

| 侧 | 结果 |
| --- | --- |
| 标签 | ✅ armed 100%、**diff 98.0%**（首次表达雷的价值） |
| 评测 | ❌ 20 s **14.1%**（比 v8.6 的 29.58% 更差） |

**原因**：v8.17 的 600/600 个状态 `player_state` 全是 **`DYING`**（死亡动画内），在那里按雷 = **死亡炸弹**，引擎**一次扣 2 颗**（3 → 1）。

| 用法 | 每次代价 | 3 颗雷能救命几次 |
| --- | ---: | ---: |
| 提前放（R5） | **1 颗** | **3 次** |
| 死亡炸弹（v8.17） | **2 颗** | **1 次** |

⇒ **标签的时机分辨率决定学到哪种策略**。要学到「1 颗/次」，必须采**更早的状态**。

## 1. 设计（单因子：采样相对死亡的**提前量**）

| 项 | v8.17 | **v8.18.0** |
| --- | --- | --- |
| 行为策略 | `S` + **不放雷** | **不变** |
| 采样位置 | 死亡前 **20 决策（40 帧）** | **死亡前 60–120 帧**（即 `decisions_before_death ∈ [30, 60]`） |
| 每状态标签 | 36 路 × H=120/240/600 | **不变** |
| 目标状态数 | 600 | **600**（36 条死亡 episode × ~17 个状态/条） |

> **关键预期**：在死亡前 60–120 帧处，玩家**还活着（ALIVE）**，此时按雷是**普通放雷（扣 1 颗）**，而 `bomb=0` 会在 H 内死 ⇒ `diff > 0` 且 **`bombs_before − bombs_after == 1`**。

## 2. 判据

| # | 终点 | 判据 |
| --- | --- | --- |
| **P0a** | 状态是否还在 ALIVE | `player_state == ALIVE` 的占比 **≥90%** |
| **P0b** | 是否带雷 | `bombs_remaining > 0` 占比 **≥50%** |
| **P0c** | **扣雷是 1 颗** | `bomb=1` 分支 honoured 的样本里，**`spent == 1`** 的占比 **≥90%**（这是与 v8.17 的判别式） |
| **P0d** | 标签是否有差异 | `best bomb1 > best bomb0` 占比 **≥20%** |
| **P1（主）** | 臂 B 的 600 决策活满率 | **> 19.44%**（v8.3.0），并**必须 > 14.1%**（v8.17）才说明「提前放」优于「死亡炸弹」 |
| **P2** | 臂 A | 与 B 并排 |
| **P3** | 用雷分布 | **出现「只用 1–2 颗」的 episode**；且**平均用雷 < 3.00** |
| **P4** | 900 决策 | 与 v8.3（0.61%）、v8.6（2.94%）、R5（17.61%）并排 |

### 2.1 停止条件

| # | 条件 | 动作 |
| --- | --- | --- |
| **S-dead** | P0a 不成立（状态已是 DYING） | 采样窗再前移（30–60 → 60–120 决策）；并在 RUN.md 记录死亡检测滞后的实测帧数 |
| **S-2bomb** | P0c 不成立（仍是扣 2 颗） | 判「死亡检测滞后超过预期」；改为**按 `player_state == ALIVE` 过滤**而不是按 `decisions_before_death` |
| **S-nodiff** | P0d <20% | 判「提前 1–2 秒放雷在 H=120 内也救不了」；**这是「雷只能救命于死前一瞬」的硬证据**，本线收束 |
| **S-ok** | P1（>19.44% 且 >14.1%）与 P3 成立 | 判「时机分辨率是关键变量」；下一轮扩到 5,000 状态并做提前量扫描（30/60/120/240 帧） |
| **S-fork** | 保真门失败 | 整轮作废 |

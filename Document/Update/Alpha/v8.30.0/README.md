## 本次路线调整

近期问题从“哪套放雷配置更好”调整为：**在一个真实短攻击任务族中，合法动作能否完成任务，当前观测能否提供控制价值，像素策略能否学到这种价值。** 任务以实际阶段完成及资源后果为目标，首死时间和截断存活用于诊断；正常残机和合法资源使用沿第一面任务定义。

推进链为 R0 路线设计 → R1 冻结真实任务与契约 → R2 同任务可解性、像素接线与小规模学习/反馈判别 → R3 未见祖先 → R4 连续资源、提前接管和自然开局开发 → R5 原正式验收。有可运行像素候选后，少量自然开局开发诊断即可提前开展，不必等短窗优化全部结束。

上一稿的旧资产全面盘点、96 局 G1/T2 配对、60 回合 RL 初始化对照及大批未来 CLI 清单均撤出近期默认排程。相关局部协议仍保留身份和证据范围；是否启用由新路线结果决定，不能因为文件或命令已经写好就执行。

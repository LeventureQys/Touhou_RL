# 研究路线复核与方向决策

2026-11-24，v8.30.0 第二稿。当前应修正的是主问题与投入顺序：把真实任务中的像素闭环学习作为主线，把 BC 损失修正、放雷规则排名和局部标签作为辅助诊断。这个方向已完成研究端设计取舍，仍须通过小规模路线判别验证可行性；不能称为路线已经被实验验证。

用户要求先分析路线，再安排确认工作。因此上一稿的 V830-INFO-01 全量盘点、BC/G1T2 首批和 RL 初始化预算均撤出近期排程，保留为条件性备选。当前不派发训练或批量确认，不恢复 WP05。本页优先于本版本其他文件的旧执行顺序。

## 从最终目标反推必要证据

最终目标要求 actor 只从框内画面与自己的执行历史决策，在自然开局、标准资源、正常残机下完成第一面，并接受真实 Windows 复验。首死存活是诊断；第一面允许正常使用生命和资源。训练期特权、像素执行、严格像素自我改进是不同能力，分别验收。[正式目标及任务定义](../v4.1.0/README.md)

要支持这条目标链，至少需要知道：同一任务在合法动作下可解；在线观测相对预定动作确实提供控制价值；像素策略能学到这种价值；它能迁移到未见起点；连续执行时不依赖教师起点、资源重置或记忆重置；最后才是自然第一面与正式确认。当前大量证据集中在标签、特权微段和仪器，后面的连接尚未成立。

## 五项路线问题

| 结构问题 | 项目证据与可作判断 | 路线处理 |
| --- | --- | --- |
| 局部监督目标没有保证整段价值 | v8 的 H=120 标签中放雷从不更差，而失去库存的代价落在更后面；旧 WP05 还有大量动作打平。它们说明特定标签可能遗漏代价或强迫任意选择，不等于所有监督学习都失败 | 短视分支标签降为局部风险/辅助监督；只有能改善同任务闭环结果时，才成为主训练目标 |
| 微段生存与第一面完成没有接通 | v8 从未评估 Boss 击杀；G1 使用已知剩余预算，20/30/40 秒又是不同预算策略。无死亡微段和允许正常残机的 S1N 是不同任务 | 主研究采用真实攻击阶段完成及资源后果；固定时域存活保留为诊断，不单独承担通关选模 |
| 特权成功到像素学习之间存在未经验证的跨越 | 隐藏 PLAYER_HIT 可触发教师反射，像素学生未必有同样先兆；旧 power 裁剪遗漏也说明输入契约会改变问题。teacher 很强不能直接证明 teacher 动作可视觉模仿 | 像素 actor 尽早进入同任务实验；特权控制器用于可解性和故障定位，不再要求先把特权路线全部做完 |
| 尚未证明当前学习器依赖反馈获得实用收益 | 历史 A 的均值 94.1 决策，训练选定固定动作 #12 的四窗均值 172.375；这不证明反馈无用，但说明只胜随机不能说明已经学会控制。G1/T2 只更换放雷规则，也不回答这个问题 | 用强的可部署固定/开环参照，与闭环同任务比较；先判断信息和学习是否带来增益，再扩大确认 |
| 恢复起点与自然来访状态之间有分布断层 | 课程原设计已要求提前接管和资源继承，但尚无连接后的能力证据。独立恢复时每段补足三颗雷，不能推出连续对局可行 | 局部学习一旦有信号即提前接管、连续继承；自然开局的抵达率从早期就做开发诊断，不等所有短窗优化完成 |

证据入口：[v8 短视标签及代价](../v8.13.0/SYNTHESIS_BOMBLINE_2026-11-22.md) §3、§46.6；[教师可视觉学习性](../v4.1.0/README.md) §2.2、WP02；[A 历史结果](../v4.3.1/evidence/R38/n80.json)；[固定动作参照](../v4.3.1/evidence/R51/baseline_ladder.json)；[课程与自然来访状态](../v4.4.0/RESEARCH_PLAN.md)。这些是历史记录与研究端推断，不是新实机结果。

还应收窄旧负结果的含义。v4.2 后续审计发现早期过关动作/裁判存在缺陷，当时的 0/N 不能直接概括算法能力；其后 §10.8 已用修复后的仪器重测四臂、两口径共 160 局，仍为 0 过关，这是该批配方的有效负结果。A1 集合损失的负结果也只约束该形式和规模。仪器修复没有取消有效负结果；多次配方失败也不能相加成为整个方法“不可能”的证明。[v4.2 最终限定](../v4.2.0/ROUTE_CONCLUSION.md) §9.3、§9.7、§10.8

## 主路线与备选路线的取舍

| 候选路线 | 适用条件与当前不足 | 本次决定 |
| --- | --- | --- |
| 原 BC/DAgger 配方继续扩大 | 只有标签表达任务价值、学生可从可见历史预测有用动作且闭环获益，扩大覆盖才有依据；这些前提仍有缺口 | 原配方继续暂停。BC/DAgger 作为可验证的初始化或辅助数据方式保留，不作为必经主干 |
| 自然整面、纯像素、长时域 RL 直接扩大 | 观测、反馈、优化、探索和任务接线同时变化，失败难定位；当前没有已证明的可学习起步任务 | 暂不进行长期训练或扩大预算；也不据旧失败否定 RL |
| 同一真实任务上的像素闭环学习与逐级课程 | 从小任务族开始，actor 从一开始受部署输入约束；用特权参照定位可解性、观测和优化问题，随后验证未见与连续执行 | **选为下一阶段主路线，先做小规模路线判别** |
| 像素感知模块接既有状态控制器 | 可提供定位/危险估计和控制接线参照；误差传播及状态控制器本身的能力仍须测量 | 保留为可部署参考和诊断桥梁，不预设优于直接像素 actor |
| G1/T2 规则优化、分层放雷或更复杂网络 | 可以研究资源机制，但单独胜出不能回答像素学习和整面完成问题 | 固定当前规则为参照；不列入主线首批，除非路线判别定位资源调度是限制 |

选定的是任务、信息与验证结构，不是宣称某个优化器必胜。训练以真实任务完成与其合法后果为目标；可采用训练期特权回报、价值估计或辅助标签帮助像素 actor。是否更换现有学习器、加入记忆或不对称 critic，由同任务诊断决定，不同时更换全部组件。使用特权回报的结果只支持像素执行候选，不能充作严格像素自我改进。

三条外部方法依据只用于约束推断：DAgger 针对学习者来访分布，其保证有学习问题的附加条件，不能替代本项目的标签和可观察性验证；不对称 actor-critic 提供了训练期 critic 用状态、actor 用图像的一种实现先例，不证明在 TH08 必然有效；时间限制研究区分真正有限时域任务与训练截断，支持本项目单独处理微段预算和整面目标。[DAgger 原论文](https://proceedings.mlr.press/v15/ross11a.html) · [Asymmetric Actor Critic 原论文](https://arxiv.org/abs/1710.06542) · [Time Limits 原论文](https://proceedings.mlr.press/v80/pardo18a.html)

## 新的推进链

```mermaid
flowchart LR
    A[同一真实任务与输入动作契约] --> B[可解性诊断与像素小学习]
    B --> C[冻结候选后判别反馈价值]
    C --> D[未见起点与阶段]
    D --> E[连续继承与提前接管]
    E --> F[自然第一面与正式确认]
```

可解性诊断、像素接线和小学习可以在同一切片内协同推进，不以旧 A 或特权臂先证明反馈收益作为像素学习的前提。小学习后冻结候选，再检验反馈价值；不要求先训练出能通关的特权学生。HUD/自机定位/死亡事件按所需最小范围推进。严格像素奖励与重开仍按 WP06/G410-3 独立验收，不能为了它推迟所有允许特权训练的像素执行研究。

### R1 冻结一个能判断路线的小任务族

优先使用现有来源中的短攻击阶段，以实际阶段完成、合法转场或明确任务事件为目标。阶段选择先在训练材料和脚本元数据上完成，再冻结开发起点；不得根据候选的新成绩筛容易窗。各起点保持相同机体、射击、动作保持和资源语义。

该任务须有同动作约束的真实成功见证。允许缩减动作空间作诊断，但若 18 动作/禁 bomb 不可解，不能因此否定允许 bomb 的完整游戏任务；应恢复所需合法动作并重新登记任务。放雷如依赖特权距离或库存，相关臂仅为特权/混合参照，不标纯像素 actor。

在训练侧已有成功/失败轨迹上先检查任务事件和回报的区分度，包括完成事件是否仅按时间自动发生、控制是否能改变后果、当前候选多久能获得一次有效事件。完成事件是任务定义，阶段转场本身不证明反馈价值。若小预算内完全没有有效正例或区分信号，先调整训练起点、可解任务范围或探索支持；不盲目扩帧，也不默认加入密集奖励就解决问题。任何辅助奖励需独立检查与真实任务后果的一致性。

固定动作能通过个别窗口不使任务无效；它提醒我们比较整个任务族与强参照。若冻结参照已解释全部表现，当前任务不足以判断观测收益，应在训练材料上设计新的任务族，再冻结新开发样本。不能事后要求全部固定动作在每个评估窗都死亡。

### R2 用同任务对照区分控制、观测与学习

第一批只要求一个完整的真实像素输入到动作、终态链路和受限学习试点。使用同一任务目标、动作节拍、资源和计分，对比学习前后像素策略及训练材料选定的可部署参照。特权教师/控制器单列为可解性参照；必要时加入同任务状态学习臂诊断，不把旧 A 或旧 G1 成绩当作新任务上限。

检查反馈价值时，开环动作表只来自独立训练供体并在目标局前冻结，不能使用目标闭环局已经成功的动作序列。对照应尽量保持动作频率、持续时长与采样安排；若开环质量不足，不能把它的失败直接解释为反馈收益。共同使用特权放雷规则的 live/open 只识别该规则条件下的移动反馈价值，不能证明像素端到端控制。

学习的验收是冻结任务上同预算、同评测安排的行为改善，不能用 loss 下降或单段过拟合结算控制能力。初次单 seed 只作调试与可行性观察；复训稳定性另用多个训练 seed，独立确认再用全新祖先。先核算一个端到端回合的墙钟、受控帧、恢复、渲染和存储，再冻结试点上限，撤销上一稿把 60 回合/96 局列为近期默认的排程。

### R3 至 R5 再扩大结论范围

局部学习出现可复现信号后，先检查未见起点，报告每祖先与阶段的效果。随后连续执行相邻阶段，保持资源与记忆自然继承，提前接管并记录入口抵达率和抵达后完成率。一旦有可运行像素候选，就安排少量自然开局开发诊断，确定最早失败阶段；这不是消耗正式确认集。

自然第一面候选达到原提名条件后，才进入 S1N 100 局、Windows 至少 20 局的原正式确认。原门和保留样本用途不变。具体规模由小试点实际差异、祖先供给与算时确定，不能从历史四窗的重复回合数推导泛化把握。

## 什么结果会让主路线改变

| 观察 | 约束的解释 | 下一项决策 |
| --- | --- | --- |
| 同约束真实见证也无法完成 | 当前任务、动作契约或驱动可解性未建立 | 先修任务与执行；不归罪于像素或学习算法 |
| 冻结固定/开环参照已解释全部成绩 | 该任务或该候选尚未显示反馈价值 | 检查任务族和对照质量；不扩确认同一弱假设 |
| 状态控制有效、像素接线正确但像素学习失败 | 观测覆盖、历史/记忆、表示与优化仍是竞争解释 | 用局部状态预测/可见先兆及单因素表示对照区分；不直接断言像素不可观察 |
| 局部拟合有效、未见起点失败 | 当前能力限于训练分布 | 增加独立任务阶段、来访状态与记忆研究，暂不整面长训 |
| 各恢复段有效、连续运行失败 | 接缝、资源和自然来访状态未覆盖 | 针对连续执行训练与提前接管；不在每段重置资源掩盖失败 |
| 新祖先、连续执行、自然开局均改善 | 主路线在该范围获得支持 | 冻结候选，再安排正式能力确认 |

因此，当前可以确定的是：原计划必须调整主问题，BC 修正和规则排名不足以承担主线。尚未确定的是：具体任务上的像素学习能否产生足够收益，以及瓶颈最终落在观测、目标还是优化。下一步用小规模路线判别回答这些未知，而不是先批量确认旧代理指标。

## 1. 两臂与冻结项

| 项目 | L0：复现旧目标 | L1：与部署一致的目标 |
| --- | --- | --- |
| 损失 | `BCEWithLogitsLoss(z[:,1], y.float())` | `CrossEntropyLoss(z, y.long())` |
| 推理 | 两输出 softmax；离线分类按 argmax | 完全相同 |
| 等价核验 | 记录其不满足共同 logit 平移不变性 | 与 `BCEWithLogitsLoss(z[:,1]-z[:,0], y)` 数值及梯度相等 |

两臂同为 `Linear(109,64) → Tanh → Linear(64,2)`，输入为当前冻结的 106 维观测与同版本三项显式特征。每个 seed 从同一个原始 `state_dict` 克隆为两臂，逐参数初值哈希相同；优化器均从空状态新建。seed 为 **0、1、2**，同 seed 使用同一训练表、相同 200 个 batch 的有序行号和相同执行顺序，不让一臂的随机数消费影响另一臂。

保持研究端源码 `v8u0_features.py:198–208` 的预算：**200 更新步、batch 256、每 batch 128 正/128 负、Adam lr=0.01、梯度裁剪 1.0**；Adam 其它参数沿冻结 PyTorch 版本默认值并在清单中展开登记。样本索引生成方式沿旧实现的有放回正负采样及 `random.Random(seed*1000+7)`，先生成一次并保存摘要，两臂共用。禁止同时改架构、表示、特征、采样比例、优化器或训练步数。

正例过采样为 50% 可能使概率偏离自然状态分布的正例率。本轮保持该因素不变；在自然分布留出表上记录偏差，不另外做阈值选择、温度缩放或先验修正。若以后修正，另编号并用新的校准数据。改变到“总 batch 128”也是额外预算变化，不属于本单。

## 3. 先验实现验收

拟新增模块为 `touhou_rl/v830/bc.py` 与 `audit.py`，入口 `tools/rl/v8_30.py`，必要数学测试为 `tests/test_v830_bc.py`。不改旧 runner 或旧证据，不新增依赖。以下检查必须能在不启动引擎、不加载训练资产时运行：

- 任意共同 logit 平移后，L1 的 loss、softmax 概率与梯度不变；L0 保留用于证明不等价的反例。
- 对 y=0/1、多组有限 logits，双类 CE 与 margin BCE 的 loss、两输出梯度一致；用有限差分交叉核对。检查目标不是错误的单独 `z1`。
- 旧目标对 `z0` 的直接梯度为零，一致目标的两类梯度和为零；实际两输出层梯度与解析式相符。共享隐层变化不误写为 `z0` 永久不变。
- 两臂初始参数逐位相同、batch 行号序列相同、标签 dtype/shape 正确；拟合与校准祖先无交叉且不触碰 v8.29 新祖先、保留家族或封存资料。
- 极端 logits 的数值稳定性、CPU 可复算性，以及输出缺失、身份不同、单类数据、无有效分母时明确失败。浮点容差随 dtype 冻结并输出，不能运行后放宽。

## 4. 离线克隆：先 seed0 冒烟，再完成 3 seeds

seed0 先在临时副本跑 1 个 batch 检查参数、标签、有限 loss/梯度和产物身份；这一步不按学习好坏筛选。预检副本随后弃用，不改变正式初值、优化器、RNG 或 batch 索引。实现门通过后，对 0/1/2 各自从冻结初态跑恰好 200 步 L0/L1，正式 seed0 不继承预检更新。保留每 20 步及末步的 loss、实际部署概率指标、梯度范数和参数摘要。L0/L1 各自训练损失的定义不同，不能把两者 loss 数字直接当优劣比较。

训练表与留出校准表分开报告，均按自然分布、全行计算：混淆矩阵、正例 precision/recall/F1、PR 曲线及其算法冻结后的 AUPRC、放雷率、平均 `P(bomb)`、平均 `P(bomb)-y`、MAE、Brier 分数及固定分箱校准表。无正例时 PR/F1 标不可判并报告分母，不能填 1。两臂逐 seed 差值和逐祖先差值全部保留，独立样本单位按祖先报，不能把逐帧行当独立样本求泛化 p 值。

另按库存 B=0/1/2/3/>3 和 `distance-threshold` 分层；阈值附近分箱预先固定为 `<-5`、`[-5,-1)`、`[-1,0)`、`[0,1)`、`[1,5]`、`>5` px，无距离另列。对精确等阈值、刚内/刚外、B=0、B>3、无子弹做边界单元验收。自然状态覆盖不足时明确列空格；离线构造边界只检验实现，不充真实轨迹。

**研发建议的推进门，尚非经验结论：**L1 在至少 2/3 seeds 的留出 Brier 和标签不一致率均优于 L0，第三 seed 不出现超过 5 个百分点的不一致率恶化，才提名真实克隆扩展；若校准祖先不足则仅可批准实现冒烟。该门用于分配预算，不证明所有历史失败的原因。指标方向相反或均无改善时，保留失败并检查覆盖、类别重采样和训练可拟合性，不启动长期 RL 来掩盖问题。

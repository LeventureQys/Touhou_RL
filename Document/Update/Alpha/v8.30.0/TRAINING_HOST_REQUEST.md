## 可直接使用的只读命令

在实际运行检出根执行下列身份命令，分别保留退出码。它们只说明当前主机与源码身份，不证明历史运行或任务能力。

```bash
git rev-parse --show-toplevel

git status --short --untracked-files=no
python -B -c "import sys; from datetime import datetime; print(sys.executable, sys.version.split()[0], datetime.now().astimezone().isoformat())"
```

需要核对小清单或日志是否仍在时，可以使用下面的标准库元数据命令。实际运行前，只把参数替换为上表既有索引已明确指向的精确文件；不用通配符，不自行递归定位，不读取整个大文件。已有清单中带 SHA 的直接引用并注明清单日期，不为本轮重新哈希数据集或引擎资产。

```bash
python -B - '已登记的精确文件路径' <<'PY'
import json
import sys
from pathlib import Path

failed = False
for name in sys.argv[1:]:
    path = Path(name)
    try:
        stat = path.stat()
        print(json.dumps({"path": str(path), "is_file": path.is_file(),
                          "bytes": stat.st_size, "mtime_ns": stat.st_mtime_ns},
                         ensure_ascii=False))
    except OSError as error:
        failed = True
        print(json.dumps({"path": str(path), "error": str(error)}, ensure_ascii=False))
raise SystemExit(int(failed))
PY
```

现有记录只摘回答六项所必需的小段，给原文件身份、行号或 episode，缺失字段保持缺失。无原始记录时，报告“仅历史摘要”；不执行旧版四 runner 前向探针、24 文件批量核对或任何新游戏验证。

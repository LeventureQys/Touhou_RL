# 04 阶段计划

- 读者：执行 Agent。
- 用途：总览所有阶段、工作包（WP）、门、时间盒和依赖关系。工作包的细节以各阶段的规格文件为准；进度记录在 [任务清单](<任务清单.md>)。

---

## 1. 依赖图

```text
P0 训练场 ──G0──┬──► P1 搜索教师 ──G1──┐
                │                      ├──► P3 像素学生 ──G3──► P4 自我改进 ──G4──► P5 留出适应 ──G5──► P6 第二作
                └──► P2 感知与回报 ─G2─┘                         (A 专家迭代 ‖ B 像素回报 RL)
```

- P1 与 P2 都只依赖 G0，可以并行。
- P2 的数据生成在 P1 的教师可用之前，先用 `random`、`still` 以及"人类回放快进"三种来源；教师可用之后，再补充教师轨迹。
- P4 的循环 A 和循环 B 可以并行。
- **门不过，就不进入依赖它的阶段。**

## 4. 门判据摘要

完整判据以各规格文件为准，这里只列摘要：

| 门 | 判据摘要 |
|---|---|
| G0 | 回放 108/108 逐位一致；快照恢复逐位一致；渲染观测 ≥ 2,000 帧/s（全机）、推演 ≥ 5,000 帧/s/核；像素差异报告 |
| G1 | 教师在 `PSN` 确认种子上平均每面死亡 ≤ 0.5；`S1N` 过关率 ≥ 90% |
| G2 | 死亡事件召回率、精确率 ≥ 99%，延迟 ≤ 10 帧；残机、bomb 读数 ≥ 99.5%；分数增量符号 ≥ 99% |
| G3 | 学生 `S1N` 过关率 ≥ 50%（区间下界 ≥ 35%）；真实 Windows 游戏 ≥ harness 成绩的 70% |
| G4-A | 教师 v2、学生 v2 分别显著优于 v1 |
| G4-B | 像素回报 RL 相对冻结学生提升 ≥ 15 个百分点（区间下界 > 0），且达到特权回报提升的 70% 以上 |
| G5 | 在 ≥ 2 个留出家族上，预训练后适应的 AULC 显著优于从零训练 |

## 5. 预算（默认值，见 D-05）

| 项 | 上限 | 主要消耗在 |
|---|---|---|
| GPU 时 | 400 h | P3 的 DAgger、P4 的 RL（每个 run 5,000 万帧 × 4 臂 × 3 种子） |
| 磁盘新增 | 300 GB | 像素缓存（可以删除），checkpoint |
| 墙钟 | 按阶段时间盒 | — |

P4-B 是最耗算力的部分。开跑前，必须先用 P0 实测的吞吐算出它预计要花多少 GPU 时，写进实验卡片。如果超过剩余预算，就缩减预算档或种子数，并问负责人。

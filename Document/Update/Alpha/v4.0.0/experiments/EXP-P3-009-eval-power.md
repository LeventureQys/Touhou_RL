## 0. 结论先说

1. **噪声有两个成分，5 局只量到其中一个**：`σ²_total = σ²_ckpt + σ²_episode/n`。
   `σ²_episode`（同一 checkpoint 的局间方差）用 20 局能钉死；`σ²_ckpt`（同配方重训之间
   均值本身的漂移）**5 局一个都看不到**，因为它只来自一次训练。过去所有 ±300~550 帧的
   "杠杆"都是拿 5 局均值比的，即**只量了前者、默认后者为 0**。
2. **量出来的 σ²_ckpt 远大于任何被称作杠杆的效应**：同配置（M1/M1b）σ²_ckpt = 223,254.9 ⇒ **sd_ckpt = 472.5 帧**，局间 sd_episode = 545.9 帧，ICC = 0.428（6 个 checkpoint 的上界估计：sd_ckpt = 431.0 帧）。
   由此得到的**单次训练分辨极限**（k=1，两臂各一次训练）是 **1,309.7** 帧——
   比历史上报告的全部五个效应（447.8 / 552.2 / 1,025.4 / 165 / 354 帧）都大。
3. **功效计算（power=0.8，α=0.05，双侧）**：+550 帧需要每臂 **k ≥ 12 个 checkpoint**
   （k 下限 11.6；最省设计 12 × 38 = 456 局/臂），+300 帧需要 **k ≥ 39 个**（下限 38.9；
   最省设计 57 × 3 = 171 局/臂）；**k=1 时 power 分别只有 0.13 / 0.07，且与局数无关**。
   反过来说，若 σ²_ckpt 为 0，+550 只需 16 局、+300 只需 52 局 —— 所以这张表本身就是
   "σ²_ckpt 能不能忽略"的判决书。
4. **重定基线**：当前最好的学生是 `m1`，20 局均值 **2,248.8** 帧、
   95% bootstrap CI **[1,952.0, 2,553.1]**（n=20，sd=709.8）；把 checkpoint 级方差计入后，同一配方"再训一次"
   的可信区间是 **[1,271.9, 3,225.8]**。**历史最好 1,816.0 低于 `m1` 的 20 局 CI 下界
   （即按 20 局口径 `m1` 确实更好），但仍落在 checkpoint 级区间内**。
   **关于 `1,816.0` 本身（本轮实测）**：那个 checkpoint（`armF_v2i27.pt`，sha256 `c58b0adc`，EXP-P3-005 的 F 臂）也用 20 局重测了 → **1,468.3 帧**、95% CI [1,326.3, 1,659.1]，前 5 个种子与历史**逐帧相同**（1,816.0）。也就是说 **1,816.0 落在该 checkpoint 自己的 20 局 CI 之外，比 20 局均值高 347.7 帧（+23.7 %）**：「历史最好」这条行有一大半是 seed 1000–1004 的有利抽样。EXP-P3-008 的 `2,116` 绝对门因此有**三个独立**的失效理由：5 种子高抽（−347.7）、同配置重训漂移（sd_ckpt 472.5）、以及基线本身已被 `m1` 超过。
5. **五条历史结论全部降级**（六行，`geo_restore` 有两个语料）：数据量 8→27 片 = 无法判定；
   `geo_restore`（8 片）= 无法判定；`geo_restore`（127k 语料）= 无法判定；`verify_k` 1→3 =
   无法判定；v2j 动作集 = 无法判定；obs-v2 / GRU = 无法判定。没有一条满足新判据（CI 不重叠
   **且** 超过 checkpoint 分辨极限 **且** 多 checkpoint 复现）。
   **措辞红线**：它们的正确状态是"**未被证实**"，不是"**已被否证**"——本卡没有新增任何训练，
   无法排除"效应真实但被噪声掩盖"。把"无法判定"写成"不成立"与把噪声写成"成立"同样是造假。
6. **尺子本身没问题，是"尺子的读数所有权"错了**：同一 (checkpoint, seed) 重跑逐帧一致
   （本卡复核：`--repeats 2` 两次都是 1,531 帧，见 §5.3；20 局的 seed 1000–1004 与历史 5 局
   **逐帧相同**，§2.4 的复现表）。所以差异不是评测噪声，而是**训练噪声**；加局数只能收窄
   `σ²_episode/n` 那一项，收不窄 `σ²_ckpt`。
7. **新判据已落进代码**：`claim` 子命令在任一臂缺 CI 时**退出码 2 且拒绝给结论**；
   判据模板不再允许把"CI 重叠"写成"小幅/趋势/方向一致"。

## 1. 问题：5 局均值把两个方差当成了一个

一次 S1N 读数是"某个 checkpoint 的若干局首死帧"。写成两层抽样：

```text
y_ij = μ + b_i + e_ij,   b_i ~ (0, σ²_ckpt),   e_ij ~ (0, σ²_episode)
```

- `e_ij`：**局间方差**。同一 checkpoint、不同 seed。确定性引擎下它是"局面难度差异"，
  不是评测噪声。
- `b_i`：**checkpoint 方差**。同配方重训第 i 次的均值偏移。它来自初始化、数据顺序、
  优化步数在墙钟预算下的不确定性。

一个臂报 `mean(y_i·)` 时，它的方差是 `σ²_ckpt + σ²_episode/n`。历史协议固定 `n=5`，
于是隐含假设 `σ²_ckpt = 0`。EXP-P3-008 §7.4 直接否掉了这个假设：

| 事实 | 数值 | 含义 |
|---|---|---|
| M1 与 M1b 的配置差异 | 仅训练时长（+73 % step，5.34 M → 9.23 M labels） | 同 init / 同数据顺序 / 同 split / 同 τ |
| 离线 val top-1 | 0.5946 vs 0.5950（Δ 0.0004） | 离线几乎不可区分 |
| 闭环 5 局均值 | 2,774.4 vs 1,444.2（**Δ = 1,330.2，5/5 同向**） | 闭环差三个数量级的"杠杆" |
| 同 checkpoint 重跑 | 逐帧完全一致 | 差异不是评测噪声 |

**本卡要回答的三个问题**：(a) `σ²_ckpt` / `σ²_episode` 各是多少；(b) 要分辨 +300 / +550 帧
需要多少局 × 多少 checkpoint；(c) 过去五条结论在这个分辨率下还站不站得住。

## 3. 功效计算：要多少局 × 多少 checkpoint

两臂独立重训，各 `k` 个 checkpoint × `n` 局，则

```text
se(Δ) = √( 2 · (σ²_ckpt/k + σ²_episode/(k·n)) )
power(Δ) = Φ( |Δ|/se − z_{1−α/2} ) + Φ( −|Δ|/se − z_{1−α/2} )
```

`power=0.8, α=0.05` ⇒ `z_α + z_power = 1.95996 + 0.84162 = 2.80159`，即需要
`se ≤ Δ / 2.80159`：**+550 帧需要 se ≤ 196.3 帧，+300 帧需要 se ≤ 107.1 帧**。

**假设 σ²_ckpt = 0（历史协议隐含的假设）**

| Δ (帧) | 需要 se | k 下限 | 最省设计 | 达成 se | 达成 power |
|---|---|---|---|---|---|
| 300 | 107.1 | 0.0 | 1 个 checkpoint × 52 局（52 局/臂） | 107.1 | 0.80 |
| 550 | 196.3 | 0.0 | 1 个 checkpoint × 16 局（16 局/臂） | 193.0 | 0.81 |

**用实测 checkpoint 方差（本卡结论所依据的）**

| Δ (帧) | 需要 se | k 下限 | 最省设计 | 达成 se | 达成 power |
|---|---|---|---|---|---|
| 300 | 107.1 | 38.9 | 57 个 checkpoint × 3 局（171 局/臂） | 106.4 | 0.81 |
| 550 | 196.3 | 11.6 | 20 个 checkpoint × 2 局（40 局/臂） | 192.9 | 0.81 |

**结论（三条，直接可执行）**：

1. **k=1（每臂只训一次）永远不行**：`se` 的下限是 `√(2σ²_ckpt)`，与 `n` 无关。
   实测 `√(2σ²_ckpt)` = 668.2 帧，> 1.96 倍后就是 **1,309.7** 帧的
   **分辨极限**。**在这个极限以下，加多少局都不会让结论变可靠。**
2. **要分辨 +550，成本主要花在 checkpoint 上，不是局数上**：见上表"最省设计"一列；
   一旦 `k` 够大，需要的 `n` 立刻掉到 20 以内。这与过去"多跑几局"的直觉正好相反。
3. **若 `σ²_ckpt` 确实为 0，则 20 局就够**（上表第一块）：+550 只需 16 局、+300
   只需 52 局。**所以 §3 的表本身就是对 `σ²_ckpt` 是否可忽略的判决**：实测不为 0，
   于是"20 局协议"只能解决局间方差，解决不了配方级比较。

### 3.1 降低 `σ²_ckpt` 的三条路（这才是修方法学的地方）

上表的结论很容易被误读成"什么都测不出来"。正确的读法是：**问题不在评测，在训练的可复现预算**。
按可控性排序：

1. **把训练预算从墙钟改成步数**。M1 与 M1b 的差别里唯一被点名的因子就是"步数不同
   （5.34 M vs 9.23 M labels seen）"，而它是 `--train-seconds 690` 在**共享机器**上跑出来的
   副产物（EXP-P3-008 §10-4 已记录吞吐在 3.6k–13.3k labels/s 之间波动）。步数固定的 A/B
   实验里，"checkpoint 级差分"不再包含这个因子，`σ²_ckpt` 会**系统性变小**，且实验可复现。
   这是单条改动里性价比最高的。
2. **每臂铺 `k ≥ 3` 个 checkpoint**。`σ²_ckpt/k` 直接掉；按 §3 表，`k` 一够，`n` 立刻降到
   20 以内，所以总成本比"多跑几局"低。
3. **降低单次训练本身的方差**（init 集成 / EMA / 更长但固定的预算）。这条最贵、也最慢，
   但在 1、2 都做完之前不该启动任何新的"调参"。

**反过来说**：在 1 或 2 落地之前，任何"臂 A 比臂 B 好 N 百帧"的结论都**必然**落在
checkpoint 抽样带内——这不是某个实验的失误，是当前预算形式的必然结果。

## 5. 新评测协议

### 5.1 `tools/rl/v400_student_eval.py`（改的是评测器，不是引擎）

```bash
--seeds 1000-1019        # 区间 / 列表 / 混合；去重保序；上限 256（防手误 1000-9999）
--repeats N              # 每个 seed 重跑 N 次，episode 记录带 repeat 索引
--bootstrap-iters 20000  # 百分位 bootstrap
--ci-level 0.95
```

`summary.json` 新增（旧字段全部保留，向后兼容）：

| 字段 | 内容 |
|---|---|
| `frames_stats` | `n / mean / sd / se / median / min / max / ci_low / ci_high / ci_level / ci_method / ci_half_width` |
| `frames` | 逐局帧数（有序），使 CI 可在不重跑的前提下重算 |
| `per_seed` | 每个 seed 的 `repeats / mean_frames / frames` |
| `seed_list / seed_count / repeats` | 去重后的种子表、种子数、重复数 |
| `criterion` | 判据模板本身（含 `this_summary_has_ci`），使"点估计"无法脱离它的许可被引用 |
| 顶层 `sd_frames / se_frames / ci_low / ci_high` | 便于下游脚本直接读 |

`parse_seeds` 对 `""`、`"1000-"`、`"1019-1000"`、`"1000-9999"`、`"abc"` 全部 `EvalError`
fail-closed（有单测）。`--repeats` **不是**为了买精度：它是用来证明"同一 (checkpoint, seed)
逐帧可复现"的，所以它只该在换新 checkpoint 时跑一次。

### 5.2 新增 `tools/rl/v400_eval_power.py`（聚合 + 功效 + 判据）

| 子命令 | 作用 | 退出码 |
|---|---|---|
| `noise --runs label=dir … [--same-config a,b]` | 方差分解（两种估计都出）+ 每臂 CI 表 | 0 |
| `power --noise noise.json --deltas 300,550` | 上述功效表（含"最省设计"与 k 下限） | 0 |
| `claim --a label=dir --b label=dir [--sigma2-checkpoint X]` | 判据模板；两臂 CI 不重叠才 `有效应` | 0 = 有效应，**2 = 无法判定** |
| `baseline --run dir --sigma2-checkpoint X` | 单臂基线：均值 + CI + **checkpoint 级区间** | 0 |

`--allow-missing-ci` 被显式拒绝（`SystemExit`），因为"缺 CI 仍给结论"正是要修掉的病。

### 5.3 判据模板（写死，不再协商）

> **差异只有在【两个臂都给出同一置信水平的 CI】且【两个 CI 不重叠】时才可称为"有效应"；
> 否则一律记为"无法判定"，禁止写成"小幅效应"/"方向一致"/"趋势"。**

工程化为四条，**全满足**才允许写"有效应"：

| # | 条件 | 不满足时的写法 | 机器检查 |
|---|---|---|---|
| 1 | 两臂都有同置信水平 CI（`ci_low/ci_high/n/sd`） | 无法判定（缺 CI） | `claim` 退出码 2 |
| 2 | 两条 CI **不重叠** | 无法判定（CI 重叠） | `claim` 退出码 2 |
| 3 | `\|Δ\| > 1.96·√(2σ²_ckpt/k)`（超过 checkpoint 分辨极限） | 无法判定（分辨率不足） | `--sigma2-checkpoint` 给 `resolution_limit` |
| 4 | `n ≥ 20` 且（`k ≥ 3` 或已把 `σ²_ckpt` 计入） | 降级为"参考行" | `claim` 打 `warnings` |

### 5.4 每次开臂的默认流程（最小可执行版）

```bash

bash .tmp_v400_power/launch_power.sh            # 见 §7 复现命令
# 2) 聚合

  --runs m1=.tmp_v400_power/m1,m1b=.tmp_v400_power/m1b,armF=.tmp_v400_power/armF \

# 3) 判据
python -X utf8 tools/rl/v400_eval_power.py claim \
  --a new=.tmp_v400_power/new --b base=.tmp_v400_power/m1 \
  --sigma2-checkpoint <noise.json 里的 sigma2_checkpoint>     # 退出码 0/2 即判据结论
```

## 6. 五条历史结论逐条重判

判法（不重新发明统计）：每条结论的两个臂都**有逐局记录**（`.tmp_v400_power/report.json`
的 `historical_arms`），因此可以：

1. 重算配对（同种子）差值 Δ 的 **95% bootstrap CI**；
2. 套用新模板的条件 1/2（CI 是否重叠）；
3. 再套条件 3（`|Δ|` 是否超过 checkpoint 分辨极限）；
4. 只有当 `|Δ|` 超过极限、CI 又不重叠、且能在 ≥3 个 checkpoint 上复现时，才写"成立"。

| 历史结论 | 原报 Δ | 重算 Δ（配对） | 95% CI | CI 不重叠 | 1.96·√(2σ²_ckpt) | 新判 |
|---|---|---|---|---|---|---|
| 数据量 8→27 片 | 552.2 | 552.2 | [417.4, 710.8] | 是 | 1,309.7 | **无法判定** |
| geo_restore off→on（8 片 A/B 格） | 447.8 | 447.8 | [414.0, 480.2] | 是 | 1,309.7 | **无法判定** |
| geo_restore off→on（127k 决策语料） | -1,025.4 | -1,025.4 | [-1,468.0, -501.8] | 是 | 1,309.7 | **无法判定** |
| verify_k 1→3 | -147.5 | -162.8 / -132.2 | [-348.2, 141.0] / [-339.4, 32.2] | **否** / **否** | 1,309.7 | **无法判定** |
| v2j 动作集（armE / armF 两对） | −165 / −354 | -165.0 / -353.8 | [-436.4, 126.6] / [-922.2, 201.6] | **否** / **否** | 1,309.7 | **无法判定** |
| obs-v2 / GRU（M2 / M3） | −1,430.6 / −2,028.4 / −100.4 | -1,430.6 / -2,028.4 / -100.4 | [-1,804.0, -1,049.8] / [-2,390.8, -1,659.4] / [-211.0, 10.2] | 是 / 是 / **否** | 1,309.7 | **无法判定** |

**逐条说明**（下面每条都给出"为什么是这个判"）：

1. **数据量 8→27 片 = +552.2 帧 → 无法判定**
   两臂 CI p3sig_v2−p3sig_armA = 552.2。它原本是本项目最像"真效应"的一条（5/5 同向、t=6.55、
   两个臂的 CI 完全不重叠），**新模板的条件 1/2 是过的**；卡住它的是条件 3：
   +552.2 < **1,309.7** 帧的分辨极限。也就是说这条效应**可能存在**，但
   "换一次训练就重抽一个 checkpoint"能搬动的量比它大，**单次配对无法把它与重训漂移分开**。
   要救它，只能按 §3 上表把它铺到 `k` 个 checkpoint 上；**在此之前它不能当结论用**。
2. **`geo_restore` = +447.8 帧（8 片）/ −1,025.4 帧（127k 语料）→ 无法判定 / 无法判定**
   这两个数字**符号相反、量级都小于分辨极限**。同一因子在两个语料上给相反符号，本身就已经
   说明"单次配对"读到的多半是 `b_i` 而不是因子效应。原卡在 127k 语料上把它读成"−1,025 的
   负效应"、在 8 片语料上读成"+447.8 的正效应"，两者都不满足新模板。**这一条最值得注意的是：
   它不是"效应小"，而是"同一个因子的符号可以被 checkpoint 抽样翻过来"。**

   **n=20 的复核（本轮顺手做的唯一一条）**：`armG_geo_on − armG_geo_off` 在**同样 20 个种子**上是 **-1,061.1 帧**（配对 95% CI [-1,325.1, -797.1]，se=134.7），历史 5 局值是 −1,025.4。符号**一致**、量级为历史值的 103 %，说明这条效应**不是 5 个种子的抽样运气**；但它仍然 **低于** checkpoint 级分辨极限 1,309.7 帧（两臂各只有一个 checkpoint），所以按新判据它依旧只能记为**未被证实**。这是本卡最想传达的区分：**「不是种子运气」与「是配方效应」是两件不同的事**。

3. **`verify_k` 1→3 = −147.5 帧 → 无法判定**
   两对臂的 Δ 是 p3sig_armC−p3sig_armA = -162.8；p3sig_armD−p3sig_armB = -132.2，CI [-348.2, 141.0]（n=5，重叠）；[-339.4, 32.2]（n=5，重叠）。**CI 已经重叠**（条件 2 不过），
   `|Δ|` 又远小于分辨极限（条件 3 不过）。原卡的表述（"`verify_k=3` 不提供闭环信号"）作为
   **否证**是安全的，但**不能**反过来读成"−147.5 帧的负效应"。
4. **v2j 动作集 = −165 / −354 帧 → 无法判定**
   两对：`v2j_armE − margin_armE` 与 `v2j_armF − margin_armF`，Δ = v2j_armE−margin_armE = -165.0；v2j_armF−margin_armF = -353.8，
   CI [-436.4, 126.6]（n=5，重叠）；[-922.2, 201.6]（n=5，重叠）。两对臂**方向一致但幅度差 2 倍**，且第二对（`armF`）的 CI 是否重叠见上表；幅度随基线 checkpoint 变动本身就是 `σ²_ckpt` 的指纹。
5. **obs-v2 / GRU = 负效应 → 无法判定**
   这条是**方法学上最危险的一条**：`M2 − M1 = −1,430.6` 看起来很硬，但 `M1` 与 `M1b` 是
   **同一配置的两个 checkpoint**，而 `M2 − M1b = −100.4`。同一个 `M2`，换一个同样合法的
   基线就从 −1,431 变成 −100。**这说明"obs-v2 负效应"的量级完全由选哪个 M1 决定**；
   按新模板，`M2 − M1` 的 CI 是否重叠已经不重要——**基线本身的 checkpoint 方差就覆盖了
   整个"效应"**。可以安全保留的只有一条更弱的结论：obs-v2 的三臂**没有**表现出正效应
   （三条腿的离线增益都没转化到闭环），这是**否证**，不是效应量。

## 8. 已知限制（必须先说，避免把本卡读成"什么都测不出来"）

1. **`σ²_ckpt` 的矩估计只有 k=2（同配置）**：1 个自由度，是量级估计不是标定先验。
   本卡因此同时报"全臂上界"，且判据只用同配置那个更保守的读法。
2. **M1/M1b 的差里含一个真实因子（训练步数）**，所以 `sd_ckpt` 是上界；这条偏差的方向
   对本卡结论有利（真实 `sd_ckpt` 更小 ⇒ 分辨极限更小 ⇒ 结论更容易成立），而本卡在最有利
   的读法下仍然判"无法判定"，所以结论不依赖它。
3. **本卡没有训练任何新 checkpoint**。`k ≥ 3` 的复现要求因此**尚未满足**：五条结论是
   "**未被证实**"，不是"**已被否证**"。本卡不把任何一条写成"不成立"。
   可以顺手一提的唯一一条正面复现是 §6 第 2 条的 `geo_restore`（20 局 −1,061.1，
   与历史 −1,025.4 同号同量级），但它两臂各只有 1 个 checkpoint，仍不满足判据。
4. **`--stop-on-death` 的 frames 是"首死帧"**，不是"能活多久"；EXP-P3-006 §8-7 已指出站桩也能
   骗高这个量。本卡只讨论**同一个量的可分辨性**，不主张它是正确的目标函数。
5. **功效用的是正态近似、双侧、独立重训**；按种子配对的设计严格更有力，所以 §3 的成本是**上界**。
6. **20 局不足以让 bootstrap CI 覆盖 `σ²_ckpt`**：`frames_stats` 的 CI 是**局间**CI，读它时
   必须同时读 §2.3 的 `σ²_ckpt`。这点已写进 `summary.json` 的 `criterion` 字段。

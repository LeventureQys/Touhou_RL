## 0. 预注册（运行前写定，运行后不得改）

### 0.1 主指标

**留出种子上、自机周围 48 像素内的致死物占用 F1**（micro-F1，阈值 0.5）。

- 占用定义沿用 P2 已冻结的生成器 `touhou_rl.v400.labels.occupancy.hazard_occupancy`：
  96×112 网格、4 像素/格、`occupied` 通道 = 子弹 ∪ 敌体 ∪ 激光（即 P2 §3.3 的"致死物"）。
  标签只由引擎状态导出，**不读像素**（V8：学生输入只有像素）。
- 计分窗口：以自机（`PLAYER` 的 `position`）为中心、对齐到 4 像素网格的 **24×24 格 = 96×96 像素**，
  即自机 48 像素内。窗口越出 96×112 网格的格子一律**不计分**（不是当作负例）。
- F1 在全部留出样本的格子上直接数 TP/FP/FN 聚合（micro），避免"子弹稀疏"造成的宏平均抖动。

### 0.2 四种输入（代号、定义、张量）

| 代号 | 输入 | 形状 | 生成方式 |
|---|---|---|---|
| A | 64×64 全场（现状） | `(1,64,64)` | obs-v1 原式：`(77R+151G+28B)>>8` 后按 6 列 × 7 行块整数均值 `sum//n` |
| B | 96×112 全场 | `(1,112,96)` | 同亮度，按 4×4 块整数均值（384/96=4、448/112=4，整除） |
| C | 192×224 全场（半分辨率） | `(1,224,192)` | 同亮度，按 2×2 块整数均值（整除） |
| D | 64×64 全场 + 128×128 原分辨率局部窗 | `(2,128,128)` | ch0 = 以自机为中心的原分辨率 128×128 窗（越界补 0）；ch1 = A 的 64×64 全场双线性放大到 128×128 |

- **时序窗：统一取 1 帧**（决策时刻最新的那次渲染，即 `decision_frame - 1`）。
  理由：占用是**当帧**属性，本卡隔离的是**空间分辨率**；四种输入用同一时序定义才可比。
  A 因此不等于 obs-v1 的 4 帧堆叠，这一点在 §3 结论里必须写明；若最终选中 A/B，
  T4 用满 4 帧堆叠时须重测一次（预注册的补救口径）。
- 归一化：`float32 / 255.0`，与 obs-v1 一致（不减均值、不除标准差）。
- D 的局部窗**永远把自机放在正中**（窗外补 0），因此窗内格子与标签格子一一对应；
  窗锚点用**对齐到 4 像素**的窗口原点，保证 max-pool 不漏像素。

### 0.3 感知头（四种输入**同一个**头，全卷积、无全局池化）

```text
conv3x3(C_in→16) ReLU → conv3x3(16→16) ReLU → conv3x3(16→16) ReLU → conv1x1(16→1)
→ 每格 max-pool（adaptive_max_pool2d）→ sigmoid → 24×24 格占用概率
```

- `C_in = 1`（A/B/C），`C_in = 2`（D）。除此之外**结构、通道、参数量完全相同**，
  唯一变量是输入分辨率。
- **没有任何 `AdaptiveAvgPool2d(1)`/全局池化/全连接**；输出直接摊到标签格子。
- 每格概率 = 覆盖该格的所有输入像素 logits 的最大值（"该 4 像素格里有没有致死物"是 max 语义）。
- 损失：`BCEWithLogits`，只算 24×24 窗口内的格子，越界格不计。
- 优化：Adam，lr 3e-3，batch 256，**6 epochs**，每输入 **3 个训练种子**（0/1/2）。
  输入像素不足一格的边界情况由 `adaptive_max_pool2d` 处理（A 的每格 < 1 像素，允许重复采样）。

### 0.4 数据与切分

- 来源：**D0 轨迹重放**（不是重采教师）。D0 分片 `shard.json` 保存了 StageStart
  （`stage/difficulty/team/seed`，与 `work/seedN/channel_b.json` 的 `reset_command` 一致），
  `labels.jsonl` 的 `step_frames` 保存了**逐帧按键掩码**（每决策 4 帧，`load_labels` 已校验）。
  因此可以在 env 角色下逐帧重放，把原分辨率场地 384×448 灰度图重新渲染出来。
- 对齐闸门：每个决策边界都要 `HASH` 等于 D0 的 `hash_pre`/`hash_post`；任一不等 → 该 seed fail-closed，
  如实记录并**不出数**（不猜、不跳过匹配）。
- 切分：**train = seeds 1–14，test = seeds 15–16**（与任务书一致，留出 2 个独立 episode）。
  训练/测试不共享任何 seed（V6）。
- 规模：16 个 seed × 约 3,370 决策 ≈ **5.4 万决策**（D0 的实际总数，不增不减）。

### 0.5 自机定位器（像素，部署合法）

- 结构：与感知头同族的小全卷积热图头（输入 = A 的 64×64 单帧），输出 64×64 热图，
  argmax 后取 3×3 邻域的加权质心做亚像素修正，再线性映射回场地坐标。
- 只用 seeds 1–14 训练；**误差只在 seeds 15–16 上报告**（中位欧氏像素误差）。
- 闸门（预注册）：**中位误差 > 4 像素 → D 不得入选**。

### 0.6 选择规则（预注册，照抄任务书）

1. 设 `F_max = max(F1_A, F1_B, F1_C, F1_D)`。
2. 合格集 = `{X : F1_X ≥ 0.90 且 F1_X ≥ 0.95 × F_max}`，D 另需定位器中位误差 ≤ 4 像素。
3. 在合格集里选**输入最小**者，面积序：`A (4,096) < B (10,752) < D (20,480) < C (43,008)`。
4. 止损：四种输入的 F1 **全部 < 0.90** → 停下问负责人，本卡不产出结论。
5. 若 A 就已 ≥ 0.90：照规则选 A，并在结论写明"**分辨率不是主要瓶颈**"，重心转到网络结构与数据量。

### 0.7 次要指标（只报告，不参与选择）

- 每 seed 的 F1（看 seed 间方差）、precision/recall 分开报（避免 F1 单值掩盖"全预测有物"）。
- 平凡基线（V5）：恒定"无占用"（F1=0）、恒定"有占用"、以及"把占用当作自机位置处的固定方形"
  —— 三者都比不过的头不值得解释。
- D 的部署版（`D+loc`）：窗锚点改用定位器估计值，报告 F1 掉多少。

# EXP-P0-002 吞吐 spike 首轮：单实例渲染路径帧率

- 日期 / 工作包：2026-11-07 / P0-WP2
- 假设：在本机的 xvfb + 软件 GL 上，原样构建（`-O0`）的单实例吞吐距离 `10-P0` 的门槛（渲染加读回全机合计 ≥ 2,000 帧/s、推演 ≥ 5,000 帧/s/核）有多远。
- 预注册：主指标 = 单个进程在稳定窗口内每秒推进的逻辑帧数（两次采样差 ÷ 墙钟差）；通过阈值 = `10-P0` WP2 决策表；样本量 = 每种配置 1 次 25 s 窗口（本轮只做首轮定点，不做统计推断）。
- 设置：
  - worktree `third_party/th08-rl`（`rl-harness` @ `bcddaa2`）
  - 二进制：`build/measure/th08-modern`，在 `main.cpp` 的 `g_SoundPlayer.ProcessQueues()` 之后临时插入了帧计数器（每 100 帧写一次 `TH08_FRAME_COUNT_FILE`），测完已 `git checkout` 还原
  - 数据目录：`~/v400-data/game`，`th08.cfg` 用 `tools/rl/v400_make_cfg.py` 生成的 harness 模板（`disableVsync=1`、`preloadMusic=1`、`musicMode=0`、`playSounds=0`），sha256 `7617a7ca…53aa`
  - 回放：`th8_ud2cd4.rpy`（`lunatic-3-b`，149,986 次计算）
  - 运行：`TH08_RENDER_AUDIT_FAST=1 SDL_AUDIODRIVER=dummy xvfb-run -a -s "-screen 0 640x480x24"`
- 结果：
  | 配置 | 帧数变化 | 窗口 | fps |
  |---|---|---|---|
  | `-O0` + `LP_NO_RAST=true` | 600 → 5300 | 22.9 s | **204.9** |
  | `-O0` + 光栅化（llvmpipe） | 4800 → 14100 | 23.0 s | **403.9** |
  | `-O0` + `LP_NO_RAST=true`（前一次） | 200 → 5700 | 27.8 s | 197.7 |
- 两个必须写明的观察：
  1. **`LP_NO_RAST` 没有起到"关掉光栅化"的作用，反而更慢**。同一二进制下带光栅化反而快约 2 倍。合理怀疑：`LP_NO_RAST` 只是 llvmpipe 的光栅开关，而游戏侧整条 draw 链、顶点变换、GL 驱动调用照常执行，开销并不在光栅化那一层；两次窗口落在回放的不同阶段也会带来方差。**结论：`LP_NO_RAST` 不能当作"影子进程/推演"吞吐的代理**，`10-P0` WP2 的"逻辑帧速度（不光栅化）"这一行需要改用 WP3 的空设备模式来测。
  2. **`disableVsync` 是前提，否则根本测不出数**。用原始的 play 版 `th08.cfg`（vsync 开）时，`TH08_RENDER_AUDIT_FAST` 让 `CheckFps()` 测到 >65 fps，游戏会**整套自我重启**：60 s 内只推进约 100 个逻辑帧、CPU 却占 87%。换成 harness 模板后帧计数才正常增长。这条与 `10-P0` §4.1 的警告一致，现已被实测确认。
- 有效性自检：
  - V1 是：计数器插在 `RunCalcChain()` 之后，直接数逻辑帧，不依赖任何间接指标
  - V2 不适用
  - V3 是：`-O0` 两个配置的量级接近（198/205），说明计数机制可重复
  - V4 否：单次窗口，不是独立 episode 的统计；本轮只作定点估计
  - V5 是：平凡基线是"进程不崩溃"；有计数增长才说明真的在推进
  - V6 不适用
  - V7 否：未换种子/换窗口重跑；同配置两次得到 197.7 与 204.9，差 3.6%，方差可接受但未系统测量
  - V8 不适用
  - V9 是：指标在运行前由 `10-P0` WP2 规定
- 结论：**实验无效（不完整），不得据此做决策**。原因是本轮只测了"渲染路径"这一半，而决策表要的是"渲染加读回的全机合计"与"推演帧/s/核"两个数；读回成本未测、多实例扩展未测、`-O2` 变体未测（`-O2` 能编译链接，但与帧计数器补丁同时应用时链接失败，需要拆开重做）。已测到的 205/404 fps 单实例数字，只说明 `-O0` 渲染路径本身离 2,000 帧/s 的全机目标还差一个量级，必须靠多实例并行使之成立。
- 成本：GPU 0 h；墙钟约 1.0 h；磁盘约 0.1 GB。

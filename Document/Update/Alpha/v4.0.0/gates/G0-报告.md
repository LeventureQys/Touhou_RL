### 30.4 新增 reset-hash 守卫（EXP-P0-071）

- **实测缺口**：4 次运行共 **18 次引擎启动**，其中 **1 次（≈5.6%）** 在 `RESET 0 1 0 1 0` 后落入
  **不同 StageStart**：该进程回复 `hash=795b9441ed0c8056`，其余 5 个进程回复 `7f04c7361749ed9f`；
  漂移发生在任何 `STEP` 之前。
- **已实现守卫**：三来源优先级（cli / env / first-observed）、不一致时 **fail-closed 退出码 4**、
  默认重试 1 次，且重试**必须新起进程**（同进程重复 `RESET` 返回 `ready=0`，不能复用）。
- **验证**：3 局真实运行 reset hash 全为 `3eafc035dc4fe6a9`、**无误报**；负对照 exit 4 且**不写行**；
  单测 **49 passed**。
- **限制**：守卫只**检测**、不消除根因，也不降低 5.6% 的发生概率；
  `Th08Env.reset`（`touhou_rl/v400/gym/env.py`）**尚未接入**该守卫。

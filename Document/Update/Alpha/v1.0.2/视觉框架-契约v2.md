# 视觉框架 · 契约 v2

- 所属阶段：Stage 6（架构改造：从"特权 RL"转向"视觉优先"）
- 前置：`框架评估-鲁棒性与性能.md` 的结论——现有框架是"特权教师工厂"，不是视觉系统
- 定位：本文件是视觉层的**唯一契约**；与代码冲突时以代码为准并立即修正本文（v1.0.2 出过
  `obs.py` 文档承诺 `profile.state_source` 而代码里没有的问题，这类漂移必须避免）
- 判据：**部署端不得出现任何一次内存读取**。视觉策略的输入只能是画面。

---

## 1. 三条铁律

1. **部署只看画面。** `touhou_rl/vision.py` 之后的路径（模型、训练、评估）不允许调用
   `state.py`；它只允许读 `frame`。
2. **特权数据只是标签。** `self_feat` / `bullets` / `danger` / 教师价值，全部是"训练期的
   监督信号"，用来教视觉学生，不进入推理。
3. **换作品只允许改一个东西：框。** 任何新游戏的非通用信息都必须收敛到
   `PlayfieldBox(x, y, w, h)` 这一个参数里；模型输入张量形状固定不变。

## 2. 帧契约（`touhou_rl/vision.py`）

| 项 | 值 | 理由 |
| --- | --- | --- |
| 输入 | 客户区 RGB `uint8[H, W, 3]`（TH08 窗口模式 640×480） | GDI `BitBlt` 实测 0.678 ms/帧 |
| 裁剪 | `PlayfieldBox`，默认 TH08 `(32, 16, 384, 448)` | 只保留可玩区域，去掉 HUD 与边框 |
| 缩放 | 面积平均（`Image.BOX`）→ `128 × 112 × 3` | 面积平均保证 4 px 子弹不会在降采样中被点采样跳过 |
| 采样率 | **30 Hz**（每 2 个逻辑帧一帧），与决策频率一致 | 60 Hz 会让数据量翻倍，而策略每两帧才决策一次 |
| 历史 | `FrameStack(depth)`，默认 3，**旧帧在前** | 像素没有速度信息，运动必须由多帧提供 |
| 归一化 | 存储 `uint8`，送入模型时 `/255`（`frames_to_batch`） | 存储与预处理解耦，训练/推理共用同一函数 |
| 尺寸校验 | checkpoint 记录 `H/W/C/depth`，加载时校验 | 换分辨率必须显式失败，而不是形状对不上报错 |

**为什么是 128×112**：原比例 384:448 = 0.857，112:128 = 0.875，接近；一颗 10 px 子弹
在张量里约 3 px，可分辨；单帧 43 KB，30 Hz 下约 1.3 MB/s，采 20 分钟约 1.5 GB。

---

## 3. 数据契约（`touhou_rl/vision_data.py`）

分片 `.npz`，**每片 512 帧**（约 22 MB，压缩后通常 5–10 MB）：

| key | 形状/dtype | 角色 |
| --- | --- | --- |
| `frame` | u8 `[n, 128, 112, 3]` | **唯一推理输入** |
| `self_feat` | f32 `[n, 24]` | 标签（自机位置/资源/射线） |
| `bullets` | f16 `[n, 64, 6]` | 标签（最近 64 发） |
| `danger` | u8 `[n, 16, 8]` | 标签（弹幕占据图） |
| `action` | u8 `[n, 4]` | 人类专家动作（回放采集） |
| `value` | f16 `[n, 18]` | 教师价值（可选；由特权观测离线算出） |
| `meta` | f32 `[n, 8]` | frame/stage/score/graze/lives/bombs/power/deaths |

规则：

- `action` 与 `value` 分属两种标签来源，**不允许互相冒充**（人类动作 ≠ 教师 argmax，
  v1.0.2 已量化两者只有 21.5% 一致）；
- 教师价值**不落盘**也可：它是特权观测的纯函数，`vision_train` 离线重算（约 1 ms/帧），
  这样换教师不用重采视频；
- 分片边界 = 回合边界，`stack_indices` 因此**只在分片内**回看历史，绝不跨片拼接。

## 4. 模型契约（`touhou_rl/vmodels.py`）

```
frames [B, depth, 128, 112, 3] /255
   └─ VisionEncoder（4 层卷积 → 自适应池化 → Linear）
        ├─ VisionStateDecoder → self_feat[24] + danger_log[128]      （阶段一：表征）
        └─ VisionScorer      → 18 个候选动作的价值                    （阶段二：策略）
```

| 契约项 | 值 | 理由 |
| --- | --- | --- |
| 候选集 | 18 = 9 方向 × 2 火力状态 | 与特权教师 `candidate_scores` 完全同集，标签可直接复用 |
| 策略形式 | **价值回归 + argmax**，不是四头分类 | 并列动作的分类标签会互相抵消（已实测：argmax 一致率 21.5%，后悔值仅 0.16 px） |
| 射击/炸弹 | 恒开射击、炸弹留给规则 | 教师的 18 路价值只排序移动/火力；炸弹是稀有事件，单列会污染主标签 |
| 主干共享 | 表征与策略共用同一编码器 | 表征阶段免费标签先教会"看见子弹"，策略阶段只需学排序 |
| 参数规模 | 默认约 2.3 M（width=32, trunk=256） | 单帧 2.3 GFLOP 级别，4070S 上 ms 级；不够再加宽 |

## 5. 训练契约（`touhou_rl/vision_train.py`）

两个阶段，顺序不可颠倒：

| 阶段 | 目标 | 损失 | 可读指标 |
| --- | --- | --- | --- |
| `state` | 画面 → 特权观测 | `smooth_l1(self_feat)` + `smooth_l1(log1p(danger/8))` | 自机位置误差（**px**）、子弹数误差（**颗**）、危险图相关/格子命中率 |
| `policy` | 画面 → 教师价值 | `smooth_l1(clip(value)/10)` | top1 一致率、**后悔值（px）**，并按"最近子弹距离"分桶 |

**为什么指标必须换算成游戏单位**：v1.0.2 的教训是"准确率涨了但不会玩"。位置误差用像素、
子弹数用颗、决策质量用"教师会让出的最小空隙（px）"，任何一项恶化都能直接读出来。

**分桶报告是硬要求**：安全区（>120 px）的指标没有意义，只有 0–15 px 这一桶决定生死。

## 6. 评估契约

三层，从便宜到贵：

| 层 | 方法 | 成本 | 通过标准 |
| --- | --- | --- | --- |
| L1 表征 | `vision_train --stage state` 的验证集指标 | GPU 分钟 | 自机位置误差 < 20 px、危险图相关 > 0.6 |
| L2 决策 | `--stage policy` 的 top1 / 后悔值（分桶） | GPU 分钟 | 0–15 px 桶后悔值 < 1.5 px |
| L3 真机 | `evaluate.py --vision-checkpoint`，**帧是唯一输入** | 每局 1–3 分钟 | 存活帧数 > 随机策略（2,418） |

L3 的报告必须带 `"policy": "vision"`，且该局全程不得读内存（代码路径保证：视觉分支不调用
`state.py`，仅用 `session.grab()`）。

## 7. 与旧路径的关系

| 旧模块 | 新角色 |
| --- | --- |
| `spec.py` / `state.py` / `obs.py` | **训练期标签生成器**（教师侧），部署期不参与 |
| `pilot.py` | 教师（生成 18 路价值标签） |
| `distill.py` / `bc.py` / `ppo.py` | 特权学生（对照基线，不再作为交付目标） |
| `evaluate.py` | 同时支持特权与视觉策略，用同一套报告口径 |
| `capture_dataset.py` | 特权数据集（视觉数据集由 `vision_capture.py` 产出） |

## 8. 未决项（明确写出来，避免假装完整）

1. **跨作品输入层还没实现**：目前只有 `PlayfieldBox` 一个参数，尚无"自动框选/分辨率自适应"；
2. **视觉学生还没有 DAgger**：现有视觉数据只来自人类回放轨迹，学生自己走到的状态没有标签；
3. **无递归、无光流**：运动信息完全依赖 3 帧堆叠，快速弹幕下可能仍不足；
4. **激光/敌人未进标签**：`state.read_lasers()` 与 `read_boss_positions()` 已实现但未进入
   `obs`，视觉学生自然学不到它们（这是**标签缺失**，不是视觉能力问题）。

## 2. 游戏状态契约（`touhou_rl/state.py`）

### 2.1 `GameState`（slots dataclass）

| 字段 | 类型 | 来源（基址 + 偏移） | 归一化/说明 |
| --- | --- | --- | --- |
| `supervisor_state` | int | `g_Supervisor+0x15C` | `1`=标题，`2`=游戏内，其余见 `spec.STATE_*` |
| `title_screen_current` | int | `g_TitleScreen+0x14428` | 0=主菜单、4=难度、5=角色、7=回放、11=练习选面；非标题态时为 `-1` |
| `title_screen_state` | int | `+0xC` | 0=Init、1=Ready、2=Exit、3=Changing；回放菜单内为子状态 0–4 |
| `title_cursor` | int | `+0x0` | 当前高亮项 |
| `title_replay_count` | int | `+0xC288` | 回放列表条目数 |
| `stage` | int | `g_GameManager+0x3DDC4` | 0-based（0 = Stage 1，4 = Stage 5，5 = Final） |
| `gameplay_frame` | int | `+0x3DDC0` | 每关从 0 开始计数，**一帧一增** |
| `stage_frames` / `run_frames` | int | `+0x3DE14` / `+0x3DE10` | 关内/整局活动帧 |
| `flags` | u32 | `+0x3DBAC` | bit0 练习、bit1 demo、bit3 replay、bit14 符卡练习 |
| `is_demo`/`is_replay`/`is_practice`/`is_spell_practice` | bool | 由 `flags` 派生 | |
| `score` / `graze` | int | `globals+0x8` / `+0xC` | 原始值 |
| `lives` / `bombs` / `power` | float | `globals+0x74`/`+0x80`/`+0x98` | 原始值（残机可为负=Game Over） |
| `bombs_used` / `deaths` | int | `globals+0x84` / `+0x64` | 单调递增 |
| `clock_time` / `time_orbs` | int | `globals+0x28` / `+0x3C` | 人妖槽时钟/时间球 |
| `player_x` / `player_y` | float | `g_Player+0x2B4` | 场地绝对坐标 |
| `player_vx` / `player_vy` | float | `g_Player+0x3F8` | 像素/帧 |
| `focus_mode` | u8 | `g_Player+0x3` | 低速状态 |
| `field_x`/`field_y`/`field_w`/`field_h` | float | `g_GameManager+0x3DDD4`/`+0x3DDDC` | 实测 `(32,16,384,448)`；未加载关卡时回退到常量 |
| `input_mask` / `last_input_mask` | u16 | `0x0165A808` / `0x0165A804` | `g_CurFrameInput`（实时输入；回放播放时恒 0） |
| `gui_input_current` / `gui_input_previous` | u16 | `0x0161C674` / `0x0161C678` | **游戏实际消费的输入**（`Player::OnUpdate`），回放输入也在这里（F-12） |
| `active_bullets` | int | `g_BulletManager+0x6BA538` | 计数器 |

**错误行为**

- `ReadProcessMemory` 失败 → `OSError`（带地址/长度/Win32 错误码），**不返回零填充**；
- 标题屏对象在切屏瞬间会被释放 → `read_state` 捕获该 `OSError`，把标题相关字段置 `-1`/`0`，不抛出；
- `module_base` 解析失败 → `GameStateReader.__init__` 抛 `RuntimeError`。

### 2.2 `BulletField`（零拷贝视图）

一次 `ReadProcessMemory` 读 `g_BulletManager+0x1A880` 起 `0x601 × 0x10B8 = 6,578,360` 字节（F-08：0.537 ms），再建立 5 个 NumPy 跨步视图：

| 视图 | 形状/dtype | 偏移 | 含义 |
| --- | --- | --- | --- |
| `raw` | `u8 [0x601, 0x10B8]` | 0 | 原始块 |
| `position` | `f32 [0x601, 2]` | `0xD44` | x, y（场地坐标） |
| `velocity` | `f32 [0x601, 2]` | `0xD50` | 像素/帧 |
| `state` | `u16 [0x601]` | `0xDB8` | 0=未使用、1=发射、2–4=生成中、5=消失中 |
| `disabled` | `i8 [0x601]` | `0x10B4` | 非 0 = 碰撞被禁用 |
| `half_size` | `f32 [0x601, 2]` | `0xD34` | 判定半径（x 分量取 max 后使用） |

`active_mask() = (state != 0) & (state != 5) & (disabled == 0)`。

## 3. 观测契约（`touhou_rl/obs.py`）

观测是 `Dict`，三个键：

### 3.1 `self_feat`：`float32 [24]`

| 下标 | 含义 | 归一化 |
| --- | --- | --- |
| 0 | 自机 x | `(x - field_x) / field_w` |
| 1 | 自机 y | `(y - field_y) / field_h` |
| 2–3 | 自机速度 | `/8.0` |
| 4 | 低速 | 0/1 |
| 5 | 残机 | `/8` |
| 6 | 符卡（炸弹） | `/8` |
| 7 | 火力 | `/128` |
| 8 | 擦弹 | `min(1, graze/20000)` |
| 9 | 分数 | `min(1, score/2e8)` |
| 10 | 时钟 | `min(1, max(0, clock)/20)` |
| 11 | 时间球 | `min(1, orbs/20)` |
| 12 | 关卡 | `min(1, stage/6)` |
| 13 | 关卡通过标记 | 0/1 |
| 14 | 活跃子弹数 | `min(1, n/700)` |
| 15 | 近距（<192 px）子弹数 | `min(1, n/120)` |
| 16–23 | 8 条射线的最近危险距离 | `min(1, d/320)`；无危险 = 1.0 |

射线：以自机为原点，方向 `N, NE, E, SE, S, SW, W, NW`；判据 `along ∈ (0, 320)` 且 `lateral < 6 + 0.02·along`；取该方向最近子弹距离。

### 3.2 `bullets`：`float16 [64, 6]`

按到自机距离升序取前 64 发（不足补零）：

| 列 | 含义 | 归一化 |
| --- | --- | --- |
| 0 | `dx` | `/192` |
| 1 | `dy` | `/224` |
| 2 | `dvx` | `/6` |
| 3 | `dvy` | `/6` |
| 4 | 判定半径 | `/8` |
| 5 | 有效位 | 1=有子弹，0=填充 |

排序保证「最近的子弹永远在 0 行」；无效行的 `0..4` 列恒为 0，网络用第 5 列做掩码池化。

### 3.3 `danger`：`uint8 [16, 8]`（训练时转 float 并 `/8`）

全场地粗占据：格子 `48 × 28` 游戏像素（8 列 × 16 行），值 = 该格活跃子弹数（上限 255）。

**错误行为**：`encode(state, None)` 返回全零子弹与全零危险图、射线全 1.0（「无威胁」语义），不抛异常。

## 4. 动作契约

| 维度 | 名称 | 取值 |
| --- | --- | --- |
| 0 | `move` | 0 静止、1 N、2 NE、3 E、4 SE、5 S、6 SW、7 W、8 NW（屏幕坐标，y 向下） |
| 1 | `shoot` | 0/1（Z） |
| 2 | `focus` | 0/1（Shift，低速+显示判定点） |
| 3 | `bomb` | 0/1（X，**边沿触发**：只在按下那一帧生效） |

- Gym 空间：`MultiDiscrete([9,2,2,2])`；
- 扁平等价：`flat = move*8 + shoot*4 + focus*2 + bomb ∈ [0,72)`，双向双射（单测锁定）；
- 键位：`up/down/left/right/z/shift/x`；注入方式是「设置当前按键集合」，未列出的键在下一帧前释放；
- 越界动作：`spec.action_to_buttons` 抛 `ValueError`。

## 5. 奖励契约（`touhou_rl/reward.py`）

每步先算 6 维向量（各自裁剪到 `[-10, 10]`），再与权重内积得标量：

| 下标 | 分量 | 公式（默认参数） |
| --- | --- | --- |
| 0 | `survive` | 非终止步 `+1.0`，终止步 `0` |
| 1 | `progress` | 进入新关卡 `+1.0`；否则帧数前进时 `+0.01` |
| 2 | `score` | `min(10, Δscore / 1e6)` |
| 3 | `graze` | `min(10, Δgraze / 100)` |
| 4 | `resource` | `min(10, Δpower/8 + Δorbs/4 − 2·ΔbombsUsed)` |
| 5 | `event` | `−10·Δdeaths + 100·（关卡推进）` |

默认权重 `RewardWeights(survive=0.01, progress=0.02, score=1.0, graze=0.1, resource=0.1, event=1.0)`。

**错误行为**：权重非有限或为负 → 构造 `RewardEngine` 时 `ValueError`；首次 `compute`（未 `reset`）返回全零向量与空 info。

## 6. 环境契约（`touhou_rl/env.py`）

| 项 | 契约 |
| --- | --- |
| 类 | `Th08Env(gymnasium.Env)`，`metadata={"render_modes":["rgb_array"],"render_fps":60}` |
| `action_space` | `MultiDiscrete([9,2,2,2])` |
| `observation_space` | `Dict(self_feat: Box(-10,10,(24),f32), bullets: Box(-10,10,(64,6),f32), danger: Box(0,255,(16,8),f32))` |
| `reset()` | 返回 `(obs, {"state": {...}})`；保证已进入「人控关卡」（`supervisor_state==2` 且非 demo/replay 且 `gameplay_frame>1`） |
| `step(a)` | 返回 `(obs, reward, terminated, truncated, info)`；每步消费 `frameskip` 个游戏帧 |
| `terminated` | 离开游戏态（回标题/结算/`supervisor_state!=2`）或 `lives < 0` |
| `truncated` | `step_index >= max_steps` |
| `info` | 含 `reward_vector`(6,)、`scalar_reward`、`episode_reward`、`step`，以及 `stage/frame/lives/bombs/power/score/graze/deaths/bullets`；终止/截断时额外含 `episode{steps,frames,stages_reached,score,graze,deaths,lives,episode_reward,terminated,truncated}` |
| `reset_mode` | `"menu"`（默认，回标题再进关）或 `"relaunch"`（杀进程重启） |
| 时钟 | 只用 `gameplay_frame` 计步，不用墙钟 |
| `render()` | 返回 `uint8[480,640,3]` RGB |
| `close()` | 释放按键、关进程、释放 GDI 资源 |

**错误行为**：启动失败重试 3 次（每次先等旧进程退出）；3 次都失败抛 `RuntimeError`，消息包含 TH08 启动对话框文本（若有）。

## 7. 数据集契约（`touhou_rl/dataset.py`）

### 7.1 分片文件 `<tag>-NNNNN.npz`（`np.savez_compressed`）

| 键 | 形状 / dtype | 含义 |
| --- | --- | --- |
| `self_feat` | `f32 [n, 24]` | 观测 §3.1 |
| `bullets` | `f16 [n, 64, 6]` | 观测 §3.2 |
| `danger` | `u8 [n, 16, 8]` | 观测 §3.3 |
| `action` | `u8 [n, 4]` | 专家动作（move/shoot/focus/bomb） |
| `meta` | `f32 [n, 8]` | `frame, stage, score, graze, lives, bombs, power, deaths` |

### 7.2 旁车文件

- `<分片>.json`：`{shard, frames, created, total_frames, replay, tag, stage_start}`；
- `dataset-summary.json`：`{shards[], frames, out_dir, elapsed_seconds, replay, tag, stage_start}`；
- `capture-report.json`：`{replay, frames, stages_seen[], nonzero_action_frames, distinct_actions[], frame_jumps, max_gap, foreground_fixes, ended_reason, elapsed_seconds, final_state{}}`。

### 7.3 语义

- 一行 = **一个真实游戏帧**（`gameplay_frame` 变化才写一行）；
- `action` 来自 `gui_input_current`（§2.1），不是 `input_mask`；
- 同一目录下所有分片属于同一数据集；`ReplayDataset` 按文件名排序拼接。

## 8. 检查点契约

`torch.save({state_dict, config, obs{N_SELF,N_BULLETS,N_BULLET_FEATURES,DANGER_ROWS,DANGER_COLS}, extra})`

- `config` 是 `models.NetConfig.__dict__`；
- `extra` 至少含 `epoch`/`val_loss`（BC）或 `step`（PPO）；
- 加载时 `obs` 维度不符 → `ValueError`；
- 文件名约定：`best.pt`（最佳验证）、`last.pt`（最新）、`ppo-<step>.pt`（周期快照）。

## 10. 错误处理与超时（逐项）

| 场景 | 行为 |
| --- | --- |
| 已有 `th08.exe` 在跑 | 启动前最多等 25 s；超时抛 `RuntimeError("another th08.exe is still running: [...]")` |
| 启动后停在致命对话框 | 检测 `#32770`，读取文本，抛 `RuntimeError("th08 start-up dialog: ...")`；最多重试 3 次 |
| 等标题/关卡超时 | `TimeoutError`，消息含 emoji-free 的描述（`timeout waiting for supervisor_state=1`） |
| `ReadProcessMemory` 失败 | `OSError`，含地址/长度/errno |
| 标题屏对象释放竞态 | 标题字段降级为 `-1`/`0`，不抛 |
| 数据集太小（< 2×batch） | BC 抛 `RuntimeError("dataset too small ...")` |
| 检查点观测维度不符 | `ValueError` |
| 回放播放结束 | 采集器写 `ended_reason="left game (supervisor_state=N)"` 并正常收尾 |

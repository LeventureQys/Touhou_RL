# S3-3 回放采集任务书

- 所属 Stage：Stage 3（开发）
- 依赖前置：S3-2 的 `obs.encode`（契约 §3）、S3-1 的会话层
- 并行状态：需等 S3-2（编码器）
- 所属阶段：开发

---

## 1. 背景与目标（零上下文）

TH08 录像（`.rpy`）按帧记录输入。回放播放时，游戏把录像输入写入
`g_GuiMessageInputCurrent`（`0x0161C674`），**不是** `g_CurFrameInput`（后者恒 0）。
因此「让游戏自己放录像 + 只读采样」就能得到 (状态, 专家动作) 对，无需注入、无需专家可查询。

本任务把这件事做成可复用命令，并落成可训练的数据集分片。

## 2. 交付物

```
touhou_rl/dataset.py           # ShardWriter / load_shard / discover_shards / ReplayDataset / stacked_batch
touhou_rl/capture_dataset.py   # capture_replay() + CLI
```

## 3. 契约要点

| 契约节 | 要求 |
| --- | --- |
| §7.1 | 分片键 `self_feat/bullets/danger/action/meta`，dtype/形状严格一致 |
| §7.2 | 每个分片旁车 JSON + `dataset-summary.json` + `capture-report.json` |
| §7.3 | 一行 = 一个真实游戏帧（`gameplay_frame` 变化才写）；动作来自 `gui_input_current` |
| §9 | CLI 参数与退出码 |
| §10 | 回放结束/阶段切换的处理 |

## 4. 关键行为（实测决定）

1. **阶段切换不是结束**：`SupervisorState` 会短暂变成 3/10/12，然后回到 2 继续下一关；只有 1（标题）、5/6（结算）、-1、9 才是结束；
2. **失焦掉帧**：窗口失焦时逻辑帧率从 60 降到 ~14，采集循环必须每 2 s 检查并夺回前台；
3. **回放文件安装**：把目标 `.rpy` 复制成 `<run_dir>/replay/th8_01.rpy`（菜单按序号枚举）；
4. **采样节流**：循环可以快于 60 Hz，靠 `gameplay_frame` 去重，保证不重复写同一帧。

## 5. 输入 / 输出

- 输入：`--replay <path>`、`--out <dir>`，可选 `--tag/--max-minutes/--shard-size/--stage/--run-dir`；
- 输出：`<out>/<tag>-NNNNN.npz`（+ `.json`）、`dataset-summary.json`、`capture-report.json`；
- 报告字段：`frames / stages_seen / nonzero_action_frames / distinct_actions / frame_jumps / max_gap / foreground_fixes / ended_reason / final_state`。

## 6. 可观察的验收标准

1. 用 `th8_ud2ce5.rpy`（Border Team Lunatic Final B）采集 ≥ 10 分钟：`frames ≥ 30000`、`nonzero_action_frames / frames > 0.9`、`distinct_actions` 覆盖 8 方向；
2. 采集跨越 Stage 1→2 时 `stages_seen` 含 0 和 1（不被误判为结束）；
3. 每分片 `frames == shard_size`（末片可少）；`dataset-summary.json` 的 `frames` 等于各分片之和；
4. `ReplayDataset(dir)` 的 `len()` 等于总帧数；`stacked_batch` 取出的形状与契约一致；
5. 采集结束（回放放完）时 `ended_reason` 形如 `left game (supervisor_state=1)`，且进程被关闭。

## 7. 禁止事项

- 禁止用 `input_mask` 当标签（必须 `gui_input_current`）；
- 禁止在采集循环里做模型推理/训练（保持采样节拍）；
- 禁止修改录像文件本身（复制副本）；
- 禁止把结束条件写成「`supervisor_state != 2` 就退出」（会漏掉后续关卡）。

## 8. 出错行为

| 情况 | 期望 |
| --- | --- |
| 回放菜单超时 | `TimeoutError("replay list did not appear")` |
| 播放未开始 | `TimeoutError("replay playback did not start")` |
| 中途卡住（90 s 无新帧） | 结束并写 `ended_reason="stalled during transition"` |
| 磁盘写入失败 | 冒泡 `OSError`，但 `finally` 仍关闭游戏进程 |

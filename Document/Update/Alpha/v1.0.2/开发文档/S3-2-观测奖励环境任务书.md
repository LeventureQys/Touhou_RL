## 1. 背景与目标（零上下文）

本任务把「只读状态」变成「可训练的信号」：菜单宏（进入游戏/回放）、观测编码、多目标奖励、
Gymnasium 环境。上层（采集/训练/评估）只依赖这里的接口。

设计动机（见 `训练方案与路线取舍.md` §4）：TH08 在单实例下只有约 20–30 决策/秒，因此观测必须
**信息密度高、维度小**：对象级子弹集合 + 低分辨率危险图 + 自机特征，而不是 640x480 像素。

## 3. 契约要点

| 契约节 | 要求 |
| --- | --- |
| §3.1 | `self_feat[24]` 逐项归一化；8 条射线判据 `along∈(0,320)`、`lateral<6+0.02·along` |
| §3.2 | 最近 64 发按距离升序；6 列含义与归一化；无效行第 5 列 = 0 |
| §3.3 | `danger[16,8]` = 48x28 像素格内子弹数（上限 255） |
| §5 | 6 分量顺序与公式；每分量裁剪 `[-10,10]`；权重非负 |
| §6 | `reset/step` 返回与 `info` 字段；`terminated` = 离开游戏态或 `lives<0`；`truncated` = 步数上限 |
| §2/§4 | 菜单跳转必须用「读回来的 `title_screen_current`/`cursor`/`replayCount` 校正」，不得只用固定延时 |

## 4. 菜单流程（实测，必须按此实现）

- 主菜单：`currentScreen==0`，光标项 0=Start、3=Practice Start、4=Replay；
- `Z` 后到难度选择（`currentScreen==4`/`8`），光标 0=Easy…3=Lunatic（`defaultDifficulty` 决定初始光标）；
- 再 `Z` 到角色选择（`5`/`9`），光标 = `GameManager.shotType`，0–3 是四个组合；
- 练习模式多一步选面（`11`）；
- 回放菜单保持 `currentScreen==7`，子状态在 `currentScreenState`：0=枚举、1=选录像、2=选关、3=选播放模式、4=退出；
- 回放文件从 `./replay/th8_NN.rpy`（NN=01..15）与 `./replay/th8_ud????.rpy` 枚举。

## 5. 输入 / 输出

- `obs.encode(state, bullet_field) -> Observation(self_feat f32[24], bullets f16[64,6], danger_map u8[16,8])`；
- `RewardEngine.reset(state)` / `.compute(state, terminal) -> (vector[6], info)` / `.scalar(vector) -> float`；
- `Th08Env(EnvConfig).reset() -> (obs_dict, info)`、`.step(action) -> (obs, reward, terminated, truncated, info)`。

## 6. 可观察的验收标准

1. `pytest touhou_rl/tests -q` 中观测/奖励/环境相关用例全绿（形状、归一化、射线单调性、危险图计数、奖励分量、权重校验）；
2. 真实游戏：`env.reset()` 后 `info["state"]["stage"]==0`、`lives==2`、`bombs==3`；
3. `env.step((0,1,0,0))` 连续 20 步：`gameplay_frame` 单调增、每步推进 `frameskip`±1 帧、无异常；
4. 失焦 30 秒内 `env` 能自动夺回前台（`_focus_guard`），游戏帧率恢复到 60；
5. 终止条件：残机耗尽或回标题时 `terminated=True` 且 `info["episode"]` 含帧数/关卡/得分。

## 7. 禁止事项

- 禁止在 `obs` 里引入像素；禁止把危险图分辨率改大以「看起来更清楚」；
- 禁止把奖励写成单一标量（必须保留 6 维向量）；
- 禁止用墙钟计步（只能用 `gameplay_frame`）；
- 禁止在 `env.step` 里隐式重启游戏（重启只允许发生在 `reset`）。

## 8. 出错行为

| 情况 | 期望 |
| --- | --- |
| `frameskip<1`、未知 `reset_mode`、`practice_stage` 越界 | `EnvConfig.validate()` 抛 `ValueError` |
| 菜单跳转超时 | `TimeoutError`，消息含目标 screen 编号 |
| `reset` 时游戏未到标题 | 先 `ensure_title`；失败则杀进程重启一次，再失败抛 `TimeoutError` |
| `step` 中游戏已退出 | 返回 `terminated=True`，不抛异常 |

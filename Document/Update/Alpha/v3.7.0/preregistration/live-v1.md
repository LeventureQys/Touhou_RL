## 3. 主指标与门（引用验收标准，不在此改动阈值）

- **B-01**：固定窗口每局死亡数下降 ≥20%，且配对死亡差 95% 区间上界 <0。
- **B-02**：独立核验的可撤离事件按时撤离率 ≥90%，每臂 ≥30 个可判事件。
- **B-03**：每局 bomb 均值不高于 baseline，并报告每千帧率、清弹与无敌分层。
- **B-04**：输出/关卡进展口径在 R1 选定后冻结，新方案/baseline ≥90%。
- **B-05**：完整决策比例与有效配对 ≥99% / ≥90%。
- **B-06**：P95 ≤33.3 ms，错过截止 ≤1%。

阈值只来自[验收标准](../验收标准.md)；本文件不复制数值以外的任何放宽。

## 4. 必报的诊断（即使主指标通过）

死亡归因（提前选位/入坑、预测误差、局部执行、输入缺失、资源事件、未知）、贴墙率、方向切换率、回退率、未知实体比例、性能 P99、`framerateMultiplier` 非 1 的帧数、`observed_frame_age` 分布、bomb 分层结果。

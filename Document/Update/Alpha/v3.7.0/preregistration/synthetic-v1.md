## 3. 边界实例（E-01 … E-20）

设计与目标家族见 `seeds-v1.json` 的 `edge_instances`。每个实例要求：

1. 有**独立**参考解或解析判定（不得由受测规划器自评）；
2. 结果可人工逐帧复核；
3. 记录“预期标签”与“实际标签”，不一致时先修测试台，不改预期。

其中直接约束几何与时间语义的几个：

- **E-05/E-06**：缺口恰好比 hurtbox 宽 3 px / 窄 1 px —— 用于防止“过度膨胀把可行缝封死”与“把不可行缝当可行”。
- **E-11/E-12**：真无解 vs 预算耗尽 —— 用于 A-06 的标签正确性。
- **E-13/E-14**：弹墙在第 180 / 181 帧到达 —— 用于防止“视界末端当成永久安全”。
- **E-19**：线性模型精确的对照样例（SC-13 的零噪声基线）。

## 4. 判定口径（引用，不新造）

- 成功：完成场景及其保持窗口、无碰撞、未使用 bomb（M1）；保持窗口首轮 60 帧。
- 按时撤离：实际启动不晚于参考求解器给出的最迟安全启动时刻（M3）。
- 可避免封死：起始有解、随后进入已证无路状态（M2）；`unknown` 单列。
- 门禁状态只有 `not_started / pass / fail / invalid / underpowered`；当前全部 **not_started**。

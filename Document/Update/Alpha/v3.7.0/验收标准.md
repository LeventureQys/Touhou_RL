# v3.7.0 验收标准：提前撤离，而非贴脸才闪

- 日期：2026-10-25
- 状态：需求阶段拟定门槛；尚无测试结果。
- 关联：[需求文档](<需求文档.md>)。
- 正式实验前必须冻结测试清单、参数、分母、统计脚本和本文件版本。若可行性试验发现需改动，另记修订，并使用新的未见测试集；不得回看正式结果后修改门槛。

## 1. 场景矩阵

每类至少 30 个独立留出参数种子；另外建立不少于 20 个可人工/解析核验的确定性边界实例。家族、参数范围和种子在 R1 固定。

| ID | 场景 | 必须体现的行为 | 重点防止的假通过 |
|---|---|---|---|
| SC-01 | 宽幅扇形向自机展开，外侧有可达出口 | 在最迟启动时刻前持续横向撤离 | 弹幕贴脸后碰巧擦过 |
| SC-02 | 弹墙只有一个缺口 | 提前对齐并按时通过 | 只看终点空、途中撞墙 |
| SC-03 | 扩散环，外绕不可行但内缝可过 | 选择可行穿缝路线 | 把整片区域膨胀成永久禁区 |
| SC-04 | 左右出口距离/关闭时间不同 | 选择能按时到达的一侧 | 选择最近却已关闭的出口 |
| SC-05 | 第一波后有延迟第二波 | 避免假安全终点 | 只躲过第一波就计成功 |
| SC-06 | 墙边/角落将被封锁 | 提前离墙，保留后继动作 | 贴边静止刷安全分 |
| SC-07 | 相同空间位置先后被弹幕经过 | 利用时间窗口等待或穿越 | 把未来占据全并成静态障碍 |
| SC-08 | 某两观测帧之间发生穿越碰撞 | 判定途中碰撞并避开 | 离散终点检测漏碰 |
| SC-09 | 远处弹墙/高弹数、局部当前安全 | 将封路危险纳入路线 | 近邻/弹数截断漏掉整面弹幕 |
| SC-10 | 撤离中出口突然变化 | 中断并重规划 | 方向稳定性锁死错误按键 |
| SC-11 | 当前路线安全，旁边有 P/输出诱惑 | 保持安全撤离优先 | 为收益一头扎进弹幕 |
| SC-12 | 真无解、模型未知、搜索超时 | 分别标记并执行审计回退 | 没搜到路线就宣称物理无解 |
| SC-13 | 小幅加速/转弯弹与运动估计噪声 | 在声明支持域内保守处理，域外显式降级 | 匀速假设失效仍报高置信安全 |
| SC-14 | 镜像/位置平移与初始 focus 改变 | 行为随几何及真实速度变化 | 死记固定向左/向右或固定按键 |

SC-12 的无解样本不进入“有解成功率”分母；未知样本单列。SC-13 未支持的类型必须公开覆盖缺口，不能用排除后的小分母宣称支持全部弹幕。

## 2. 指标定义

### M1 专项通过率

每个有解实例，完成整个场景及其预定义后继保持窗口、无碰撞且未使用 bomb，记为成功。提前终止、超时或停在结束区外不算成功。保持窗口按场景冻结，首轮建议不少于 60 游戏帧。

### M2 可避免封死率

在预定义场景观察窗口内，起始状态经独立参考求解器确认有解，而策略进入已证实无路线状态的场景数 / 起始确认有解场景数。每场景最多计一次，unknown 单列。真机若无可靠反事实求解能力，不把这个数包装成真实物理无解率，改报“预测封路事件”并给出人工核验子集。

### M3 提前撤离率与提前量

仅在预标注“需要主动撤离且存在有效启动窗口”的场景上统计。按需求中的延迟协议确定最迟启动时刻；实际启动不晚于该时刻记为按时。报告按时比例及提前量的中位数、P10，不仅报告平均值。有效进展距离、持续窗口在 R1 固定。

### M4 安全与资源

- 固定游戏时长窗口内的真实死亡数（允许按固定规则重生继续），不是只比较首次死亡前动作数。
- bomb 使用数及每千游戏帧使用率；无敌期与清弹收益单列。
- 完整窗口曝光时长、生存帧数、stage clear、退出/截断原因。
- 射击开启率、有效输出或敌人/Boss 进展、贴墙率、方向切换率。
- 不能用更早结束一局减少死亡分母；每对必须拥有同口径曝光，未完成窗口按预注册缺失规则处理。

### M5 性能与覆盖

观测到动作提交的端到端 P50/P95/P99 耗时、错过控制截止时间比例、规划超时率、回退率、未知实体比例、输入完整率。GPU 异步计算必须在正确同步点计时，不能只计提交耗时。

## 3. R2：契约和合成专项门

以下条件全部满足才进入 R3：

| 编号 | 判据 | 拟定门槛 |
|---|---|---|
| A-01 | 时间单位、几何、速度、帧对齐、路径扫掠、reset/缺帧、超时测试 | 必需测试全部通过；已知必须避开的确定性穿越实例漏检为 0 |
| A-02 | 有解专项成功率 | 总体 ≥90%，各有解家族 ≥80%；逐家族公开分母 |
| A-03 | 需要撤离场景的按时撤离率 | ≥90% |
| A-04 | 可避免封死率相对固定 baseline | 下降 ≥30%；若 baseline 无此类事件则 underpowered，不能除以零 |
| A-05 | 时间窗口、内部穿缝、第二波、远处封路四类负例 | 确定性边界实例全部通过 |
| A-06 | 未知/无解/预算耗尽区分，日志与可视化 | 全部边界实例标签正确；必需 trace 字段完整 |

这里的比例是功能目标，不是已经证实的效果。至少用一个未修改的旧版短视 pilot 作基线；合成测试对两臂使用相同动力学、碰撞规则和资源权限。

## 4. R3：特权真机比较门

### 4.1 协议

- 候选沿用 TH08 1.00d、Lunatic、team 0、frameskip=2；开跑前记录版本哈希和速度复核结果。
- 每臂至少 30 局，以 30 对为最低起点；功效分析若要求更多，在正式开跑前增加并固定样本量。各对须来自有效不同的初始条件，不能重复确定性同局充数。
- 同一对使用相同初始化/热身条件，热身不得使用 bomb；臂顺序随机交错并记录。
- 评估窗口、重生继续规则、baseline 配置、随机种子、数据质量停止线提前冻结。
- 以整对/整局为统计单位做配对 bootstrap，至少 5000 次，报告点估计和 95% 区间；帧不是独立样本。
- 正式集不调参；只在独立开发集上决定预测视界和计算预算。

### 4.2 全部通过条件

| 编号 | 判据 | 拟定门槛 |
|---|---|---|
| B-01 主效果 | 固定窗口的每局死亡数相对 baseline 下降 | ≥20%，且配对“新方案−baseline”死亡差的 95% 区间上界 <0 |
| B-02 专项目标 | 预定义且独立核验的可撤离弹幕事件按时撤离比例 | ≥90%；两臂各至少 30 个可判事件，不足则专项证据 underpowered |
| B-03 资源约束 | 每局 bomb 均值 | 新方案不得高于 baseline；并报告每千帧率、清弹与无敌分层结果 |
| B-04 输出非退化 | 相同有效游戏曝光下输出/关卡进展 | R1 选择唯一主口径并冻结；新方案/baseline ≥90%，基线为零时另定适用口径而非除零 |
| B-05 数据质量 | 完整决策比例与有效配对 | 每臂 ≥99%，有效对 ≥预注册样本的90%；失败则先修记录/环境，不继续作效果结论 |
| B-06 实时性 | 端到端控制时限 | frameskip=2 且游戏60fps时 P95 ≤33.3ms；错过截止时间比例 ≤1%；不得靠降游戏速度通过 |

额外必须报告死亡归因、贴墙率、切换率、回退率、性能 P99 和输入未知覆盖。bomb 均值约束是最低资源门，不等于证明资源使用完全等价；需用禁 bomb 专项和分层数据支撑“真正会提前撤离”的结论。

若 baseline 死亡为零或事件不足，记录 underpowered 并另开更有挑战的预注册测试，不能临时改分母、拼接帧样本或降低阈值。

## 5. R4/R5：训练、消融与视觉交付门

开发集至少比较：

1. 固定旧版短视 baseline。
2. 仅延长规划视界，不增加出口/后继项。
3. 时间危险 + 可达路线。
4. 完整方案，再加入可中断持续意图。

公开各自视界、候选数量、实际耗时和参数，避免把更大算力收益误称为特定结构收益。若某模块没有增益，允许不保留，但必须给出证据。

视觉验收必须重新执行适用的 A/B 门：

- 纯视觉结果独立成表，不借用特权成绩。
- 禁止读取内存、真值子弹位置、未来帧或特权自机位置；记录实际输入依赖。
- 报告自机定位、未来危险漏检/误报及未知覆盖，分析感知错误导致的路线失效。
- 不允许仅凭教师模仿准确率、离线 AUC 或预测图好看宣称会躲范围弹幕。
- 若仅完成特权原型，明确标注 R5 未启动/未通过。

## 6. 正式验收应保留的证据

冻结配置与数据清单哈希、逐局/逐事件结果、配对关系、完整 trace、统计脚本输出、参考求解器标签和 unknown、成功与失败回放、输入依赖审计、性能记录、消融表，以及结论的适用范围。

## 7. 路线强化补充（2026-10-25，尚未运行实验）

对应用户“多数死亡来自钻入必死弹幕群”的补充，本次增加控制优先级验证，不修改既有 A/B 门槛，也不将用户经验写成已测比例。

### 7.1 必增场景

| ID | 场景 | 验收重点 |
|---|---|---|
| SC-15 | 眼前较宽空隙通向封死区，较窄但满足安全余量的路线通向宽出口 | 不选局部 clearance 最大却无后继的路线；有已验证替代路径时拒绝高置信入坑动作 |
| SC-16 | 自机周围空旷，但出口将在 90–180 帧视界内逐渐关闭 | 不等近弹阈值触发；按自身到达时间与误差余量提前撤离；远期未知不得伪装成确定安全 |
| SC-17 | 独立零散子弹，未形成宏观封锁 | 保留局部避弹能力，不因宏观误判过度换位或误屏蔽正常可行动作 |

新增家族同样至少 30 个独立留出参数种子；SC-15/16 纳入适用的 A-02/A-03 门。SC-17 单独作为回归集，不用大量简单零散弹稀释范围弹幕专项分母。

### 7.2 新增功能门与诊断

- **A-07 入坑拒绝门**：在独立解析/求解器可核验、输入完整且存在安全替代路线的确定性 SC-15 实例上，高置信进入封死区的动作被执行次数为 0；须检查实际动作与轨迹，不能只看控制器自报“已拒绝”。
- **A-08 局部回归门**：SC-17 禁 bomb，成功率 ≥95%，且相对固定旧版局部 pilot 的点估计下降不超过 2 个百分点；逐种子配对报告区间，样本量不足以支持非劣结论时不得声称统计等价。原型前在开发集测量 baseline，正式测试前完成样本量与非劣检验预注册。
- 诊断必须展示：主动进入事件数、进入前可用出口、首次预警到实际撤离间隔、因局部 clearance 诱惑而离开走廊的次数，以及安全约束误拒绝率。
- 真机死亡审计至少区分：提前选位/入坑、预测误差、局部执行、输入缺失、资源事件、未知；报告占比与未定比例。不能因为尚未证明“多数”就阻止原型，也不能靠主观标签宣称该假设已证实。
- 消融补充比较“软奖励偏好”和“高置信进入动作筛选”，公开误屏蔽和回退代价。旧 baseline 不变；更激进路线仍必须满足 B-03 资源门、B-04 输出门与 B-06 实时门。

门禁状态限定为：not_started / pass / fail / invalid / underpowered。当前所有实现与实验门均为 **not_started**。

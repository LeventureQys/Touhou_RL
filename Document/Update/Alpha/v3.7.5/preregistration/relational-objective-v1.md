# 关系型目标预注册 v1

- 状态：planned
- 适用版本：v3.7.5
- 目的：验证模型是否学习 gap 相对自机的位置关系
- 当前限制：真实像素数据尚未采集

## 目标

主目标为 gap_center - player_x 的连续值或区间。屏幕左/右分类只作为诊断，不作为主目标。

## 数据要求

- 左右两个朝向；
- 不同自机横向位置；
- 左右边缘位置；
- 完整事件分组；
- train、validation、test 按 template group 互斥；
- 输入只含当前和过去的像素、历史动作及显式有效性；
- 不含未来像素、教师目标、特权状态或完整弹池。

## 实验臂

- B0：冻结基线；
- B1：无记忆宏观头；
- N0：无 option/target 条件的时序残差；
- N1：完整时序分层策略。

所有臂使用相同事件、预算、split 和三个 seed。先冻结视觉骨干，只有在诊断失败且单因素预注册后才允许解冻。

## 主要判定

- 8 个可靠事件过拟合时动作正例一致率至少 95%；
- 留出集目标方向有明确方向性；
- 骨干 SHA 不变；
- unknown 样本不产生梯度；
- 训练集有效而留出无效时判定为 overfit，不进入闭环或部署。

本文件不是训练结果报告。

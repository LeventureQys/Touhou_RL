# 预注册（修订）：像素信息量探针 round27b

- 写入时间：2026-11-02，在 27b 任何渲染/训练之前。上游是本目录的 [p1-pixel-info-round27.md](<p1-pixel-info-round27.md>)。
- 为什么要修订：27 的第一次执行**被它自己的控制项判为无效**——直读器 12/12 + 120/120 全对（说明预告渲染里确实有方向信息），但 Q5 的"仅用自机位置"基线拿到 **0.80**（预注册要求 ≤0.60），说明生成集的 `start_x` 与标签相关（`label=+1` 时 `start=gap−offset`，`−1` 时 `start=gap+offset`，裁剪后两类位置分布不同）。这正是 R24 记录过的"98.5% 可解码＝玩家 x>192"陷阱。CNN 在镜像迁移上只有 0.45（低于随机），与"只学到自机位置、镜像后规则翻转"一致。
- 另外，27 的 CNN 用 `AdaptiveAvgPool2d(1)` 把空间布局压成一个向量，**结构上无法表达"缺口在自机左边还是右边"**。这是我在预注册里选错的头，不是判据问题。

## 只改这三处（判据 Q1–Q6 原样保留）

| 项 | 27 | 27b |
|---|---|---|
| 生成集采样 | `start_x = gap ∓ offset`（位置与标签相关） | `gap_center ~ U[80,304]`、`start_x ~ U[16,368]` **独立采样**，只保留 `|gap−start| ≥ 30`；两类数量配平到 ±2 |
| CNN 头 | `AdaptiveAvgPool2d(1)`（空间无关） | `AdaptiveAvgPool2d((4,4))` → Flatten → Linear（保留 4×4 空间布局） |
| 训练步数 | 300 | 600（27 在 60 个样本上只跑 300 步，欠拟合与不可学无法区分） |

**不改**：Q1–Q6 的通过条件、3 个 seed（7/17/27）、标签定义、决策帧 `wall−44`、132 个世界（120 生成 + 12 有效世界独立留出）、镜像迁移协议（只训练 base、测试 mirror）。

## 新增两个自证项（不参与通过判定，但必须报告）

- **P1 位置基线**：27b 的生成集上，"仅用自机位置"的逻辑回归必须 ≤0.60，否则整个探针作废（与 Q5 相同，但单独列出以便区分"数据集仍脏"和"控制臂过强"）。
- **P2 遮挡控制**：把预告带颜色替换成背景色后，直读器必须全部读不出（应为 132/132 不可读），用来证明直读器读的确实是预告带，而不是其它像素结构。

## 判定

与 27 完全一致：

- Q1∧Q2∧Q3∧Q4∧Q5∧Q6 全过 → "信息在像素里且可学"；
- Q1 过、Q3 不过 → "信息在但这个小 CNN/这个规模学不到"，下一步是数据与读出；
- Q1 不过 → "渲染没有编码方向"。

任何一条不过如实上报，不换 seed、不调阈值、不挑最好的一次。27 的 attempt-1 证据保留在 `evidence/pixel-info-round27/attempt-1/`，不删除、不改写。

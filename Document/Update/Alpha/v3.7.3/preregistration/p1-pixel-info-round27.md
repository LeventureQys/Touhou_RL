# 预注册：F1 方向信息是否在像素里（round27）

- 写入时间：2026-11-02，**在本轮任何渲染/训练/计数之前**。
- 上游：[synthesis-round25](<../reports/synthesis-round25.md>) 把合成学习线的卡点收敛为"镜像方向"，并列出四个未检验的单因子；[P4-telegraph-round21](<../reports/P4-telegraph-round21.md>) 已经"把缺口画出来"，训练反而更差（F1 留出 A 3/3/3→2/2/2）。本轮不训练策略，只回答一个更前置的问题：**"该往左还是该往右"这件事，在决策时刻的像素里到底有没有、能不能学？**
- 与真实像素路径的关系：本轮用的是**合成渲染器**，不是真机；它只用于判定"任务构造是否信息不足"，不产出任何可部署结论，也不改动 P0/P3 的结论。

## 1. 三种可能，先写死怎么区分

| 结果 | 含义 | 下一步该做什么 |
|---|---|---|
| 直读器能从像素读出方向 | 信息在像素里，且不需要学习 | R21 的失败不是"信息缺失"，必须转向策略目标/骨干/优化 |
| 直读器读不出、CNN 能学 | 信息在像素里但需要学习提取 | 加数据/换读出，不是加预告 |
| 直读器和 CNN 都失败 | 渲染没有编码方向 | 先修渲染，任何训练都是浪费 |

## 2. 数据与标签

**标签**：`y = sign(gap_center_screen − player_x_screen)`，其中 `gap_center_screen` 取自 `telegraph_gap(world)`（已按 mirror 变换到屏幕坐标），`player_x_screen` 是渲染时自机在 playfield 的 x（0..383）。左=−1，右=+1。

**决策时刻**：`f0 = max(2, wall_frame − 44)`（偶数帧，落在 R21 预告窗口 `[wall−45, wall)` 内），自机从初始位置按"保持不动"因果推进到 f0，只渲染一帧。不做任何动作，不读未来。

**两臂**：
- A（有预告）：`v373_telegraph.render_state_telegraph`
- B（无预告，对照）：`tactical_synthetic_pixels.render_state`

**数据来源（三个集合，互不混用）**：

| 集合 | 数量 | 用途 |
|---|---|---|
| 生成集-基座 | 60 组（每组 1 个 base 世界） | CNN 训练 |
| 生成集-镜像 | 与上面同组的 60 个 mirror 世界 | CNN 测试（镜像迁移，**训练只见过 base**） |
| R18 有效世界 | 12 个（6 组 × 2 镜像，`wf18-F1-*`） | 独立留出，**不参与训练/调参** |

**生成规则**（防止捷径）：
- 生成集的 `start_x` 必须使 `|gap_center − start_x| ∈ [30, 120]` px，正负各半 → 标签平衡；因此"只看自机位置"无法预测标签。
- 组内镜像对：canonical 几何相同，mirror 世界把 gap 变换到屏幕镜像位置、`start_x = 384 − start_x_base`，标签因此翻转。
- 其余字段沿用 R18 域：`coverage ∈ {[8,376],[8,372],[12,376],[16,368]}`，gap 宽 12–20，`wall_frame ∈ [48, 90]`，`internal_gap=True`，`horizon=160`，`fire_interval=16`，`bullet_speed=8`。
- 数据 SHA 落盘；生成脚本固定 seed。

## 3. 判据（先写死）

| 编号 | 判据 | 通过条件 |
|---|---|---|
| Q1 | 直读器（无学习）在 A 臂能读出方向 | R18 有效世界 **12/12** 标签与像素读数一致；生成集 **120/120** |
| Q2 | 直读器在 B 臂读不出 | A 臂同算法在 B 臂上返回 None 或 ≤70%（预期：没有预告带，读不出） |
| Q3 | CNN 在 A 臂的镜像迁移 | 生成集 base→mirror 准确率，3 个 seed 均值 **≥ 90%** |
| Q4 | CNN 在 A 臂的独立留出 | R18 12 个有效世界 **≥ 10/12**（三 seed 均值） |
| Q5 | CNN 在 B 臂无捷径 | B 臂同样协议准确率 **≤ 70%**；且"自机位置单特征逻辑回归"基线在生成集 **≤ 60%** |
| Q6 | 两臂渲染仅在预告窗口不同 | 同一世界同一帧，A/B 图像在 `[wall−45, wall)` 之外的字节差异 **0**（渲染器自证） |

判定规则：
- **Q1∧Q2∧Q3∧Q4∧Q5∧Q6 全过** → 结论"信息在像素里且可学，R21 的失败不是信息缺失"。
- Q1 过但 Q3 不过 → "信息在，但这个小 CNN/这个规模学不到"，下一步是数据与读出，不是再加预告。
- Q1 不过 → "渲染没有编码方向"，先修渲染。
- 任何一条不过都如实上报，不改判据、不换 seed 重试到过（seed 固定为 7/17/27，三个全报）。

## 4. 方法细节（固定）

- **直读器**（纯像素，不读 world）：
  1. 取 playfield `image[16:464, 32:416]`；
  2. 预告带颜色 `(44,58,74)`、缺口边缘色 `(96,148,128)`（来自 `v373_telegraph` 常量）；
  3. 边缘色的列聚成两簇，缺口 = 两簇内边界之间；缺口中心 = 两内边界中点；
  4. 自机 x = 青色 `(90,225,255)` 像素列的中位；
  5. 输出 sign(缺口中心 − 自机 x)；列聚类不是两簇或找不到自机 → 返回 None。
- **CNN**：输入 playfield 下采样到 96×112 RGB（`float/255`）；Conv3→16(s2)-Conv16→32(s2)-Conv32→64(s2)-ReLU-GAP-Linear(64,1)；Adam 1e-3，300 步，batch 32，BCE；无翻转增强（翻转会改标签）。
- 3 seeds = 7/17/27，报告每 seed 与均值，不看最好的那个。
- 运行环境：本机 RTX 4070 SUPER；CPU/GPU 差异不作结论，只固定同一设备。

# F1 方向信息在像素里：可读、可学，但不是"再加预告"能解决（round27）

- 日期：2026-11-02。预注册：[p1-pixel-info-round27.md](<../preregistration/p1-pixel-info-round27.md>) 与其修订 [p1-pixel-info-round27b.md](<../preregistration/p1-pixel-info-round27b.md>)。
- 本轮**不训练策略、不产生权重、不碰真机**。它只回答 [synthesis-round25](<synthesis-round25.md>) 卡住的那个前置问题：R21 加了预告反而更差，到底是"像素里没有方向信息"，还是"策略不用它"？
- 结论先说：**信息在像素里，且一个二十行的直读器就能 492/492 全对；同一份像素上，一个小 CNN 在"两个朝向都出现在训练集"时能到 0.90 的组留出，但预注册的严格两关（只训练 base 的镜像迁移 ≥0.90、边缘位置留出 10/12）没通过。所以"再加预告/再加数据"不是下一步，关系型读出与目标才是。**

## 判据结果

| 判据 | 结果 | 数字 |
|---|---|---|
| Q1 直读器（无学习）读出方向 | **通过** | R18 有效世界 **12/12**；生成集 **480/480** |
| Q2 无预告时直读器读不出 | **通过** | 0/492 可读（同一算法） |
| Q3 CNN 只训练 base → 测试镜像 | **未通过** | 3 seed：0.854 / 0.854 / 0.871，均值 **0.860**（门槛 0.90） |
| Q4 CNN 在 12 个有效世界留出 | **未通过** | 3 seed：0.50 / 0.50 / 0.583，均值 **0.528**（门槛 10/12） |
| Q5 控制臂与捷径 | **通过** | 无预告臂 0.55/0.54/0.52（均值 0.538 ≤0.70）；"仅自机位置"基线 **0.492 ≤0.60** |
| Q6 两臂只在预告窗口不同 | **通过** | 490/490 个世界在窗口外逐字节相同 |

附加自证（不进门）：**遮挡控制**把预告带两种颜色替换成背景后，直读器 **0/492** 可读——它读的确实是预告带，不是别的像素结构。

按预注册判定规则：Q1/Q2/Q5/Q6 过、Q3/Q4 不过 → **"信息在，但在这个规模/这个严格门槛下没学到"**。下面把"没学到"拆开，因为拆开之后结论完全不同。

## "没学到"其实是三件事，不是一件

### 1. 信息是可读的（决定性）

直读器只做四件事：取 playfield、按预告带颜色 `(44,58,74)` 与缺口边缘色 `(96,148,128)` 找出缺口两缘、用青色 `(90,225,255)` 找自机列、比较两列位置。它在 480 个生成世界与 12 个 R18 有效世界上**全对**，在无预告渲染上**一个也读不出**。

这条直接否掉了"任务信息不足"的解释：R20 的"缺口在致命前从未渲染"是**旧渲染**的事实，R21 的预告带已经把它画出来了，而且画得足够清楚，清楚到不需要学习。**R21 训练更差，不是信息缺失。**

### 2. 关系是可学的，只要训练里见过两个朝向

| 训练/测试 | 3 seed | 说明 |
|---|---|---|
| 只在 base 上训练，测镜像 | 0.854 / 0.854 / 0.871（均值 0.860） | 训练集拟合 0.933–0.938，说明模型确实学了东西 |
| base+mirror 混合训练，按组留出 20% | 训练 0.90–0.93、**组留出 0.896 / 0.906 / 0.917** | 见过两个朝向时，关系能泛化到**没见过的世界组** |
| 不做非线性、直接在线性层上读下采样像素 | **0.808**（镜像测试） | 连线性模型都能从空间布局里读出方向 |

也就是说：**"缺口相对自机在哪边"是一个几乎线性的、可由梯度下降学到的关系**——前提是训练分布里两个朝向都出现。

### 3. 严格两关为什么没过：不是信息问题，是分布外

- **Q3（0.860 < 0.90）**：只喂 base，模型仍能到 0.86，但差 4 个百分点；它部分依赖了绝对位置而不是纯关系。
- **Q4（0.50）**：12 个有效世界的自机在 `x=56 / 328`，而生成集为保证"任一 x 两个标签都可行"把自机限制在 `x ∈ [110,274]`。**留出世界整个落在训练分布之外**，模型退化成常数。这是外推失败，不是"读不出方向"——同一批世界上直读器 12/12 全对。

这两个失败指标的是**生成分布太窄**，不是像素欠信息。把它们读成"F1 不可学"会重复 R20 的错误（把构造缺陷当成能力结论）。

## 对 v3.7.3 计划的影响（三句话）

1. **停止"再加预告"这条线**：预告已经足够（492/492 可读），R21 的负结果不是预告不够，而是策略目标从未要求"比较缺口与自机"。再加 45 帧预告只会重复 R21。
2. **下一步单因子应该是"关系型读出/目标"，不是更多的数据或通道**：把"缺口相对自机"作为显式比较（例如按列 profile 的差、或让辅助头直接回归 `gap_center − player_x`，而不是分类"屏幕左/右"），并且**训练分布必须同时包含两个朝向与边缘位置**。
3. **P3/P4 的门不变**：本轮没有产生任何可训练权重或真机结论；它只把"任务信息不足"这个解释删除，并把"策略不用信息"从推测变成了排除后的唯一候选（与 R22/R24 的"表征里有、行为不用"一致，但这次是在**像素层**证实的）。

## 三次执行与两次自证失败（全部保留）

| 执行 | 结束原因 | 学到的 |
|---|---|---|
| 27（`attempt-1/`） | Q5 的自机位置基线 **0.80 > 0.60**：生成集用 `start = gap ∓ offset`，位置与标签相关 | 这正是 R24 记录过的"98.5% 可解码＝玩家 x>192"陷阱；数据集作废 |
| 27b 第一次（`27b/attempt-1/`） | 独立采样 + `|gap−start| ≥ 30` 过滤，仍 0.83 | 过滤本身在边缘制造了"某标签不可能"，相关没除掉 |
| 27b 第二次（`27b/`） | 数据干净了（位置基线 0.492），但探针**损失为负**（−283,965） | 把 ±1 标签喂给了 `BCEWithLogits`（要 0/1）：网络根本没在训练 |
| 27c（`27c/`） | 修了标签前的诊断版，同样带 bug | 保留，用于说明"负损失"这一现象 |
| **27d（`27d/`，正式）** | 修标签 + 加 `loss < 0` 断言 + 加混合朝向诊断 | 本报告所有数字 |

两次失败都是**本轮自己的控制项/断言抓住的**，不是靠外部复核；这也是为什么预注册里那两条"自证项"（位置基线、遮挡控制）值得留着。

## 限制（必须一起读）

1. **合成渲染，不是真机**：结论只适用 F1 的玩具渲染器；不能外推到真机像素，也不改变 P0/P3 的结论。
2. **直读器用了预告带的具体颜色**：它证明"信息在那儿且可直接提取"，不证明"任意视觉模型都会提取"。
3. **CNN 不是策略**：它只说明"这份像素上关系可学"，不说明 v3-st+GRU 能学到，也不说明学到的能在闭环里用。
4. **生成分布窄**：自机被限制在 `x ∈ [110,274]` 以保证标签与位置独立；边缘位置没有覆盖，Q4 的失败应读成分布外，而不是不可读。
5. **Q3 差 4 个百分点就判失败**：这是预注册门槛，未放宽。0.86 也不该被说成"通过"。
6. **没有 seed 挑选**：7/17/27 三个全报。

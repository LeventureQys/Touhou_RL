## 三、逐层排除的四个原因

1. **信息没画出来？** F1 的缺口在致命前从未渲染（镜像对初始帧只差玩家精灵 154 像素）。补上 45 帧预告后仍失败，且**唯一变化是同一 head 从"停在缺口 248"变成"hold 在 216"**（[P1-f1-visibility-round20.md](<P1-f1-visibility-round20.md>)、[P4-telegraph-round21.md](<P4-telegraph-round21.md>)）。
2. **缺空间通道？** 加 F8 池化 + 行列 profile 的零初始化融合，F1 留出 **A=S=2/2/2**，14 个事件 first-hit 逐 seed 全同；融合层 94.4% 学成常数偏置（[P4-spatialfuse-round22.md](<P4-spatialfuse-round22.md>)）。
3. **缺监督信号？** 加特权辅助任务（缺口侧别），标签从"相对屏幕"改到"相对玩家"：前者把镜像从 3/9 打到 1/9，后者把 F1 留出抬到 3/3/3 但**镜像 0/9、屏幕方向变成 18 右/0 左/0 hold**——两次都是"恒定向右"的塌缩换形（[P4-privaux-round23.md](<P4-privaux-round23.md>)、[P4-prelaux-round24.md](<P4-prelaux-round24.md>)）。
4. **缺数据？** F1 训练组从 6 扩到 12（24 事件，全部过六基线判据），新增留出里"需要向左"的 21 格**翻转 0/21**，而"需要向右"的 21 格保持 21/21（[P4-f1scale-round25.md](<P4-f1scale-round25.md>)）。

## 四、卡点：镜像方向

| 事实 | 出处 |
|---|---|
| 冻结底座本身 mirror-blind：镜像世界仍 16–22/22 投屏幕向右 | R22 |
| 策略在任何干预下都收敛到"屏幕向右/不动"，从不按镜像翻转 | R21/R23/R24/R25 |
| R22 曾测出"256 维特征可解码缺口侧 98.5%"，但 R24 发现该标签在留出 6/6 等价于"玩家 x>192" | R22 / R24（已回写台账） |
| 自造 94 维池化向量只有 67% 可解码；一列 F8 = 16 原生像素，而缺口 12–20px | R22 |
| 辅助标签 12/12 与教师首动作同向，但教师 6/12 在锚定行动 hold → 标签只有方向、没有时机 | R24 |

一句话：**现有冻结表征 + 单路线模仿的目标，无法把"缺口相对我该往哪边"表达成可执行的方向决策**；再加数据、再加辅助任务、再加池化通道都只是让塌缩更纯。

## 五、下一步（按证据排序，均为单因子）

1. **分辨率/定位通道**：用 F4（56×48，8 px/列）在玩家附近取相对坐标的列 profile，而不是全场池化；先验证线性可解码"缺口 − 玩家"符号 ≥95%，再谈训练。当前证据显示这条路还没被证伪（R22 的自制通道设计太粗，不能代表 F4）。
2. **把"何时动/何时停"变成一等目标**：教师 6/12 在锚定行 hold，而单路线模仿给不出时机；可试 stop/move 二分类头或两段式显式监督。
3. **结构耦合**：把辅助头与策略头共享（而非只在 GRU 状态上挂线性探头），避免 R24 的"头不泛化 + 策略不理"。
4. **换任务难度梯度**：先在"只需一次横向移动"的极简世界上验证最后 0.9 的差距能否闭合，再回到 F1/F3。

## 六、没有做到的事（必须与结论同读）

- 真实像素训练仍未开始：P0 的显示相位/弹池同步被冻结为 `unknown`（[P0-exit-round15.md](<P0-exit-round15.md>)），P3 真机数据、P6 真机小试、P7 独立确认全部阻断。
- 合成结论只覆盖固定 y 的玩具世界，F2 只有 4 例、F3 全族 0/6，均不足以外推到真实游戏。
- 没有任何可部署产物：默认模型未替换，所有研究权重都是 research-only schema。

## 七、补记（2026-11-02，round27）：把"信息缺失"这个解释删掉

本文件第五节把"分辨率/定位通道"列为第一个待检验单因子，其隐含前提是"方向信息可能没有被画出来/表达不出来"。[round27](<P1-pixel-info-round27.md>) 直接测了这件事：

| 测量 | 结果 |
|---|---|
| 二十行直读器（不学习）在预告渲染上读"缺口在自机哪边" | **R18 有效世界 12/12、生成世界 480/480** |
| 同一读法在无预告渲染上 | 0/492 可读 |
| 遮挡预告带后 | 0/492 可读（读的确实是预告带） |
| 小 CNN 只训练 base → 测镜像 | 0.854 / 0.854 / 0.871（均值 0.860，未达预注册 0.90） |
| 小 CNN 两个朝向都训练 → 按组留出 | **0.896 / 0.906 / 0.917** |
| 线性层直接读下采样像素 → 测镜像 | 0.808 |
| 12 个有效世界留出（自机 x=56/328，训练分布外） | 0.50（外推失败，不是读不出） |

所以：

1. **"信息没画出来"不成立**（在 R21 的预告渲染上）——R21 训练更差不能再用"预告不够"解释。
2. 方向关系**是可学的**，前提是训练分布里同时出现两个朝向；这正好是 R21–R25 的训练协议缺的东西（单一朝向 + 单一模仿目标）。
3. 第五节第 1 条"分辨率/定位通道"的优先级应下调：不是分辨率不够，而是**没有要求模型做"缺口相对自机"的比较**。新的第一单因子应是**关系型读出/目标**（例如直接回归 `gap_center − player_x`，而不是分类"屏幕左/右"），并且训练分布必须覆盖两个朝向与边缘位置。
4. 真实像素路径不受影响：round27 是合成渲染，不产生可部署结论，也不改变 P0/P3 的门。

一句话补充：**卡点仍然是"镜像方向"，但它现在更像"目标没有要求这个比较"，而不是"表征表达不出来"。**

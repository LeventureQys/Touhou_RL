## 无法精确控制、现冻结的规则

1. **显示相位 = unknown。** GDI `BitBlt` 无 Present fence（[源码审查](<P0-capture-round4.md>)、[winapi 历史冻结事故](<../../../../../touhou_rl/winapi.py#L349-L353>)）。规则：任何由截图派生的几何标签必须标 `alignment_unknown`，**禁止**进入精确几何监督；`real_pixel_gate_passed` 恒为 false，直到出现独立呈现栅栏证据。
2. **counter 同帧 ≠ 状态原子性。** `read_state` 先读帧再读自机（不同调用），存在帧内相位差。规则：保存 pre/post 括号；括号内位置变化即 `unknown_phase`，不做插值或首末择优（[对齐规则](<P0-alignment-round7.md>)）。
3. **动作生效时刻 = 区间。** 发送后首个匹配前的轮询与匹配轮询共同构成区间；不得把 send frame 当 effective frame，也不得把延迟折算成"更慢的移动速度"（[运动包络](<../../../../../touhou_rl/tactical_motion_envelope.py>) 以"先旧后新"的端点集合表达）。
4. **边界值 = 已观测样本，不是标定模型。** x[8,376]、y[16,432] 各只有一次饱和试验；任何使用该包络的合成/离线实验必须在报告中声明这一点。
5. **未 alive / 死亡 / 回退的窗口不计合格重复。** 采集脚本必须显式检查 `player_state`，不能只看死亡计数（上轮 34 个非 alive 端点的教训）。
6. **P3 正式像素数据保持关闭。** 在本规则 1 解除前，允许继续合成研发；不允许把校准截图、像素定位结果包装成 P3 事件或正式 manifest。

## 因此

- P0 的"可审计执行 + 误差报告"部分：**已达成**（除每类 20 次独立重复标定）。
- P0 的"像素—状态精确同步"部分：**未达成，且已冻结为 unknown**，不再以追加采集追求软件证明。
- P3 真机数据、P6 真机小试、P7 独立确认：**继续阻断**；合成研究（P1/P2 任务、P4 学习诊断）不受影响，但一律标注为合成。

## 若要解除本冻结

需要能给出呈现栅栏的独立证据，例如：游戏侧可控的帧呈现计数（修改重建源码后重新标定版本）、或可证明与 Present 同步的外部采集通道。二者都会变更"同一游戏版本/同一输入后端"的前提，届时 P0 需重跑，不能沿用本轮结论。

## 补记（2026-11-02，round26）：解除条件已满足，冻结改为"按条件解冻"

上面第 34–36 行要求的"呈现栅栏的独立证据"已由 v3.7.4 的帧栅栏变体交付，并且 [round26](<P0-fence-round26.md>) 在**该变体镜像上重跑了本文件冻结的三条欠账**：

| 本文件原先的冻结项 | round26 结果 |
|---|---|
| 规则 1：显示相位 = unknown；像素派生几何标签禁止进入精确监督 | 60/60 样张 13 项检查全过、GDI 与后台缓冲逐字节相同；**在变体镜像上改为有条件的 `exact`** |
| 规则 2：counter 同帧 ≠ 状态原子性 | hold 期间无逻辑推进、无 present；`ticket + holdPhase` 复核在 60/60 样张成立 |
| 规则 3：动作生效时刻 = 区间 | 拆成两段整数：`发送→掩码 = 1 帧`、`掩码→位移 = 1 帧`，80/80 试验一致；反向旧方向恰 1 帧 4 px |
| 规则 4：边界值 = 已观测样本 | 四方向各 1 次饱和 + 20 次反向 / 10 次切轴；**仍不作标定模型** |
| 规则 5：非 alive 窗口不计合格重复 | 保留；本轮把打断降级为"作废当次试验并重做"，逐条计数上报 |
| 规则 6：P3 正式像素数据保持关闭 | **部分解除**：允许用帧栅栏采集生产 `frame_proof=exact` 样本；正式数据集仍需新预注册（尚未做） |

**新的冻结规则（取代规则 1、3 的旧表述，其余不变）：**

- `frame_proof=exact` 只在**变体镜像 + 13 项检查全过 + 镜像/地址表哈希 + 环境指纹**同时满足时成立；详见 [round26 报告的解冻规则 v2](<P0-fence-round26.md#解冻规则-v2可执行版>)。
- canonical 镜像与纯 GDI 采集的样本**仍是 `alignment_unknown`**，不得升级。
- 变体镜像不能用于 exact-match / 版本一致性声明；"窗口 DC == 后台缓冲"只是本环境（Win11 26300 / RTX 4070 SUPER 617.42 / D3D8 COPY / 无 vsync / 640×480）的实测结论。
- P3/P6/P7 不再因"像素同帧无法证明"而整体阻断，但**必须先做 `frame_proof=exact` 的预注册与清单字段**，再谈数据集合格。

本补记不删除任何旧行；旧结论在它自己的范围内仍然成立（canonical + GDI = unknown）。

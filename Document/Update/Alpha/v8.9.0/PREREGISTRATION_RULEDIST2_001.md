# 预注册 v890-RULEDIST2-001：在**有 bombs∈{1,2} 的状态**上蒸馏 R5 规则（修正 v8.5 的失败原因）

冻结时刻：2026-11-22（Asia/Shanghai），**在任何 v8.9.0 训练之前**。
状态：**FROZEN**。
**本文件取代 `v8.8.0/PREREGISTRATION_TERMINALRL_001.md` 作为下一个执行轮**（RL 留作后备，理由见 §0）。

## 0. 为什么是这条路，而不是长视界标签或 RL

| 事实 | 来源 | 含义 |
| --- | --- | --- |
| v8.5 的规则蒸馏失败（20 s 15.50% vs 19.44%） | v8.5.0 发布 | 因为 **60/40 px 两段零训练行** |
| v8.6 的状态里有 **bombs={3:624, 2:3378, 1:1038}** | v8.6.0 `labels_stats.json` | **60/40 px 段第一次有训练行** |
| v8.6 的三档 **3,661/3,661 条 episode 全部用光 3 颗雷** | 主代理实测 | 纯反事实标签学不到留雷（P3 不成立） |
| R5 规则 = 100% / 77.11% / 17.61% | v8.4.0 发布 | **靶子已知且可复现** |
| v8.7（长视界）连续 4 次实现失败、被中止 | 训练端记录 | 实现风险高 |
| v8.8（在线 RL）需 900 回合 + 稀疏奖励 | 预注册 | 信用分配更难，期望收益低 |

⇒ **最省、最可能成功的一步：把 R5 规则蒸馏到 v8.6 的状态分布上**。这不是新信息，而是**把已有的两条结果接起来**：v8.6 给了正确的状态分布，R5 给了正确的动作。

## 1. 设计（单因子：规则监督的**状态来源**）

| 项 | v8.5.0（失败） | **v8.9.0** |
| --- | --- | --- |
| 状态来源 | v8.3.0（**bombs 恒 3**） | **v8.6.0（bombs∈{1,2,3}）** |
| 规则目标 | R5 三段 80/60/40 px | **完全相同** |
| 但实际生效的段 | **只有 80 px**（60/40 零样本） | **三段全部生效** |
| 损失 | `BCE(36 路标签) + 0.5 × BCE_bomb(规则)` | **相同**（λ=0.5，与 v8.5 一致以便对照） |
| 模型/优化器/epoch/种子 | `Policy(106,64,36)`、Adam 1e-3、256、200、3 | **完全相同** |
| 评测 | 300/600/900 决策 | **完全相同** |

> **单因子成立**：v8.5 与 v8.9 的**一切**相同，只有「状态来自哪一批标签」不同。这直接检验「v8.5 的失败是否由零训练行造成」。

## 2. 判据

| # | 终点 | 判据 |
| --- | --- | --- |
| **P0（前置）** | 规则目标在三段上都有正例与负例 | `bombs=3` 段（80 px）、`bombs=2` 段（60 px）、`bombs=1` 段（40 px）**各有 ≥50 条正例与 ≥50 条负例** |
| **P1（主）** | 600 决策（20 s）活满率 | **> 19.44%**（v8.3.0）**且 > 15.50%**（v8.5 同协议）；单侧 Fisher + CP95 |
| **P2** | 与 R5（77.11%）的差距 | **≥ 60%** 才算「蒸馏成功」 |
| **P3** | 用雷分布 | 出现「只用 1–2 颗」的 episode，且**分布应接近 R5 的**（R5 每局 1.36–1.75 颗） |
| **P4** | 900 决策 | 与 v8.3.0（0.61%）、v8.6.0（待发布）、R5（17.61%）并排 |

### 2.1 停止条件

| # | 条件 | 动作 |
| --- | --- | --- |
| **S-data** | P0 不成立（某段缺正/负例） | 只发布规则目标统计，不训练 |
| **S-ok** | P1 与 P2 都成立（≥60%） | 判「零训练行是 v8.5 失败的唯一原因」；下一轮把 R5 与 R3 **同时**蒸馏并做 30 s 评测 |
| **S-partial** | P1 成立但 < 60% | 判「蒸馏有效但候选头拖累」；下一轮**冻结候选头**（用 v8.6 的），只训 bomb 头 |
| **S-fail** | P1 不成立 | 判「规则监督与反事实标签冲突」；转 v8.8 的在线 RL |

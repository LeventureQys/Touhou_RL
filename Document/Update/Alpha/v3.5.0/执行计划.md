# v3.5.0 执行计划：因果战术教师与区域级规划门

- 日期：2026-10-24
- 依据：[研究方案](<./研究方案.md>)
- 性质：**预注册执行计划**。本文件写定后，门禁阈值、数据切分和停止线不得根据结果修改；若要修改，必须新开版本。
- 本阶段不训练像素策略，不启动大规模 DAgger，不启动随机 PPO。
- 目标：先证明一个特权因果战术教师能减少大范围区域死亡、主动清怪、条件性收 P，并推进到可验收的 Stage 1 clear。

---

## 1. 当前问题与本阶段问题

### 1.1 当前问题

现有 pilot 主要优化局部短视 clearance：

```text
当前状态 → 18 个动作 → 未来约 20 帧局部碰撞风险
```

它没有直接建模：

- 大范围攻击区域的扩张与逃离路线；
- 敌人存活对未来弹幕的影响；
- 击杀敌人带来的 power 与未来安全收益；
- P 槽未满时主动收集 P 的长期收益；
- 收集/清怪路线对生命与 bomb 的风险。

### 1.2 本阶段只回答的问题

> 在不训练像素策略的前提下，现有特权状态是否足以支持“提前离开大范围攻击、主动清怪、条件性收 P”的因果战术教师？

如果不能，停止，不进入 DAgger；先修状态、区域预测或标签。

## 2. 执行阶段总览

| 阶段 | 内容 | 预算 | 进入条件 | 停止线 |
|---|---|---:|---|---|
| S0 | 状态/事件/采集契约 | 1–3 天 | 旧代码可复现，字段可追溯 | 关键字段无法读取就停 |
| S1 | 大范围危险区域探针 | 1–2 天 | 有 bullet 与 player 时间序列 | 区域无法稳定区分就停 |
| S2 | 区域级 LeaveRegion 控制 | 2–4 天 | S1 通过 | 暴露时间无改善就停 |
| S3 | ClearEnemy / CollectPower | 2–4 天 | S2 通过 | 因果收益不成立就停 |
| S4 | 因果战术教师整合 | 2–4 天 | S2、S3 通过 | 20 局战术门不通过就停 |
| S5 | DAgger/蒸馏预注册 | 不在本轮自动执行 | S4 达到教师门 | 教师门未过不得进入 |

总预算约 8–17 天；M3 通过前不估计 M4 时间。

## 3. S0：状态、事件与采集契约

### 3.1 必须交付的字段

每个逐决策样本至少包含：

```text
player position / hurtbox
full bullet pool position / velocity / half
stage / stage_frames / gameplay_frame
power / bombs / lives
boss position / life / spell
normal enemy position / life / type / active
item position / type / active / onscreen
stage_clear / game_clear / game_over / left_game
dialogue / stage_clear_screen_state
```

无法读取的字段必须记录为 `unknown`，不能用 0 代替。

### 3.2 P 点契约验证

必须用一局或受控场景确认：

1. `power` 的最大值；
2. P 槽未满的判据；
3. 25% 收集线的真实 y 坐标；
4. Shift 是按住还是按下沿触发；
5. 25% 线是否收集屏幕内全部 P；
6. 收集前后 item 状态与 power 增量。

### 3.3 采集质量门

| 编号 | 判据 | 标准 |
|---|---|---:|
| S0-1 | 逐决策时间戳单调 | 100% |
| S0-2 | enemy/item/power 字段可追溯 | 100% 样本有 schema 状态 |
| S0-3 | 事件可区分 | clear/game-over/left-game 不混淆 |
| S0-4 | 新采集 `complete` 有效率 | ≥ 95% |
| S0-5 | 整局切分 | 不允许同局跨 train/validation |

任一 S0 门失败，S1–S4 停止。

## 4. S1：大范围危险区域探针

### 4.1 目标

不先判断攻击类型名称，只构造未来危险占据：

```text
occupancy[x, y, t]
```

时间片：

```text
t = 0 / 10 / 20 / 40 / 60 帧
```

### 4.2 区域构造

至少实现一种可复现方法：

1. 基于 bullet trajectory 的时间展开网格；或
2. 基于空间/速度/方向聚类的危险区域；或
3. 已知 enemy/boss 发射源辅助的区域投影。

区域形状不限于扇形。报告必须能够表示：

- 区域覆盖面积；
- 扩张方向；
- 玩家是否处于区域内；
- 最近外部安全连通分量；
- 到达安全分量的最短暴露路径。

### 4.3 S1 门禁

在 10 局旧 pilot trace 上离线重放：

| 指标 | 通过标准 |
|---|---:|
| 死亡前区域内样本可识别率 | ≥ 80% |
| 至少 20 帧前可识别的大区域攻击比例 | ≥ 70% |
| 安全连通分量计算成功率 | ≥ 95% |
| 相比当前局部 clearance 的区域覆盖解释增量 | 显著，不低于预注册置换基线 |

S1 只做分析，不改动作；避免把错误区域估计直接带入真机。

## 5. S2：LeaveRegion 区域级控制

### 5.1 控制逻辑

```text
if player_inside_or_near_large_region:
    choose_external_safe_component()
    choose_route_minimizing_max_exposure()
    execute 1–4 frames
    replan
else:
    call local pilot
```

LeaveRegion 的路线评分：

```text
future_safe_area
+ safe_region_connectivity
+ exit_progress
- max_region_exposure
- immediate_collision_risk
- route_switch_cost
```

进入区域后，不允许用“区域内部 clearance 最大”作为唯一目标。

### 5.2 S2 真机门

与旧 pilot 使用同一难度、队伍、frameskip 和局数协议：

| 指标 | 通过标准 |
|---|---:|
| 大区域平均暴露时间下降 | ≥ 40% |
| 死亡前 10 决策进入区域比例下降 | ≥ 30% |
| 可提前 ≥20 帧选择退出方向的比例 | ≥ 70% |
| frames_mean | 不低于旧 pilot 的同协议基线的 90% |
| 贴墙/贴角占比 | 不得增加超过 5 个百分点 |

S2 不要求 Stage clear；只验证区域级逃逸确实改善。

## 6. S3：ClearEnemy 与 CollectPower

### 6.1 ClearEnemy

读取和预测每个敌人：

```text
enemy position / life / type / active
predicted bullet generation
predicted bullet reduction if killed
route risk
```

目标评分：

```text
target_score =
    predicted_bullet_generation
  + bullet_reduction_if_killed
  + power_gain
  - route_risk
  - loss_of_current_safe_region
```

约束：

1. LeaveRegion 优先级高于 ClearEnemy；
2. 只有在未来大区域风险低时进入清怪路线；
3. 清怪可以牺牲少量当前 clearance，但必须产生未来 60/240 帧收益；
4. shoot 固定打开不代表已经主动清怪，必须记录 enemy life/death 或目标进入轨迹。

### 6.2 CollectPower

```text
if power < power_max and item_exists:
    if collect_route_safe and collect_value > 0:
        move_to_verified_25_percent_line()
        hold_shift_as_verified()
        wait_until_collection_or_timeout()
        return_to_safe_region()
else:
    do_not_chase_P()
```

中止条件：

- 区域风险超过阈值；
- 预计收集路线会穿越大范围危险区；
- 生命/bomb 资源低于预注册阈值；
- 收集带来的未来 DPS 增益不足。

### 6.3 S3 离线/真机门

| 指标 | 通过标准 |
|---|---:|
| 安全窗口且 power 未满时 P 收集率 | ≥ 80% |
| 高风险 P 路线误冲率 | ≤ 10% |
| 主动清怪后未来 60 帧 bullet density | 相比纯躲避下降 |
| 主动清怪后未来 240 帧 bullet density | 相比纯躲避下降 |
| 高威胁敌人 life 下降速度 | 高于局部 pilot |
| power 在 Boss 前的提升 | 高于旧 pilot，增量可复核 |

如果清怪没有降低未来弹幕，ClearEnemy 标签或敌人读取契约无效，停止 S4。

## 7. S4：因果战术教师整合

### 7.1 意图仲裁

```text
LeaveRegion
    > ClearEnemy / CollectPower / BossDamage
    > LocalDodge
```

这是安全约束下的动态优先级，不是固定时间表。

### 7.2 教师输出

每个决策记录：

```text
intent
safe_region / region_exit_direction
full action values
enemy target / enemy clear value
collect target / collect value
power / bullet density prediction
TTC / exposure / clearance
```

### 7.3 S4 教师门

20 局同协议评估：

1. S2 区域逃逸门全部通过；
2. S3 清怪/P 门全部通过；
3. phase 1/phase 2 Boss HP 曲线可复核；
4. `stage_clear` 事件可复核；
5. 至少达到 M2，再争取 M3；
6. 不能用高帧数代替 clear；
7. 每局必须有终止原因、power、敌人和 P 统计。

S4 未通过，不进入 DAgger/蒸馏。

## 8. DAgger 与蒸馏条件

本文件不授权立即启动 DAgger。只有 S4 通过后，另开执行批次：

```text
学生运行 20 局
→ 学生状态分布
→ 因果教师标注 intent / value / route / danger
→ 并集聚合
→ 训练
→ 20 局评估
```

蒸馏目标：

```text
intent
+ full action value
+ future danger map
+ region exit direction
+ enemy clear value
+ collect value
+ power / boss damage value
```

18 路或 36 路动作空间必须在 DAgger 前冻结。

## 9. 停止线与失败处理

| 失败位置 | 处理 |
|---|---|
| enemy/item 读取失败 | 不训练对应行为，先修契约 |
| 区域预测不能提前 20 帧 | 降低目标，先修预测，不调动作权重 |
| 区域逃逸无改善 | 停止所有清怪/P 实验，先修 S2 |
| 清怪不降低未来 bullet density | 停止 ClearEnemy，重做因果标签 |
| P 收集收益不足 | 保留 P 为可选行为，不强制收集 |
| S4 教师不能到 M2 | 不做视觉蒸馏；评估是否需要 boss 专项 RL |
| S4 到 M2 但无法 M3 | 单独开 Boss phase 2 版本，不改全局门 |

## 11. 本计划不接受的伪通过

以下结果不能作为 v3.5.0 通过：

- `frames_mean` 提升但区域暴露不下降；
- 分数提高但普通敌人没有 life/death 证据；
- power 没有提升却声称 Collect 通过；
- 只收 P 不清怪；
- 只躲避不降低未来 bullet density；
- 只击破 phase 1 却把 phase 2 当作 Stage clear；
- 只通过 max_steps；
- fallback/Oracle 实际完成主要工作却报告为纯策略成功。

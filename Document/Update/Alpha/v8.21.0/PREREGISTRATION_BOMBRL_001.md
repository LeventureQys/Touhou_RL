# 预注册 v8210-BOMBRL-001：**冻结候选头，只用终点回报在线训练「放雷头」**（2 动作）

冻结时刻：2026-11-22（Asia/Shanghai），**在任何 v8.21.0 训练之前**。
状态：**FROZEN**。

---

## 0. 为什么这样改 v8.8 的设计

v8.8 的预注册是用 REINFORCE 训练**整个 36 动作策略**（从 v8.6 热启动）。但现在已知：

| 事实 | 证据 |
| --- | --- |
| **候选头（躲闪）已经很好** | bombdag + 60/40/20 规则 = 20 s **98.75%**、30 s **24.17%** |
| **唯一没解决的是「何时放雷」** | 五次实测，用雷恒为 3.00 |
| **放雷只花 1 颗（普通）或 2 颗（deathbomb）** | v8.18：ALIVE 状态 18/18 扣 1 颗 |

⇒ **同时训练两个头会冒「破坏已很好的候选头」的风险**（v8.8 的 `S-harm` 分支）。
**本轮只训练放雷头**（2 动作：放/不放），候选头**冻结**——这是最干净的「单因子」。

---

## 1. 设计

| 项 | 内容 |
| --- | --- |
| **候选头** | **冻结** v8.6 的 `bombdag.pt`（`9c6d5d4a…/36a51090…/885dde70…`），按 **argmax**（确定性，避免候选采样噪声污染放雷梯度） |
| **放雷头** | `BombHead(106→64→2)`，输出 `bomb ∈ {0,1}`；**从 R5 规则的决策热启动**（用 60/40/20 规则在若干状态上的行为做 200 步 BCE 预训练） |
| **学习信号** | **REINFORCE**：`R = survived(600 决策) + 0.5 × alive_frames/1200`；移动平均基线；熵正则 0.01 |
| **回合** | **600 决策 = 20 s**（让「花雷的代价」落在回合内）；每种子 300 回合 |
| **优化** | Adam 3e-4，每回合 1 次更新 |
| **种子** | 3（与三份 ckpt 对应） |
| **评测** | 300 / 600 / 900 × 3 种子 × 4 窗 × 300（同协议） |

### 1.1 三条对照臂

| 臂 | 放雷策略 |
| --- | --- |
| **R0** | 已发布的 60/40/20 规则（20 s **98.75%**、30 s **24.17%**、40 s **2.08%**） |
| **RL** | 训练出的放雷头（softmax 采样） |
| **RL-argmax** | 训练出的放雷头（argmax，确定性） |

---

## 2. 判据

| # | 终点 | 判据 |
| --- | --- | --- |
| **P1（主）** | 30 s 活满率 | **> 24.17%**（R0 的点估计）；单侧 Fisher + CP95 |
| **P2** | 用雷分布 | 是否出现「只用 1–2 颗」；均值是否 **< 3.00** |
| **P3** | 20 s 活满率 | **≥ 95%**（不能因为学放雷而破坏 20 s 的 98.75%） |
| **P4（诊断）** | 训练曲线（每 50 回合的平均回报） | 只看趋势 |

### 2.1 停止条件

| # | 条件 | 动作 |
| --- | --- | --- |
| **S-win** | P1 与 P2 都成立 | 判「终点回报能教出省雷」；下一轮把回合拉到 900 决策并扩到 1,000 回合 |
| **S-flat** | 训练曲线无上升（后 150 回合 ≤ 前 150 回合） | 判「REINFORCE 信号太弱」；改**离线回报加权**（用已有标签 + 真实存活时间做权重） |
| **S-nosave** | P1 不成立但训练曲线上升 | 判「学会了活得更久但仍用光雷」；下一轮加**用雷惩罚**（每颗 −0.1） |
| **S-harm** | P3 <95% | 判「放雷头破坏了 20 s」；加 KL 正则（对 R5 行为） |
| **S-fork** | 保真门失败 | 整轮作废 |

## 5. 不能声称什么

- 不能声称「学会了资源分配」——本轮只学「何时放」，且候选头是冻结的；
- 不能把 RL 的 30 s 与 R0 的 30 s 直接比较而不报 CP95；
- 训练与评测用同一批 dev 窗 ⇒ 不能声称跨窗口泛化；
- **若 P2 不成立，仍然是一条重要结论**：「终点回报也教不会省雷」。

## 2 实际走的路径（分四个阶段）

### 阶段一：打地基（W00 / W01 / W09）

先做能立刻验证的两件事：**身份可复现**与**动作/评测通路**。

- **W00**：确立摘要口径（文本 `text/lf-normalized`、二进制 `binary/raw`）、资产账本、
  `tools/rl/v430.py` 骨架（18 子命令，4 实现 / 14 显式 fail-closed）。
- **W01**：`contracts.py` / `actions.py` / `session.py` / `evaluate.py`。
  最硬的一条证据是**真实引擎 3 次通关 + 3 次失败，各跑两遍，全部 `diffs=0`**。
  但这里也留下了必须随结论一起引用的**三条诚实限制**：只有 3 段独立录制
  （S/F 是同一段磁带两种仪器设置）、**失败是仪器诱导的**、通关靠 `--tail 64` 重复最后动作推过去。
- **W09**：`data/lineage.py` 谱系注册表 + `validate-splits` CLI。

**这一步的产出让后面的每一步都能说"同一件事再测一遍，结果一样"。**

### 阶段二：观测与模型骨架（W02a / W03a–g / W04a / W04b）

- **W02a `observation.py`**：O2 契约（`global_rgb (3,240,320)`、`play_gray (4,224,192)`、
  `hud_gray (1,448,160)`、`executed_key_history (8,7)` 等），BT.601 整数灰度。
- **W03a/a2/a3 `sequence.py`**：GAE、分段、burn-in、padding。
- **W03b `data/manifest.py`**：33 个问题码，纯 stdlib。
- **W03c `models/actor.py`**：2,726,671 参数，四头 72 组合归一。
- **W03d/g `learn.py`**：BC 编排 + 防伪闸门。
- **W04a `ppo.py`**：PPO 损失与诊断（`clip` 缺 `old_values` 直接抛错，不静默降级）。
- **W04b**：把观测契约守卫**真正接进** `train_from_manifest`，`batch_source` 改为调用方声明。

**测试累积到 557 条**（v430 子集），全仓 4045 条。

### 阶段三：真实数据（W03h/k/l/m）——本会话最长的一段

代码齐了，但没有真实 O2 数据。于是开始采集：

| 批次 | 样本 | `move` 覆盖 | 记账模型 |
| --- | ---: | ---: | --- |
| `o2-64` | 64 | 5/9 | 8-shard，缺 `sample_count` |
| `o2-1k` | 1000 | **6/9** | 8-shard + `sample_count` |
| `o2-strided`（seed12） | **1099** | **9/9** | **1-shard（正确）** |
| `o2-stride-seed10` | **1099** | **9/9** | **1-shard** |
| `o2-stride-seed11` | **1099** | **9/9** | **1-shard** |

**最关键的一次转向**：按顺序采前 1000 个决策只把 `move` 覆盖从 5/9 提到 6/9。
主代理**只读磁带、不花引擎时间**算出"行为前段集中、后段才分化"，
改成**跨盘每 6 个取 1 个**——同样量级的数据直接拿到 **9/9**。

**第二个关键：差点采到作废数据。** 一个自然的 stride 实现是"改写磁带每 6 行取 1 行"，
那会让引擎**连续执行**留下的动作，得到一条**画面与原轨迹不符、却仍标着原始帧号**的轨迹。
这类污染**不报错**。主代理提前识别并写明"过滤**采集**、绝不过滤**磁带**"，
事后用黄金参照（`schedule[::6][1:]`）逐项比对确认：**帧间隔恒 12、0 处不符**。

### 阶段四：做实验，然后撤回自己的结论

基础设施齐了，就去问那个真问题：**BC 到底学到了什么？**

**第一次回答是错的。** round 97 见到"验证损失下降 0.27"就写下"映射可学、可迁移"，
**却没有和"恒预测多数类"这个平凡基线比较**。`move=0` 占 43%，该基线 CE 只有 **0.85**。

补上基线后：

| 配置 | 参数 | train CE | seed12-val | seed10 | 基线 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `ActorPolicy` 全分辨率 | 2,726,671 | **0.0293** | 1.8807 | 1.8837 | 0.8537 |
| 小模型 16× 下采样 | 30,793 | 1.2827 | 1.5306 | 1.6020 | 0.8537 |
| 小模型 4× 下采样 | 487,753 | **0.1558** | 2.1299 | 2.1161 | 0.8537 |

**三组全部不优于平凡基线。** 典型形态是训练损失塌向 0（背下来）、验证反而升到基线之上。

**第二次修正**：我曾断言"880 样本配 2.7M 参数是主因"，缩小模型后**未获支持**，
已降级为"成因未定"。

**第三次修正**：跨磁带验证本身**被污染**——seed10 与 seed12 前 **219 个决策逐字节相同**
（磁带层 1308，约 20%，因为第一关开局确定性极强）。剔除后 CE 由 2.1161 **恶化到 2.5070**。
污染是**偏乐观**的，剔除后结论更强。

## 3 关键决策与依据

| 决策 | 依据 |
| --- | --- |
| 摘要必须带口径 | 同一文件 raw 与 lf-normalized 是两个数，混用会误报缺陷（我误报过一次） |
| 1-shard 记账模型 | `counts.decisions == 样本数`，数字自解释；8-shard 模型下必然 8× 且需额外字段消歧 |
| stride 过滤**采集**不过滤**磁带** | 过滤磁带会生成"看起来对、实际错"的轨迹 |
| 每批采集用**独立**私有 data 目录 | 引擎会写 `score.dat`/`th08.cfg`，共用会互相破坏 |
| 任何学习结论必须并列**平凡基线** | 否则"loss 在降"只证明优化器在跑 |
| 跨磁带验证必须**排除共同前缀** | 否则 20% 的验证集是训练原文 |

## 4 结论

### 4.1 已经确立的

1. **O2 观测可从真实引擎采集**，编码/清单/守卫/训练整条链在五批真实语料上验通。
2. **动作与评测通路可复现**：真实引擎 3+3 双跑全 `diffs=0`。
3. **三批 stride-6 语料各 1099 样本、`move` 9/9、`cand` 17/18**，0 空白帧，
   标签与磁带逐条核对 0 不符，五份 manifest 全部 `valid=True` 且守卫放行。
4. **三盘磁带是真不同的轨迹**：sha256 互异 + 九类 `move` 直方图互异。

### 4.2 已经被否证的

1. **"BC 能学到可迁移的观测→动作映射"——在已测的三组配置下不成立。**
   全部劣于"恒预测多数类"。
2. **"容量远超数据量是主因"——未获支持**，已降级为假设。
3. **"验证损失下降说明学到了东西"——错的**，那只是从近似均匀分布向先验靠拢。

### 4.3 仍然未知的

- BC 失败的**真实成因**（数据量 / 训练步数 / 架构不适配 / 标签可预测性，四条未区分）。
- `shoot`/`bomb` 在**有信号**的数据上能否学到东西（当前零信号，从未测过有信号的情形）。
- 预乘是否成立（`max(RGB) > alpha` 仅 0.03–0.12% 越界，未裁决）。
- **换面之后的观测长什么样——没有任何样本**。

### 4.4 因此

- **G430-E0 pass**；G430-T/C/P/D `not_run`；G430-X 仅谱系腿。
- **G410-0…G410-7 全部未通过。**
- **总目标未达成。**
- 在 BC 成因查清之前，W03 的"真实微段 ≥9/10"**不可能达成**。

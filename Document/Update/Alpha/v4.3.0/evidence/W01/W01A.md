Scope marker: **synthetic implementation slice.** This slice proves the data

## 4 Implemented semantics (the parts a reviewer should argue with)

1. **Joint id.** `joint = ((move*2+focus)*2+shoot)*2+bomb`, head order
   `(move, focus, shoot, bomb)` as `PLAN_SPEC.action.heads` lists it. This is a
   *new* encoding and is intentionally not `touhou_rl.spec.encode_flat`
   (`move, shoot, focus, bomb`); mixing the two would relabel focused shots as
   focused bombs. Both directions are validated for every one of the 72 values.
2. **Probability semantics.** `log_prob = sum(head_logprob)`,
   `entropy = sum(head_entropy)`. All four heads are mandatory arguments, so
   omitting `shoot` is a `ContractError` rather than an implicit certainty
   (`-4·ln2` and `+4·ln2` are the hand-computed test values). `NaN`/`±inf` head
   values are refused because they poison both the sum and the PPO ratio.
3. **Mask semantics.** `mask = direction_bits[move] | shoot·BTN_SHOOT |
   focus·BTN_FOCUS | bomb·BTN_BOMB`, identical for both frames of the hold
   window. Directions come from `touhou_rl.v400.gym.actions._MOVE_BITS` and the
   button bits from `touhou_rl.spec`; import-time guards assert the reused table
   still agrees with `cand_to_mask(move, 0)` and with `DIRECTION_MASK`.
   `cand_to_mask` itself is never used to build a v4.3.0 mask because it ORs
   SHOOT on.
4. **Bomb semantics.** The emitted *level* follows the request (a held key stays
   held). The *trigger* is the 0→1 transition, reported as
   `bomb_edge_frames`/`bomb_edge_consumed`/`bomb_edges_total`; a held request has
   `bomb_held=True` and no new edge. `requested` and `emitted` are both logged.
   The only history the decision depends on is the previously **emitted** level —
   there is no "did the bomb succeed / how many bombs are left / was the player
   hit" state, so no zero-latency reflection on a hidden hit is possible. The real
   engine's reaction to the press/hold is *not* verified here (see §6).
5. **Ownership.** `KeyOwnership.acquire(source)` raises `OwnerConflictError`
   while anyone holds the keys; `release(token)` requires the live token; every
   compile re-checks the token, so a released compiler cannot send. Switching
   owners is therefore explicit release + acquire. `session` decisions carry
   `actor_loss_mask = 0` (also enforced for transition records in
   `contracts.check_transition`).
6. **No truth in the action path.** `compile_request` takes no resource/truth
   input. A caller that has truth may pass `context=`, which is scanned by
   `assert_not_privileged` (raising `PrivilegedInputError` for `engine_frame`,
   `seed`, `script_id`, `stage_truth`, `enemy_table`, `resource_truth`,
   `teacher_action`, `future_tape` and the neighbouring privileged names) and is
   otherwise ignored; identical masks with and without a clean context are
   asserted. A bomb request is emitted and recorded regardless of resources
   (`truth_action_mask=false`).
7. **One entry point.** Rollout and evaluation both call
   `ActionCompiler.compile_request`; `compile_action` only unpacks a
   `JointAction` into it. There is no mode/eval flag anywhere in the signature,
   and a test asserts the two call styles produce identical masks.
8. **Time contract.** `hold_game_frames = 2`. `elapsed_game_frames` (engine
   source) and `elapsed_capture_s` (external controller clock) are independent:
   the external source refuses a carried `elapsed_game_frames` (the R1 actor may
   not read the engine counter), `effective_frames_from_capture` refuses to run
   for any source other than `external_controller_clock`, and the `invalid`
   source has `effective_frames = None` so a fault/pause/dropped frame has no
   number that could be read as "two normal frames".
   `assert_normal_two_frame` rejects an invalid record and any interval more than
   half a frame from the nominal step.
9. **Transition fields.** `terminated` / `truncated` / `segment_end` are three
   required booleans; `done`/`is_terminal`/`terminal`/… are refused by name;
   `terminated ∧ truncated` is contradictory and refused; `truncated` needs a
   registered `truncation_reason`. Bootstrapping requires
   `terminal_observation_ref` for a truncated segment, forbids any bootstrap on a
   terminated episode, and refuses a `next_obs_ref` that is the post-reset image.
10. **Result JSON.** `EXIT_OK=0 / EXIT_INVALID=2 / EXIT_GATE_FAIL=3 /
    EXIT_INCOMPLETE=4`; the four result fields are separated; `capability_gate`
    defaults to `not_run` and `new_result()` **cannot** set `pass`/`fail` — only
    `set_capability_gate(..., judged_from={"judge", "sha256"})` can, and a
    `training` result claiming a capability is refused outright. An exit-0 result
    keeps saying only that the requested work completed.
11. **O2.** Parameters only (source 640×480, play crop `(32,16,384,448)`, HUD
    crop `(480,16,160,448)`, `(77R+151G+28B)>>8`, 2×2 uint32 sum then `//4`,
    uint8 on disk, `/255.0` in the minibatch, key order
    left/right/up/down/focus/shoot/bomb). `o2_digest()` is the sha256 of the
    canonical sorted-key JSON, `cb1616e4cbfa928e691c2fb8497a84c813bded528064cf2b0aa1e30fa86b85b5`,
    and is sensitive to a single changed crop or luma weight. **No pixel encoder
    is implemented** (W02), and the tests assert that `encode_o2` /
    `downsample_2x2` do not exist.

## 5 Config ↔ constant agreement

`tests/test_v430_contracts.py::test_config_constants_equal_the_module_constants`
asserts `config["constants"] == contracts.contract_constants()` (plus per-block
key-set equality), and
`::test_config_pins_the_mandated_constants` re-reads the individual numbers that
`PLAN_SPEC.json` pins (72, hold 2, `forced_shoot=false`,
`truth_action_mask=false`, `owner_exclusive=true`, `session_actor_loss_mask=0`,
crops, source size, digest, exit codes, `capability_gate` default). Drift on
either side fails the suite.

## 6 What this is not, and what is still missing

* **Not capability evidence.** Every test is synthetic. No engine was started, no
  game frame was captured, no bomb was actually spent.
* **Engine-backed semantics unverified.** Whether TH08 really treats a held bomb
  bit as one bomb, whether a 2-frame hold is delivered twice, and how focus
  behaves in the real input path must be measured on the real engine. That is the
  remaining part of W01 (the success/failure replay and the real mask
  observation), and it is listed as `not_run` here.
* **No session/evaluation/CLI.** `session.py`, `evaluate.py`,
  `tests/test_v430_session.py` and the `validate-contract` subcommand of
  `tools/rl/v430.py` belong to the follow-up W01 slices / other owners. The
  `W01` acceptance line in `DEVELOPMENT_GUIDE` §11 still needs
  `test_v430_session.py` before the package-level W01 gate can be claimed.
* **No real O2 encoder.** W02 owns the crop/gray/downsample implementation; this
  slice freezes the parameters and the digest that a run identity must bind to.
* **Working-tree note (not caused by this slice).** `git status` on this checkout
  already reports a large pre-existing deletion set and many untracked
  `tools/rl/*` files from earlier recovery work. This slice adds only the six
  whitelisted paths above and modifies none of `touhou_rl/v420/**`,
  `touhou_rl/v400/**`, `touhou_rl/spec.py`, `tools/**`, other `configs/**` or
  other `tests/**`. Nothing was staged, committed, moved or deleted.

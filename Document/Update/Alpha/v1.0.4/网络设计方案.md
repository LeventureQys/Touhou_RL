## 1. 设计结论与边界

现有三路输入、heatmap 定位和特权教师值得保留。优先修复的是策略通路，不是盲目扩大参数量：当前精细空间输出没有直接进入策略，策略仍经过 2×2 池化；单帧输入又难以恢复教师规划使用的速度。

方案分成两个交付边界：

| 层级 | 内容 | 本次地位 |
| --- | --- | --- |
| A：现有版本内 | 现有数据上的三帧视觉、局部/全局融合、18 候选蒸馏、感知辅助任务 | 建议作为 v1.0.4 网络实现候选 |
| B：后续强化学习 | 视觉 Actor-Critic、在线 rollout、放雷学习、历史动作输入 | 只设计接口；需另行确认预算与约束 |

A 不增加回放，不使用 ud0063 训练，不提高场地输入分辨率，不改教师、候选顺序、danger 标签或验收口径。B 需要新的在线交互经验；不能把“不采回放”偷换成“可以任意新增训练数据”。在获得明确授权前不执行。

本文不承诺 A-01/A-02/A-04 必然达标。所有网络尺寸是待验证设计，所有默认超参数是实验起点。

## 2. 要解决的具体问题

1. 教师使用子弹位置、速度和尺寸预测未来，学生只看单帧时存在信息缺口。
2. heatmap/danger 是共享编码器上的辅助输出，不等于策略直接获得了这些空间信息。
3. 单靠全局压缩向量，不利于区分自机附近几像素到几十像素的危险关系。
4. 感知预训练后只优化策略损失，可能导致感知遗忘；需测最终策略权重。
5. 教师评分是短时规划净空，不是折扣奖励回报，不能充当 RL 的状态价值。
6. 当前视觉动作固定不放雷；不能假定注释里的放雷规则已经实现。

## 3. 总体结构

```text
最近三帧场地 RGB，224×192，通道拼接
                  │
             场地多尺度 CNN
          ┌───────┴────────┐
     F4：64×56×48      F8：96×28×24
          │                  │
          ├─────定位融合头────┤ → 56×48 heatmap → 预测坐标、置信度
          │                  ├ → 空间 danger 头 → 16×8
          │                  └ → 7×6 空间网格 + 坐标通道 → 全局128维
          │
   以预测自机坐标为中心采样局部特征 → 局部128维
          │
          └──────┐
HUD score → 64维 │
HUD status→ 64维 ├ → 融合 MLP → z：256维
预测坐标/置信度→16维│             ├ → 18个动作 logits
                │              ├ → 辅助资源/射线输出
                │              └ → 阶段B：V、条件放雷头
                └────────────────────────────────
```

默认不引入 Transformer、大型预训练视觉模型、显式全弹幕实例检测或长序列世界模型。先让一个轻量、可消融的时空网络形成有效闭环。

## 4. 输入、时间与因果契约

### 4.1 兼容输入

沿用 `regions_to_batch` 和现有三块分区：

| 输入 | 外部形状 | 默认处理 |
| --- | --- | --- |
| playfield | `[B,3,224,192,3]` | 三帧 RGB 拼成 `[B,9,224,192]` |
| hud_score | `[B,3,34,216,3]` | 初版只编码最新帧 |
| hud_status | `[B,3,126,216,3]` | 初版只编码最新帧 |

统一张量尺寸顺序为 H×W；原生场地 H=448、W=384。三帧优先给运动信息，HUD 无须为所有历史帧重复计算。输入仍是三块视觉张量，不在 A 阶段偷偷加入内存状态。

### 4.2 帧序列

- 使用 `t-2,t-1,t`，只能访问当前和过去，不访问未来。
- 名义间隔保持现有采样约 2 个游戏帧；实际分布必须从已有 meta 统计。
- 必须根据 capture/run、stage 和帧编号识别连续性；不能认为文件相邻必然连续。现有逐帧meta没有显式capture/run id，实施前需核实分片provenance能否映射到样本；无法证明连续性时禁止跨片拼接，且在片内stage变化、帧编号不递增或异常跳变处重置历史。该回退不能保证识别所有同stage重开，残余歧义必须记录，必要时禁用该段的多帧输入，而不是猜测连续。
- 不跨 episode/stage 拼历史；缺少历史时重复该连续段首帧。
- 分片只是存储边界。初版可保守地沿用分片内截断，但必须报告边界重复占比；后续只有元数据证明连续时才跨片。
- 不规则帧间隔先记录并诊断，不静默按标准速度解释。若需要显式时间间隔输入，须另列输入契约扩展，保证部署端同样可获得。
- 训练期 meta 只用于组序列、损失和评估，不输入策略的关卡号、真实坐标或真实子弹速度。

三帧只覆盖短时间，不能保证解决所有速度歧义；若三帧无收益，先核对帧间隔与特征通路，而不是立即加长到几十帧。

## 5. 场地编码器：保留中间尺度

候选配置如下，卷积 padding 保持声明的几何关系；残差块均为同尺度两层 3×3 卷积：

| 模块 | 运算 | 输出 `[C,H,W]` |
| --- | --- | --- |
| Stem | 5×5 Conv，stride=2，9→32，ReLU | `[32,112,96]` |
| Down4 | 3×3 Conv，stride=2，32→64，ReLU | `[64,56,48]` |
| Res4 | 两层 3×3，64通道，残差 | F4=`[64,56,48]` |
| Down8 | 3×3 Conv，stride=2，64→96，ReLU | `[96,28,24]` |
| Res8 | 两层 3×3，96通道，残差 | F8=`[96,28,24]` |

初版不使用 BatchNorm，避免小 batch/部署单样本下统计行为成为额外变量。是否使用 GroupNorm 作为后续独立消融，不与结构改造同时引入。

输入仍然是 224×192。F4 在原生场地上对应约 8 px/格，F8 对应约 16 px/格；保留 F4 不是提高输入分辨率，也不能恢复缩小时已经丢失的信息。

配置校验优先要求场地 H/W 均可被 8 整除；输出网格尺寸由实际特征形状校验，禁止只用不一致的 floor 推算目标尺寸。

## 6. 定位与局部决策通路

### 6.1 定位融合头

1. F8 双线性上采样到 56×48，`align_corners=False`。
2. 与 F4 拼接为 160 通道。
3. 3×3 Conv：160→64，ReLU；1×1 Conv：64→1。
4. 输出 heatmap logits `[B,56,48]`。
5. 使用统一 softmax/soft-argmax 解码归一化坐标 `(rx,ry)`。

先融合上下文再产生一个定位分布，而不是先分别预测粗细两个坐标再加权平均。后者可能把两个错误峰平均成一个根本不存在的位置。

目标仍是高斯分布；建议起点 `sigma=2.0` 个 F4 单元，与旧 28×24 网格上 `sigma=1.0` 的物理宽度近似相同。更换网格后不能直接沿用数值 σ 而改变物理监督宽度。

额外输出归一化熵和最大概率，作为不确定性特征，而不是把它们当成已经校准的置信概率。除了原指标，并列记录 p90、>30 px 长尾、分关卡及 heatmap 熵与误差的关系。

### 6.2 自机中心局部特征

- 在 F4 上以**模型预测坐标**为中心，采样原生场地约 128×128 px 的方形窗口。
- 输出 `[B,64,16,16]`，固定使用 `grid_sample` 的双线性采样与 `align_corners=False`。
- 归一化坐标中心转换为 `(2rx-1,2ry-1)`；原生偏移 `(dx,dy)` 对应采样网格偏移 `(2dx/384,2dy/448)`，不能交换轴或漏掉系数2。16个采样点按窗口内bin中心排列。
- 越界用零填充，并附加一个采样有效性通道；否则边界外全零会被误解成安全空场。64通道特征与1通道mask拼接后为65通道。
- 局部编码器：两个 stride-2 的 3×3 卷积，通道 65→64→96，再展平 96×4×4，经 Linear→128。
- 不先把局部区域全局平均成单点，保留相对空间布局。

初版采样中心使用预测坐标的 `detach()`：策略梯度不通过窗口中心扭曲定位；采样到的 F4 特征仍可接收策略梯度，定位由辅助损失训练。是否解除 detach 后续单独试验。

**训练和部署默认都使用预测坐标。** 用真值中心裁剪只能作为“定位完美时的上限”诊断，不能作为主训练配方后直接改成预测坐标部署，否则形成新的训练/部署漂移。

定位不确定时不做硬切换；局部路与全局路始终同时存在，并把熵传给融合层，让模型学习减小错误裁剪的影响。

## 7. 全局、HUD 与融合

### 7.1 全局空间路

F8 经 1×1 Conv 压至 32 通道，AdaptiveAvgPool 到 7×6；附加 7×6 的归一化 x/y 坐标通道，展平 `(32+2)×7×6`，Linear→128，ReLU。

这里仍使用池化，但策略不再只依赖 2×2；空间网格、局部精细路和显式预测坐标共同提供几何信息。坐标通道帮助学习边界和方向关系，不代表自动获得平移等变性。

### 7.2 HUD 与状态

两路 HUD 保留独立小型 CNN，分别输出 64维。坐标、归一化熵、最大概率共4维，经 MLP→16维。

融合输入为 `128局部 + 128全局 + 64分数HUD + 64状态HUD + 16定位 = 400维`，经 `Linear(400,256)→ReLU→Linear(256,256)→ReLU` 得到 z。

`self_feat[2:24]` 的辅助头从 z 输出22维，保持历史资源/射线监督。保留位和恒定通道不计入有效任务损失，通道掩码及对应旧指标须明确记录，不改变既有验收指标定义。

### 7.3 danger 头

F8 → 1×1 Conv(96→32) → resize 到32×16 → 3×3 Conv(32→32)→ReLU → AvgPool(2)→16×8 → 1×1 Conv(32→1)。

标签严格保持16×8计数的 `log1p(count/8)`，损失先沿用 Smooth L1。输出不额外加 ReLU，以免在空格处引入死梯度。

这是可学习重建头，不宣称池化边界误差已消除；必须用原 per-frame Pearson 指标与占据误差对照。danger 不作为必须先预测正确才能决策的硬瓶颈，策略同时接收潜在特征。

## 8. 策略头与评分含义

### 8.1 阶段 A：18 个联合候选

`Linear(z,18)` 直接产生 logits `s`；顺序严格为 `focus*9+move`，不修改动作语义。

选择直接18路输出，是为了减少候选 embedding 与共享打分 MLP 的额外优化变量；原候选条件头保留为可消融对照，不断言其原则上错误。

部署默认 `argmax(s)`，动作映射保持 `[move,1,focus,0]`。必须在报告写明“禁雷视觉策略”，不能写“放雷由规则负责”却没有执行规则。

`s` 是偏好/logits，不是 px 净空，也不是 RL 的 Q 值或 V 值。后悔值仍从未变更的教师原始 px 评分读取。

### 8.2 后续 Actor-Critic 接口

预留但 A 阶段不训练：

- `V(z):256→128→1`：预测真实奖励的折扣回报；不能拿 `max(s)` 替代。
- `πmovefocus=Categorical(logits=s)`：训练采样，评估可贪心。
- `act` 返回实际 `action, log_prob, value, entropy`。
- `evaluate_actions` 必须重算与采样完全相同联合分布的 log-prob。

PPO 不要求四个独立动作头。保留18个联合移动/低速动作更容易表达相关性。

若后续允许放雷学习，可加入条件 Bernoulli：`πbomb(b|z,a)`，其中 a 为联合候选；总 log-prob=`logπmovefocus(a|z)+logπbomb(b|z,a)`。射击保持常开作为任务限制。若要恢复完整72组合，须独立设计射击决策，不宣称18×2已覆盖完整环境动作空间。

放雷条件分布初版不根据内存炸弹数做 action mask；如使用 HUD 预测做 mask，必须说明误识别风险并将 mask 纳入行为策略概率记录。联合熵可按18个候选加权计算条件熵。

## 9. 蒸馏损失：区分好坏，不强迫复现并列 argmax

### 9.1 主要排序项

教师原始评分为 v，学生 logits 为 s。对每帧 i<j：

```text
有效对：abs(v_i-v_j) > δ，δ 起点0.5 px
l_ij = softplus(-sign(v_i-v_j)*(s_i-s_j))
```

先对每帧有效对求平均，再对帧求平均；全并列帧排序项置0。禁止因危险帧有效对少就隐式降低其整帧权重。

默认计算全部最多153对；特别不能只比较教师top-6内部而不比较好动作与差动作。可选按教师差距加权，但必须设上限并做独立消融。

### 9.2 回归对照与数值问题

至少做三个同预算配方：

1. 原始裁剪评分 Smooth L1，作为历史可比基线；
2. 帧内中心化评分回归：目标 `(v-mean(v))/10`，网络输出也中心化后比较；不做原来的硬裁剪；
3. 全候选有效对 RankNet，作为推荐起点。

中心化保留动作间差值并剥离共同安全基线，不是已经证明优于原回归。若原始标签存在异常大值，先审计缓存/教师结果，不用静默裁剪遮蔽异常。

额外统计：原裁剪饱和比例、每帧动作极差、有效对数量、学生帧内评分标准差、正反排序对比例。教师缓存需绑定数据索引哈希、教师配置和标签版本；float16 标签的量化并列不可误认为全部是真实完全相等。

### 9.3 感知保留项

```text
L_A = L_policy
    + λ_hm*L_heatmap
    + λ_xy*L_coord
    + λ_d*L_danger
    + λ_self*L_self
```

感知预训练沿用现有各项默认权重作为起点。策略联合阶段建议起点：`λ_hm=0.1, λ_xy=1.0, λ_d=0.2, λ_self=0.1`，坐标损失沿用当前“px误差/100”缩放。权重不是定论；记录各项数值与共享层梯度量级，避免把原始热图交叉熵的常数基线误判为梯度强度。

先定位预训练，再短暂冻结编码器仅训练新策略头；最后编码器以头部约1/3学习率联合微调。阶段切换显式载入选定的感知checkpoint，不默认为最后一轮最优。最终策略必须重新测感知指标。

## 10. 真正的强化学习阶段 B

进入条件：离线策略已稳定优于同条件随机/常量动作基线，基础 rollout 单测通过，并明确获得在线训练授权。

1. 修复当前 PPO 在 step 后保存下一状态、却配对上一状态动作与旧概率的错误。
2. rollout 保存 `(视觉历史_t, action_t, old_logp_t, V_t, reward_t, terminated_t, truncated_t)`。
3. 真实终止不 bootstrap；纯时间截断用截断前末状态 bootstrap，并切断跨 reset 的 GAE 递推。
4. 处理 rollout 边界 bootstrap，不把 reset 后的状态值用于上一局。
5. 视觉环境适配器明确区分训练期奖励/终止的特权读取与策略的纯像素输入。
6. 冻结蒸馏模型作为初期 KL 参考；KL 系数可退火，记录实际 KL、熵、clip fraction、explained variance、梯度范数。
7. 先完成纯视觉 critic，后续可单独试验非对称特权 critic；部署始终只需要视觉 actor。
8. 不把旧 PPO 的特权 checkpoint loader 直接用于新架构。

KL 是稳定器不是永久束缚：教师只教短时净空，过强锚定会妨碍学习瞄准、资源利用和关卡推进。后续奖励应重点审计通关进度/伤害目标与存活目标的平衡，不在本提案里擅自修改现有奖励。

没有未来转移和可靠动作因果关系，不能仅凭现有回放中“给18个候选打分”就宣称完成离线RL。回放上的反事实教师评分不是环境执行这些动作后的真实奖励轨迹。

## 11. 关键消融与实施顺序

| 编号 | 配置 | 目的 |
| --- | --- | --- |
| E0 | 现有v2、depth1、原回归 | 可复现基线，先修评估丢尾部 |
| E1 | v2、depth3、原回归 | 单独测运动历史的收益 |
| E2 | v2、depth3、中心化回归 | 测共同评分基线是否干扰 |
| E3 | v2、depth3、全候选排序 | 与E1/E2同seed、同epoch比较目标 |
| E4 | v3-st、depth3、与E3相同目标，关闭局部路并用零向量占位 | 完整空间主干对照 |
| E5 | E4启用预测中心局部路 | 测局部决策增益 |
| E6 | E5去掉策略阶段感知辅助损失 | 测感知遗忘及其对策略影响 |

为满足原R1至少三组排序配置要求，E3内部固定同一网络、数据、seed和epoch预算比较：R-a=`L_rank`；R-b=`L_rank+0.1*L_centered_reg`；R-c=`L_rank+1.0*L_centered_reg`。三组均保留相同的感知辅助项、δ=0.5 px和全部有效对，中心化回归按§9.2缩放。E1/E2是额外非排序基线，不能冒充三组排序配置。§9.3的`L_policy`即对应实验所声明的策略目标；推荐默认采用R-a，E4至E6固定使用同一个已选配方。

E3→E4改变主干、定位头和全局路，是架构候选比较，不伪装成单变量因果实验。若收益明确，再分别切换F4定位、7×6全局路、残差块归因。E4/E5确保相同主干与参数槽位；局部编码器在E4不接收有效任务输入。

每次都记录实际epoch耗时和总计算预算。相同epoch不等于相同计算量，必须并列报告。筛选用同seed减少比较噪声，最终入围方案建议至少3个seed，不能只凭一次最好值宣布稳定收益。

在全量训练前做危险训练帧的小集过拟合：例如256帧，按危险距离与stage分层，报告后悔值及学习曲线。该测试只回答能否拟合，不作为泛化证据；不得用验证帧拟合。

若预算只能做一轮小改动，先做E1与E3，不立即实现整套v3-st。

## 12. 评估与数据边界

### 12.1 保持原验收

- A-01：全验证集位置误差<10 px，danger per-frame corr中位数>0.8。
- A-02：0–15 px桶后悔值<1.5 px，并列top3命中。
- A-03：ud0063只做跨回放检查，阈值保持原定义。
- A-04：真机至少3局、frames_mean>4000、hit_step_cap=0。
- A-05/A-06：维持原测试及工程缺陷证据要求。

全验证集必须实际跑满7241帧，不能只在summary里填写数量；聚合按实际样本数加权。

### 12.2 新增诊断，不替代验收

- tie-aware near-optimal命中：`vmax-vchosen≤ε`，起点ε=0.5 px。
- top3同时给出固定排序top3与并列边界扩展集合命中，避免并列时任意索引造成歧义。
- 危险桶各自样本数、均值/p90后悔值、预测碰撞动作选择率。
- 最终策略checkpoint的位置、danger及定位置信度分桶。
- 同动作权限随机、常量动作、教师禁雷、教师原策略等诊断对照。
- 真机逐局帧数、终止原因、放雷数、关卡进度、决策延迟与实际帧推进分布。

固定验证划分是帧级随机划分，临近帧高度相关；新增三帧历史后训练输入和验证输入更可能共享像素。这不是“标签直接泄漏”，但会高估独立泛化。保留原验收划分不动；可在主训练回放上另开按连续时间块隔离、边界清除至少depth-1帧的诊断实验，不能把它与原训练样本预算混作同一实验。

ud0063保留为外部守卫，不用于训练、选难帧、调损失或调学习率；反复据其结果选模型会消耗其独立测试意义。最终报告如实说明使用次数。

## 13. 工程迁移与测试契约

- 新架构独立模块和config，保留v1/v2读取能力，不覆盖历史模型。
- checkpoint记录：arch、输入尺寸、depth、候选顺序版本、ROI物理大小、align_corners、归一化、head含义、损失配置、教师缓存指纹和数据划分哈希。
- `forward`建议返回：`policy_logits[ B,18 ]`、`heatmap_logits`、`position`、`danger_log`、`self_pred`；B阶段才要求`value`和放雷分布参数。
- 如保留旧`score()`接口，显式标记返回偏好logits，不让调用方误当px净空阈值使用。
- D9/D10先修并测，D11按原要求补缓存；不把数据加载速度提升混记为模型结构收益。
- 初版精确参数量、FLOPs、显存、每epoch时间和部署延迟必须实测；本文不给虚构的性能数字。
- 先做100批吞吐测量；超过60 s/epoch的预算需报告，不能静默加时。三帧会增加读取/卷积成本，不能保证仍等于40.4 s。
- 单实例实时游戏可能在推理期间继续推进。记录截图到按键延迟与实际帧差，不能把frameskip=2当成严格同步物理步长。

最低测试清单：

1. 三路输入、不同batch的输出形状、有限值、反向梯度。
2. 人工点图验证x/y、边缘ROI、有效性mask及坐标变换。
3. 验证预测中心采样，无真值坐标进入策略；扰乱特权标签不改变同画面动作。
4. episode/stage/时间不连续时历史重置，无未来帧。
5. 全并列排序损失为0、好坏跨组有梯度、无有效对不出现NaN。
6.18候选顺序与动作映射完全一致。
7. 感知损失确实更新定位头；detach仅阻断采样中心梯度。
8. checkpoint往返一致，v1/v2回归测试通过。
9. 全验证帧覆盖、末批样本数和加权指标正确。
10. B阶段：采样log-prob与evaluate_actions一致；旧策略不变时PPO ratio≈1；终止/截断/reset的GAE玩具轨迹正确。

## 14. 不做与退出条件

- 不用ud0063训练，不增加回放，不在本轮引入大型Transformer或复杂世界模型。
- 不直接修改教师来让后悔指标变好，不用训练指标替代真机生存。
- 不宣称换网络即可解决敌人/激光监督不足、教师短视或学生闭环分布偏移。
- 若E1/E3无收益，先查序列对齐、危险小集拟合和评分分布，再决定是否实现全架构。
- 若ROI因定位尾部误差持续伤害策略，可关闭局部路回退全局路，保留对照证据，不强行维护“局部一定更好”的假设。
- 若离线A-02提升但真机失败，优先查动作权限、延迟、分布偏移和教师任务覆盖，不继续只优化位置均值。

## 15. 建议采纳结论

建议采纳架构方向，但分步实施。当前最小行动是：修正确性问题，证明多帧输入和策略目标有效，再把预测位置与局部空间特征接到策略。真正的视觉PPO必须作为独立、有完整概率与价值契约的下一阶段，不能只给现有scorer换个名字。

## 3. 本轮真正的技术发现

### 3.1 时序（depth 1 → 3）几乎没用

六配置矩阵里 E0（depth1，legacy-reg）与 E1（depth3，legacy-reg）对比：
0–15 桶 3.767 → 3.728（−1%），全局反而 3.594 → 3.922（变差）；位置 13.128 → 13.056（−0.5%）。
**「多给三帧历史就能提升」的假设在本数据上没有成立**，这是要写进下一轮的前提。

### 3.2 目标函数是 v2 时代唯一的杠杆，但不够

E1 → E2（legacy → centered）：0–15 桶 3.728 → 3.050（−18%）、top3 0.225 → 0.451（2 倍）。
部分证实了「教师价值近乎并列导致逐候选回归塌成常数」的假设。
但纯 rank（E3a 3.110）并没有跑赢 centered，混合 E3c 与 E2 差 0.001 px（噪声级），
**rank 不是拉低桶后悔的那个杠杆**。

### 3.3 v3 空间网络才是决定性的一步

E5 筛选版（仅 24 感知轮）就把 0–15 桶打到 **1.355**、位置打到 2.46 px；
正式 72+12 轮后为 **1.271 px / 2.4066 px**。
根因是**输出网格**：v2 的 28×24 heatmap 一格对应 16 原生 px，v3 换成 56×48（8 px）并把 F4/F8 融合成单一 heatmap，
精度上限本来就被网格尺寸锁死；参数量只多 2.7 倍（554,873 → 1,507,162），不是容量问题。

正式预算下的三配置消融（各 72 感知 + 12 策略、全验证、seed 7、非 screening）：

| 配置 | state（ep28 joint-pass） | 0–15 桶 | 全局 | top3 |
| --- | --- | ---: | ---: | ---: |
| E4 local **关** / 辅助开 | 2.3314 px / 0.8006 | **1.899** | 1.280 | 0.5959 |
| **E5 local 开 / 辅助开（冻结款）** | 2.4066 px / 0.8166 | **1.271** | **0.870** | **0.6601** |
| E6 local 开 / 辅助**关** | 2.1873 px / 0.8037 | **1.519** | 1.013 | 0.6354 |

两条干净的消融结论：
- **局部 ROI 分支是必要的**：关掉后桶后悔 1.271 → 1.899（+49%）、top3 0.660 → 0.596；
- **策略期辅助项是必要的**：关掉后 1.271 → 1.519（+20%），正好把 A-02 从达标推到差一点；
- **只有 E5 过 A-02（<1.5）**，E4/E6 都不过；三者都能过 A-01（位置 2.19–2.41、danger 0.8006–0.8166）。

### 3.5 必须披露：训练不是位级可复现的

E5 与 E6 的**感知阶段配置完全相同**（E6 只把策略期辅助置零）、seed 都是 7，却从**第 1 个 epoch 就分叉**
（E5 ep1 位置 31.0962 px vs E6 ep1 22.5038 px）。原因是 CUDA 侧非确定性（cuDNN autotune / 原子加 / 解码线程调度）。

后果两条，必须写进下一轮前提：
1. **单次 run 之间 0.1 px 级差异不能当信号**——例如 E3c 与 E2 差 0.001 px 是没有意义的；
2. **A-01 的 danger 余量很薄**（0.8006–0.8166，线 0.8），跨 seed 可能翻转；稳定性只能靠多 seed 复核，
   不能靠"重跑一次看数字一不一样"。

### 3.6 一个反直觉但重要的观察

六个 v2 策略检查点的**全量感知重评位置是 8.06–9.14 px（全部 <10）**，但 danger 中位仍 0.62–0.64。
说明策略期的联合训练能把位置拉进线，而 danger 相关性是没被解决的那一半——
A-01 按契约只能读感知期 `state.best`，不能用 policy 检查点的感知值替代。

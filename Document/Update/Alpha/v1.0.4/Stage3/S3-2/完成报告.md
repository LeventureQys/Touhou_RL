## 1. 交付物与接口契约

### 1.1 新增 `touhou_rl/vision_losses.py`

```python
policy_loss(
    scores: torch.Tensor,          # float32 [B,18]，B>=1，有限
    teacher_px: torch.Tensor,      # 原始教师净空 px，[B,18]，float16 或 float32，有限
    objective: str,                # "legacy-reg" | "centered-reg" | "rank"
    rank_delta_px: float = 0.5,
    rank_weight: float = 1.0,
    regression_weight: float = 0.0,
) -> tuple[torch.Tensor, dict]     # (可微零维 loss, stats)
```

`stats` 固定 6 键（后五项均为有限数；计数为 Python `int`，损失为 Python `float`）：

| 键 | 含义 |
| --- | --- |
| `objective` | 实际使用的目标名 |
| `rank_loss` | 逐帧有效对均值再对 B 帧平均；非 rank 目标恒 0.0 |
| `regression_loss` | 回归项（legacy 或 centered）；rank 目标下为混合用的 centered 值，权重为 0 时也如实报告 |
| `valid_pairs` | 全批 `abs(v_i - v_j) > rank_delta_px` 的对数之和 |
| `frames_with_pairs` | 至少贡献一个有效对的帧数 |
| `frames_without_pairs` | 走 `scores.sum(1)*0` 占位的帧数；恒有 `frames_with_pairs + frames_without_pairs == B` |

三个目标的数学定义（与任务书字面一致）：

- `legacy-reg`：`SmoothL1(scores, clip(teacher_px, -8, 40)/10).mean`，等价于
  `vision_train.py:581` 的 v1.0.3 训练损失（单测逐元素比对）；
- `centered-reg`：`SmoothL1(scores - scores.mean(1,keepdim=True), (teacher_px - teacher_px.mean(1,keepdim=True))/10).mean`，不 clip；
- `rank`：全部 153 个 `i<j` 对，仅当 `abs(v_i - v_j) > delta` 时计算
  `softplus(-sign(v_i - v_j) * (s_i - s_j))`；**逐帧有效对平均 → 再对 B 帧平均**；
  无有效对帧用 `scores[row].sum()*0` 占位（零损失、零梯度但保图可反传）；
  总损失 `rank_weight*rank_loss + regression_weight*centered_loss`，默认 `(1, 0)`，R-a=(1,0)、R-b=(1,0.1)、R-c=(1,1)。

校验与错误码（全部 `ValueError`）：

- `v104:CONFIG`：非法 objective；`rank_delta_px < 0` 或非有限；任一权重为负或非有限；总权重 `<= 0`；
  非 rank 目标未显式 `rank_weight=0`、`regression_weight=1`（按契约"必须显式"拒绝，避免静默零损失）。
- `v104:DATA`：`scores` 非 tensor / 非 `[B,18]` / `B<1` / 非 float32 / 含非有限值；
  `teacher_px` 非 tensor / shape 不等 / 非浮点 / 非有限 / 与 scores 不同 device。

实现要点：帧内均值一律 `dim=1, keepdim=True`（`[B,1]` 广播），不用 `[B]`；`float16` 教师标签被接受并上采到
float32 参与计算（保留量化后的并列，量化并列对不计入）；153 个对索引按 device 缓存。

### 1.2 修改 `touhou_rl/vision_metrics.py`

`policy_metrics(pred[N,18], teacher[N,18], bullets[N,K,6])` 保留全部原键，新增**全局与每桶** 4 键：

| 键 | 定义 |
| --- | --- |
| `top3` | 学生 argmax 是否落在教师 `(-value, index)` 稳定排序的前三（严格索引集，无 0.5 松弛） |
| `top3_tie` | 学生 argmax 的教师原始值是否 `>=` 第三名分值（并列扩展集），恒有 `top3_tie >= top3` |
| `near_optimal_05` | `max(v) - v[chosen] <= 0.5` px |
| `regret_p90_px` | 逐帧后悔（未 clip 原始教师 px）的 90 分位，`numpy` 线性插值 |

- 原键 `top1`、`regret_px`、`by_danger[bucket,frames,top1,regret_px]` 名称与数值口径不变（§5 逐字节比对）；
- `chosen = 学生行 argmax`；`regret = actual.max(1) - actual[row, chosen]`，始终未 clip；
- 危险桶 `[0,15) [15,30) [30,60) [60,120) [120,inf)`，无有效 bullet（`bullets[:,:,5] <= 0.5`）落 120+，
  距离 `sqrt((dx*192)^2 + (dy*224)^2)`；空桶 `frames=0` 且各指标 0.0（仅兼容展示，不得判通过）；
- `N=0` 仍返回零值（含新增键）。
- 新增 `v104:DATA` 错误：pred/teacher 非 `[N,18]`、帧数不一致、bullets 非 `[N,K,6]` 或帧数不一致、
  pred/teacher/bullets 含非有限值。
- 距离改用 float64（输入仍按 float32 标签量化）：float32 下恰好 15 px 的子弹可能舍入成 14.9999995 而误入
  0–15 桶（A-02 判定桶）；§5 证明固定样本数值零漂移。

`heatmap_hit_rate(logits[N,H,W], truth[N,24])`：网格改为**实际 H/W**（不再写死 28×24），
真值 cell `round(x*W-0.5), round(y*H-0.5)` 后裁边界，预测 argmax 行优先（`reshape(H*W)`），横纵各 `<=1` 格命中；
兼容 28×24、56×48、`N=0`；非 3 维 logits / 帧数不一致 / 空网格 / 非有限 logits 或真值坐标抛 `v104:DATA`。

`all_state_metrics`：12 个原键与口径不变；仅当显式传入 `heatmap_logits` 时才多 `heatmap_hit_rate`。
新增非有限失败路径：`player_position_mae_px`、`self_mae`、`ray_mae`、`bullet_count_mae`、`danger_metrics`、
`heatmap_hit_rate`、`policy_metrics` 对非有限预测/标签抛 `v104:DATA`，不再走 `_round` 归零路径
（旧行为会把 `nan` 位置误差报成 0.0，直接伪装 A-01 达标）。

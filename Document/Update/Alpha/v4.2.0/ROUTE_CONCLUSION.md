## 0 本文档的口径（先读这一节，否则数字会被误读）

**结论：v4.2.0 的产出是一组高质量的有效负结果，加一条被真实执行的 RL 诊断链；能力门一个都没过，但每一个"为什么没过"现在都有可复算的数字。**

### 0.1 三条硬口径

| 规则 | 含义 | 违反示例 |
|---|---|---|
| **可追溯** | 每个数字必须能指到一个证据文件；指不到的数字本文档不写 | 不写"大约提升 20%"这类没有出处的估计 |
| **不四舍五入** | 引用时保留证据文件的原始位数；只在明确标注"复算"处做算术 | 不把 0.33298205922092694 写成 0.33，除非同时给出全值 |
| **不外推** | 样本不足时写"未定"，并给出已有的部分数据，不按比率推断结论 | 不把 5/20 的 dev 结果写成 20 局结论 |

### 0.2 四个判定词

| 词 | 用法 |
|---|---|
| **支持** | 实测数字落在假设预测的方向上，且有对照或可复算的中间量 |
| **证伪** | 实测数字与假设预测相反，或假设要求的量在结构上不可达 |
| **未定** | 关键样本未齐（本文档只有 H-f 属于此），给出已有部分数据且不外推 |
| **未做** | 该项实验在本版本里根本没有执行（本文档有 H-h） |

| 判定 | 条数 | 条目 |
|---|---:|---|

> **一条读法**：这 8 条不是"8 个互不相干的失败"，而是一条被逐步收窄的排除链——
> 时间契约（H-a 的数据前提）→ 标签可用性（H-b）→ 状态覆盖（H-c）→ 折扣可见性（H-d）→
> 策略漂移（H-e）→ 奖励盲区（H-f，仍未定）。每一步都把上一步的候选原因排除掉，
> **最终仍未过关**，但每一步的排除都有独立数字。

## 8 一页复用摘要

**结论：可以直接复用的是 6 条排除结论与 3 条已锁死的机制事实；下一步唯一入口是"r3 补完 + 标签 matched ablation + 判据修订后的 50k 复现"，而不是加轮次或直接上 1M。**

### 8.1 六条可直接复用的排除结论

1. **时间契约不再是瓶颈**：19,772 槽每槽自带 obs/HUD/执行动作/8 条历史/18 路 verified 标签，自检 0 违反（G420-0 passed）。
2. **2 帧节拍本身不是瓶颈**：它在每一个被评测的 checkpoint 上都没有产生过 1 次过关，但也没有在任何一项一致性检查上引入可检测的差异。
3. **教师标签不是"越多越好"的问题**：每槽只有 1 个 verified 候选，`|S|≡1` 使集合监督**结构上不存在**；要 A1 必须先有 proper 状态。
4. **DAgger 的 β=0 覆盖是真的，但三轮后回撤**：D2 +16.21% → D3 +4.87%，停止条件已触发，配方按计划结束。
5. **RL 的塌缩主因是"无锚的系统性函数漂移"**：同空间 argmax 翻转 61.7% → 1.17%（−98%），KL_T1 均值 3.276 → 0.0058 nat，权重位移幅度几乎没变（2.68e-3 vs 3.37e-3）⇒ **限制参数位移防不住塌陷，必须在部署空间锚定函数**。
6. **奖励确实看不见首死存活**：`corr(return, 首死帧)` 从 0.3545 抬到 0.948483（新判据在 r3 pass、在 r2 fail），但**这还没有变成能力**（0/5 过关）。

### 8.2 三条已锁死的机制事实（后续任何配方都必须遵守）

| 事实 | 数字 | 后果 |
|---|---|---|
| 引擎需要 SHOOT 的**上升沿**才能离开过关状态 | 无脉冲 13,272 帧不过关（分数停 141,379）；加 48 决策脉冲后 13,195 帧过关（2,631,430） | 训练环境的 `shoot_pulse_period=48` 属**动作层**；训练/评测的脉冲错配未量化，是"永远不可能过关"的必要条件之一 |
| A0 在 T=1 下**采样退化** | 行熵 0.4126 nat、有效动作 1.5108；T=8 后 2.3948 nat、10.9664 | 温度属于**探索**、不改 argmax；任何"健康指标"必须在 T=1 空间量 |
| 同一次更新内部就能把策略推离自己的 rollout 数据 | 更新内 `ratio` 最大偏离 0.256（最大 0.479），换成对数比 0.391 nat（T=8）≈ **3.13 nat（部署空间）** | 49 次更新不是"轻微扰动"，是 392 个 Adam 满步 |

### 8.3 下一步唯一入口（按依赖）

1. **补完 r3 的两口径 20 局**（当前 5/20 diag，s1n 0/20）——这是 H-f 从"未定"变成"可判定"的唯一途径。
2. **做标签的 matched ablation**（offset-0 / offset-1 各两臂，不需要引擎）——这是"教师标签是否瓶颈"的唯一定判据，比再加一轮 DAgger 便宜两个数量级。
3. **把 KL 判据修订写死并复现 50k**（对比集 mean + p99 取代单轨迹 `max_t`；P2 拆两条；P3 分尺子判），然后才谈 1M。
4. 以上任一出现"整面过关"，才启动 G420-4 的 100 局确认批与 G420-5 的 Windows 会话。
5. **R1 严格像素自我改进保持"未做"**，不得以 r2/r3 的任何结果替代。

### 10.2 最后一条的机制（唯一有名字的降级）

`L_set = −log Σ_{a∈S} π(a|s)` 最大化安全集合的总概率质量。**在首死前 30–120 帧的状态上，安全集合被"仅能存活、通常被动"的动作占满** ⇒ 梯度**奖励被动** ⇒ 策略学会"苟住不动"，在 669 帧就死。

两口径比值暴露了这一点：setsup **2.78×**（1859.35/669.0）vs R0 **1.67×**（2748.0/1650.4）——**被动性在首死尺子下暴露得远比 S1N 下强烈**。

### 10.9 第八条路径：观测里**没有威力**（第 145 轮，结论级反转）

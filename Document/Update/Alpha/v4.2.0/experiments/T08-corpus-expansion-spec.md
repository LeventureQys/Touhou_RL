## 1 为什么做这个实验（依据是分支 ②，不是猜测）

`SETLOSS_FORM` 把集合监督的失败分解成**两个独立缺陷**，且两者都被单独测量过：

| 臂 | DIAG 均值（新仪器，n=20） | 塌缩 | 留出 set-hit |
|---|---:|---|---:|
| `set_mass` @ 138 状态 | **669.0** | **常数 `NE`**（1 种长度，全 669 帧，`NE` 58.7%） | 0.550 |
| `uniform_in_set` @ 138 状态 | **1139.9** | **已修好**（19 种长度 661–1647，`NE` 13.3%，17.3/18 有效动作） | **0.450**（随机 0.5389） |
| R0（BC 先验） | **1650.4** | — | 训练于 **19,772** 槽 |

**修好塌缩捡回 +470.9 帧；剩余 −510.5 帧的缺口随损失形式改变而存活 ⇒ 归因于泛化 ⇒ 泛化归因于数据规模。**

规模对照是这项归因的核心：**BC 先验见过 19,772 个槽，本臂只见过 138 个状态。**

## 2 唯一改动

**只改语料规模**：178 proper 状态 → **目标 ≥600 proper 状态**（约 3.4×）。其余**逐字节照抄**：

| 项 | 值（不动） |
|---|---|
| 损失形式 | `uniform_in_set`（塌缩已被它修好；**不换回 `set_mass`，不试 `hinge`**） |
| 超参 | seed 0 / 5,000 步 / batch 128 / Adam lr 1e-4 / wd 0 / clip 0.5 / cuda / 严格确定性 |
| 状态来源 | **仅 TRAIN seed**，每局取**首死前 30/60/90/120 帧** |
| 每状态候选 | **18**（全部） |
| 续行 | A0 `96cb219e…6b89ad`，**H=120** |
| 划分 | 状态级、祖先不交叉；留出比例沿用 `holdout_modulus=5, remainder=4`（约 22.5%） |
| 评测仪器 | `tools/rl/v420_eval_shoot.py`，`--shoot-pulse-period 48 --obs-window consecutive`，两口径各 20 dev 局（1000–1019） |

## 4 预注册判据（跑前冻结，跑后不改）

### 4.1 主判据：泛化是否随规模上升

| 编号 | 判据 | 阈值 | 依据 |
|---|---|---|---|
| **D1** | **留出 set-hit** | **> 0.6389**（= 随机 0.5389 + 0.10） | 与 `SETLOSS_FORM` 同一门槛，**同一把尺子**；上一轮 0.450 |

### 4.2 次判据

| 编号 | 判据 | 阈值 |
|---|---|---|
| **D2** | 留出 set-hit **单调性** | 必须 > 0.450（138 状态时的值）；若 ≤ 0.450 则规模增加**无效** |
| **D3** | 不塌缩保持 | 20 个 DIAG 局**≥3 种长度** 且 `NE` < 50% |
| **D4** | 帧数阶梯 | DIAG **≥ 1139.9**（138 状态 `uniform_in_set` 的值） |
| **D5** | 追平 BC 先验 | DIAG **≥ 1650.4** 或 S1N **≥ 2824.35**（新仪器 R0） |
| **D6** | 能力 | 两口径 40 局里 **`stage_clear ≥ 1`** |

### 4.3 五条决策规则（**这是本规格的核心产出**）

| 分支 | 条件 | 结论 | 下一步 |
|---|---|---|---|
| **①** | D1 成立（hit > 0.6389）且 D5 成立 | **数据规模是唯一约束，且 178→600 已跨过阈值** | 继续扩到 1,500+；能力判据 D6 单独追 |
| **②** | D1 成立但 D5 不成立 | 规模缓解泛化，但**不足以追平 BC 先验** | 扩规模 + 首次考虑"监督信号类型"与"规模"的交互 |
| **③** | **D2 成立（hit 上升）但 D1 不成立** | **规模有效但未达门槛** ⇒ 需要更多状态，且能**估算所需规模**（用 hit vs 规模的两点斜率外推，并明确标注是外推） | 按外推规模再扩一次 |
| **④** | **D1 与 D2 都不成立（hit ≤ 0.450）** | **数据规模不是约束** ⇒ 集合监督的**表征方式**有问题，扩多少都没用 | **放弃"扩语料"路线**，转向"换观测表征"（§10.6 第 3 条）或承认该路关闭 |
| **⑤** | D6 成立（出现过关） | **首次能力证据** | 仍需声明单 seed / n=20；随后按 G420-4 重新立预注册 |

**关键设计**：分支 ③ 与 ④ 都能**推进理解**，所以这不是一次赌注 —— 若规模无效，本规格**同样会给出一个明确结论**，并**关闭"扩语料"这条路**，而不是留下"或许再大一点就行"的模糊空间。

## 5 必须防的三个陷阱

1. **不得中途改判据**。130/200 状态时的中间 `hit` 不得用于调阈值。
2. **不得混用 checkpoint 或语料**。新语料的 600 状态必须与 178 状态**完全不重叠**（或明确声明为超集并单独标注），否则规模效应与重复样本效应无法分离。**推荐：从 train seeds 3042–3091 的 200 个已有状态之外，再取 400 个新状态**（更大 offset 网格或更多 seed），使 178 → 约 530–600，并报告重叠数。
3. **不得并行多训练**。本会话已三次因负载过载（load 82 / 40.75 / 多次 2–5× 墙钟膨胀）污染时间测量；训练与 dev 严格串行，单条 ≤10 分钟。

## 6 本规格不能主张什么

1. 若分支 ④ 成立，**不等于**"集合监督无用" —— 只排除"在当前观测表征下靠扩规模解决"。
2. 若分支 ①/⑤ 成立，**不等于** G420-4 通过 —— 仍是单 seed、n=20，无区间。
3. 本规格**不产生任何 R1 主张**：用的是 BC 初始化与离线标签，属监督学习范畴。
4. 规模外推（分支 ③）**是外推**，必须以"两点斜率"形式给出并标注不确定性，不得当作承诺。

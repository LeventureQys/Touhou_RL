# T08 观测修正预注册规格：把 `power` 放进观测

- 作者：主代理　|　写作时间：2026-11-14T19:30+08:00
- 状态：**规格已完成，未派发**
- 上游依据：[`../ROUTE_CONCLUSION.md`](../ROUTE_CONCLUSION.md) §10.9–10.12、[`../evidence/T06/REWARD_R4.md`](../evidence/T06/REWARD_R4.md)

## 1 为什么做（依据是可测的几何事实，不是假设）

第 145 轮的三组对照把"观测里有没有威力"钉死了：

| 对照 | 读数 | 含义 |
|---|---|---|
| 正对照 `power_band` | R² **0.99999999**、MAE 0.0023 | 探针本身可靠 |
| 区域几何 | 威力像素在 **rows 136–151 / cols 488–616**（`Gui.cpp:1348-1387`） | 位置确定 |
| **裁剪覆盖** | `play` 裁 x32–416、`hud` 裁 rows 48–112 | **两个裁剪都不覆盖 136–151** |
| **平移零分布** | `hud` 真 0.6638 vs 平移 **0.7246**；`play` 真 0.8373 vs 平移 **0.8793** | **真信号弱于零分布** |

⇒ **`power` 不在观测里。** 而 r4 的威力奖励因此**原理上不可学**：P1 的 p=0.1140 / 0.1196 不是"威力没用"，是**输入无法表达该量**。

**几何依据的第二个独立来源**（主代理第 176 轮复核，不依赖代理自述）：
`touhou_rl/v400/student/obs_spec_v3.py` 明写 `play` 是 **`(32,16)` 的 384×448 playfield 视口**做 **4×4 整数块均值**得到 96×112，`hud` 是 **56×160 的 HUD 条**。
⇒ `play` 覆盖面板 **x32–416**，`hud` 仅 56 行；而威力条在 **rows 136–151**。
⇒ 无论 `hud` 从哪一行起，**56 行的高度加上 `play` 的视口都无法覆盖 136–151**（代理实测 `hud` 为 rows 48–112，结束于威力条上方 24 行）。
**观测规约与代理测量互相印证**，不是互相引用。

## 2 两个候选方案

| 方案 | 做法 | R1 兼容 | 优点 | 缺点 |
|---|---|---|---|---|
| **A（推荐）** | 在现有 `hud (1,56,160)` 之外**新增一个像素通道** `hud_power (1,24,160)` = 面板 rows **128–152** | **是**（仍是纯像素） | 保持"只喂像素"的路线，§10.5 关于"R1 未做"的缺口不被进一步放大 | 观测契约变 ⇒ 语料必须重建 |
| **B** | 把 `power` 作为**特权标量**通道（与 `act_hist (8,18)` 同层，归一化到 [0,1]） | **否**（特权信息） | 精确、无像素解释歧义 | 把 R2 的特权性带进策略输入，`G420-4` 的能力主张会永久失去 R1 资格 |

**推荐 A**。理由：本版本至今**没有任何 R1（严格像素）结果**，而 §10.5 已把这条列为不能主张项。选 B 会把"用特权信息"写进观测契约，之后即使过关也无法升级为 R1 主张 —— 那是**不可逆的**路线收缩。A 只多花一次语料重建的代价，就保住了这个资格。

## 3 唯一改动

**只改观测**：新增 `hud_power` 通道。其余**逐字节不变**：

| 项 | 值 |
|---|---|
| `play` / `hud` / `act_hist` | **形状与裁剪完全不动**（保证与旧语料可比、可做混合消融） |
| 动作空间 | 18 候选，bomb 固定 0 |
| 决策节拍 | 2 帧/槽 |
| 奖励 | **r4**（`power_gain = 3.906e-04`）与 **r3 对照**各一条 |
| 超参 | seed 0 / 5000 步 / batch 128 / lr 1e-4 / clip 0.5 / 严格确定性 |

## 4 语料重建（这是主要成本）

`play`/`hud`/`act_hist` 是**烘焙在槽记录里**的，新增通道必须重物化：

| 步骤 | 说明 | 参考成本（实测） |
|---|---|---|
| T02c 2 帧重建切片 | 复用 `v420/rebuild.py` | 已有产物，约 1000 MiB |
| T02d 教师 2 帧重标 | 19,796 槽 × 18 候选 | 已有产物 |
| **新增**：物化 `hud_power` | 从同一批录制帧**离线裁剪**，不重跑引擎 | **低**（纯 numpy 裁剪） |
| T04 数据集 join | 19,772 槽 | 分钟级 |

**关键**：`hud_power` 可以从**已录制的帧**离线裁剪出来 —— 只要录制帧保留了面板原始行（需先核实 `.tmp_v420_data/T02c/**/2f/` 里存的 `play` 是否来自完整帧，还是已裁剪的 112×96 张量）。**若只存了裁剪后的张量，则必须重跑引擎录制，成本升到小时级。这是派发前必须先核实的第一件事。**

## 5 预注册判据（跑前冻结）

### 5.1 观测可读性（含零分布，这是 §10.12 的教训）

| 编号 | 判据 | 阈值 |
|---|---|---|
| **O1** | 新通道对 `power` 的样本外 **R²** | **> 0.90** |
| **O2** | **必须同时**：R² 高于**平移零分布**至少 **0.20** | 防重演 0.66/0.84 的混淆 |
| **O3** | 正对照（`power_band` 区域自身） | R² > 0.99 |

**没有 O2 这一步，本规格就不许执行** —— 否则会重复第 133 轮的误判。

### 5.2 行为与能力

| 编号 | 判据 | 阈值 | 基线 |
|---|---|---|---|
| **B1** | `Δpower/局`（r4 新观测 vs **同轮** r4 旧观测对照） | 单侧 Welch t **p < 0.05** 且置换 p < 0.05 | 旧观测 17.5455（r4）、14.5909（r3） |
| **B2** | `diag_first_death` 20 dev 均值 | **> 1650.05**（r4 旧观测） | 新仪器 |
| **B3** | 两口径 40 局 `stage_clear` | **≥ 1** | — |

### 5.3 六条决策规则

| 分支 | 条件 | 结论 | 下一步 |
|---|---|---|---|
| **①** | O1+O2 成立且 B1 成立 | **观测是瓶颈**，威力终于可学 | 看 B2/B3；若 B2/B3 不动则威力不是存活瓶颈 |
| **②** | O1+O2 成立但 B1 不成立 | 威力**可读但学不会** ⇒ **信用分配**是瓶颈（延迟收益） | 转向 reward shaping / 更长 rollout |
| **③** | O1+O2 不成立 | 裁剪改错了或通道无信息 ⇒ **观测这条假设被证伪** | 转 §10.11 方案 B 或放弃该机制 |
| **④** | B3 成立（出现过关） | **首次能力证据** | 仍须声明单 seed / n=20；随后按 G420-4 重新预注册 |
| **⑤** | B1 成立但 B2 不升 | 多捡了 P，但**存活未改善** ⇒ 威力不是存活瓶颈（与用户第二点呼应） | 转测"上移到自动收集线以上" |
| **⑥** | O2 通过但 O1 未过 | 通道有相对信息但绝对精度不足 | 扩通道高度到 rows 120–160 |

## 6 必须防的四个陷阱

1. **不得跳过 O2**（零分布对照）—— 这是本规格存在的首要理由
2. **不得只改观测就重跑旧语料** —— 旧语料不含新通道，混用会让"新观测"实际上是"旧观测+噪声"
3. **不得同时改奖励** —— 奖励固定 r4，否则 B1 无法归因
4. **不得在扩容未完成时启动语料重建** —— 两者都吃引擎与磁盘；扩容 `run_all` pid 397 跑完（750/750）再动

## 7 成本与预算

| 项 | 值 |
|---|---|
| 语料重建（**若录制帧含完整面板**） | 低：纯离线裁剪 + join，**< 1 h** |
| 语料重建（**若只存裁剪张量**） | 高：重跑录制，**≈ 3–5 h 三 worker** |
| 两条 50k 训练（r4 新观测 + 同轮对照） | **≈ 35 min** |
| 两口径各 20 dev × 2 臂 | **≈ 50 min** |
| 合计 | **1.5 h（乐观）/ 5–6 h（悲观）** |
| 当前墙钟用量 | ≈ 26%（上限 96 h）⇒ 两者都在册内 |

## 9 本规格不能主张什么

1. 本规格**不保证**提高能力：即使 B1 成立，B2/B3 可能仍然不动。
2. 即便 A 是纯像素方案，**本次实验也不构成 R1 主张** —— R1 需要从零只用像素自我改进，而这里仍是 BC 初始化 + 离线标签。
3. O1/O2 只证明"通道含威力信息"，不证明"策略会用它"。
4. 单 seed / 50k / n=20 ⇒ 无区间结论。

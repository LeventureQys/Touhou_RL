# v4.2.0 首轮执行任务单

依据：[版本计划](README.md)。状态：待执行。适用于资产主机，当前训练保持 paused。

本任务单用于以后明确派发“执行 v4.2.0”时接手；制定计划不等于恢复旧 WP05。首轮从 T00 开始，不先补完旧 round3，也不先跑全量训练。

## 1 派发边界

每个任务交给 Provider=DeepSeek、模型=DeepSeek Flash。主代理只规划、审查范围、核对命令与统计。一次至多一个重 GPU 作业和一个 CPU 标注批次，任务依赖满足才并行。

所有任务禁止删除、移动、覆盖旧资产；不修改旧 ABI、第三方、依赖、默认部署模型、v4.1.0 state/journal/budget 或旧证据；不提交、不上传。新代码只写 v420 白名单。新增运行资产由资产主机所有者登记至资产清单。

本任务单中的 v420 CLI 是未来实现约定。T00 先核对真实模块与参数，在 T01 实现薄入口；后续调用受此依赖约束。主代理验收时必须确认命令确实执行、退出码与原始报告一致，不能只照录代理结论。

tools/rl/v420.py 由 T01 的入口 owner 负责集成，后续子命令串行接入；其他任务不同时改公共入口。配置验证必须拒绝空的资产路径、指向旧资产的输出路径和未声明恢复模式的既有 run 目录。

## 2 T00 固定远端路径与历史参照

目标：定位资产、源码与原执行命令，为一个最小真实复现准备输入。

允许修改：Document/Update/Alpha/v4.2.0/experiments/、本版本 evidence/T00/ 中的新小证据、configs/v420/local.json。旧对象只读。

在资产主机选定执行检出和 Python。建立环境变量 ROOT420、PY420、ENGINE420、V420_DATA，均使用核验过的绝对路径，写入新 local.json；实际值来自资产主机，不照搬当前编辑端路径。local.json 位于 configs/v420/，不含凭据，按现有仓库规则处理本机路径。

验收命令在资产主机执行，先为当前 shell 设置变量；下面是 Bash 形式：

~~~bash
cd "$ROOT420"
"$PY420" --version
sha256sum "$ENGINE420"
"$PY420" -c 'import importlib.util, sys; spec=importlib.util.find_spec("touhou_rl.v410"); print(spec); sys.exit(0 if spec is not None else 2)'
sha256sum -c ASSET_SYNC.sha256
~~~

sha 清单中旧快照、换行或路径不匹配要逐对象解释；不得为得到全绿而改旧哈希。仅当实际读取的源码、引擎、数据、权重身份已确认，才允许跑复现。某个非必需旧文件缺失，不阻止其他已核验对象。

输出：资产主机路径映射、已消费对象的核验表、原 B0/20k evaluator 的完整 argv、基线逐局参照、split 与种子曝光登记、剩余预算下界。字段缺失写 unknown。

立即返回：完成/未完成、变更文件、每条命令与退出码、已核验/缺失/待解释对象数、下一任务的精确 argv。不得开启训练。

## 10 主代理验收与停止条件

每项验收都核对改动白名单、实际 argv、退出码、原始分母、checkpoint/源码/引擎身份和资源余额。缺原始输入或身份不匹配时只标该结果未验证，继续不依赖它的有效工作。

阶段 A/B/C 的资源按版本计划共同约束，不能给每个子代理各发一份 48 GPU 小时或 96 小时。每条命令执行前估算剩余额度，80% 处停止新增长任务。长任务每 60 秒更新可读进度，完成或遇阻立即返回。

实际业务测试只在对应实现变更后运行；文档、单测、管线 smoke、训练微段与标准能力分别结算。版本门未通过时保留真实缺口，项目最终目标仍未完成。

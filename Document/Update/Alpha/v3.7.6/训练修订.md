# v3.7.6 真实F2训练修订与执行边界

## 1. 决策与原规格的关系

用户选择真实F2回放示范动作行为克隆（BC），并授权三独立replay研究变体补采。它是**新增实验分支，不是原U05/G4关系目标通过**。

- F2是瞄准弹流；旧教师对其没有固有gap目标。gap_center、relative_dx、deadline、route等关系/规划监督不适用，字段为null、相关valid mask=false，不能补0冒标签。
- 标签仅为解码并按stage frame对齐的真实回放演示动作，不声称最优、安全或完整可行集；unknown/unmappable/bomb不静默变hold。
- 原U05关系目标、8事件、四臂、三seed及留出效应验收为not_run，须另行重设计预注册；BC单臂/一更新不代验任何原任务。
- 原报告不重写；新增配置、数据、报告、缓存/checkpoint一律新目录，不覆盖旧run。默认模型及canonical保持不变。

## 3. 真实训练准入链

1. B3+D1共同冻结标签schema、动作语义、来源与split，不再出现互相等待。
2. exact深审必须核验逐帧proof、图像内容、完整活动池audit-state与collectionProvenance的replay/config绑定；top64训练摘要不能替代完整审计状态。审计状态与标签资产隔离，绝不进入模型部署观测。
3. 独立画面审查者依据原图和当前/过去帧确认自机、可见弹体、至少两次同一发射源重复瞄准证据、坐标单位及时间范围。reviewpack只提供图像/索引/哈希及待填模板；脚本验证结构/绑定，不能认证审查者诚实，更不能生成虚假通过注释。
4. 本轮发现train的stageFrame 5451重复55行、validation的5706重复94行（logicFrame仍前进），test无重复。不能按stageFrame首尾范围猜回放索引；歧义帧整组排除并保留原因，不改raw、不降级exact。reviewpack/dataset正同步修复，最终reviewpack输出r3。精确同帧并不自动证明动作标签能唯一对齐。
5. [候选配置](<configs/f2-bc-v1.json>)冻结来源选择，并不等于dataset builder的 `v376-f2-bc-plan/1`。review齐备后另存冻结事件plan，绑定upstream manifest/replay/collect_config/teacher artifact及review内容SHA。
5. 至少train/validation/test三独立replay来源组；同episode/template/派生关联不得跨split。帧、shard、stage窗口不能充当独立来源。按组分配后切窗口，真实像素逐帧重包泄漏及未来帧一律拒绝。
6. 解码回放并以stage frame对齐；物理键盘input readback不是回放动作标签。因果历史、动作生效、有效mask及输入/标签隔离通过内容审计；未映射动作保留unknown、无动作梯度。
7. 每事件须有真实reviewed示范；train/validation burn-in之后须有可监督行。少样本/不支持族如实报告。任何review、来源、身份、对齐或覆盖缺失都阻断真实准入，不能以fake/工程smoke代替。
8. build/audit/check-gate全过后才复用冻结v3-st缓存及序列训练。test不用于选模；先一更新验证，再另申请长训练。

## 4. 真实准入后的命令模板

**以下是待执行模板，不是运行成功记录。当前缺独立画面review时不得执行后续真实训练。** 将 `$plan` 替换为已绑定真实review的冻结事件plan，不能直接传候选预注册配置。所有输出目录必须不存在；失败保留目录并换新run_id，不覆盖。

```powershell
$plan = '<reviewed-frozen-v376-f2-bc-plan.json>'
$newout = '<new-f2-dataset-output-directory>'
$manifest = "$newout/manifest.json"
$baseline = 'third_party/th08/build/rl/runs/v104-v3-E5-s7/policy.pt'
$cache = '<new-frozen-feature-cache-directory>'
$run = '<new-one-update-output-directory>'

# 先build；没有真实review/来源绑定时必须拒绝
python -m touhou_rl.f2_dataset build $plan $newout
python -m touhou_rl.f2_dataset audit $manifest
python -m touhou_rl.tactical_train check-gate --manifest $manifest

# 仅上述三步均exit 0后继续；复用现有冻结骨干缓存
python -m touhou_rl.tactical_feature_cache `
  --manifest $manifest --baseline $baseline --out $cache `
  --device cpu --batch-size 16

# 最多一个更新，不是长训练或G4验收
python -m touhou_rl.tactical_sequence_train `
  --manifest $manifest --cache-index "$cache/index.json" `
  --baseline $baseline --out $run --arm N1 --seed 7 `
  --epochs 1 --max-updates 1 --device cpu
```

调用对应 [dataset入口](<../../../../touhou_rl/f2_dataset.py>)、[check-gate](<../../../../touhou_rl/tactical_train.py>)、[feature cache](<../../../../touhou_rl/tactical_feature_cache.py>)、[sequence train](<../../../../touhou_rl/tactical_sequence_train.py>)。执行者须逐命令检查退出码、保存stdout/stderr及resolved身份；PowerShell不会因普通外部命令非零自动停止，**前一步失败严禁手工继续**。

一次更新只能证明数据/缓存/优化器/冻结骨干/落盘链路；还应报告实际有效样本与更新数、unknown比例、骨干参数/buffers前后SHA和checkpoint身份。未执行时写not_run；全部mask无效时不得伪报完成一次有效更新。它不证明学习、泛化、闭环、玩法改善、发布或原G4。

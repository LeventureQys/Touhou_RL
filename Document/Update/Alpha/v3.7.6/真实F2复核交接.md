## 审查者要做什么

1. 不把自机频繁运动、内存有弹、脚本采集成功当成 F2 证据。只接受图上可独立辨识的瞄准弹流。
2. 按冻结来源顺序检查候选。记录取舍理由，不按模型结果挑片段；同来源/模板/episode/镜像派生跟随原 split。
3. 逐事件导出 review：至少 48 个因果输入行，前 16 行是 burn-in，后段必须有有效示范标签。不能用一张图证明整段发射因果。
4. 独立标注图上自机和弹体位置、轨迹，以及同发射体至少两次瞄准证据；所有标注绑定具体 image SHA 和 frame。使用图像坐标 image_px，640×480 原图；游戏场地区域原点是 (32,16)。
5. 内存轨迹在 privileged_audit 独立区域，仅用于核对，不是像素标注。teacher 的 slot:N 仅池槽，不是生命周期ID；必须核查重用/遮挡，不能跨生命周期拼轨迹。
6. 保留明确 context_only/unknown 行，缺证据不能标 hold。bomb、非18路、矛盾按键也无动作监督。F2 gap/deadline/route/relative_dx 不适用。
7. 用不同 producer 的 teacher artifact 与独立 pixel reviewer 核对，显式设定单位/位置及瞄准容差。SHA 能证明身份，不能证明审查者诚实。
8. pending 模板故意不能建训练集：player_px=null、bullet_tracks=[]、annotation=null、frozen=false。填完并独立复核后方可冻结，不要只把 frozen 改 true。

## 冻结计划与训练命令

数据构建计划要求 `v376-f2-bc-plan/1`；完整结构和受支持配置以 [f2_dataset.py](<../../../../touhou_rl/f2_dataset.py>) 的模块说明与 DEFAULT_CONFIG 为准。plan 根必须是原始来源的共同父目录（建议仓库根），所有来源引用相对此根，禁止路径逃逸。不要将文档目录中的 `../../..` 作为逃逸引用塞给 builder。

原始来源固定为：
- train: `third_party/th08/build/rl/exact/v376-f2-train-20261104-r1`
- validation: `third_party/th08/build/rl/exact/v376-f2-validation-20261104-r1`
- test: `third_party/th08/build/rl/exact/v376-f2-test-20261104-r1`

计划中来源必须绑定各自 frame-proof.json、collect-report.json、audit-state.jsonl、原 .rpy 的完整 SHA；collect_config 指向 collect-report.json，collection_config_sha256 使用其中 capture_identity.config_sha256。用户已冻结候选方案 [f2-bc-v1.json](<configs/f2-bc-v1.json>)，但它不是已标注事件 plan，不能直接 build。

以下占位路径需在复核后替换，不代表文件已经存在：

```powershell

python -B -m touhou_rl.f2_dataset build <frozen-plan.json> <new-dataset-dir>
python -B -m touhou_rl.f2_dataset audit <new-dataset-dir>/manifest.json
python -B -m touhou_rl.tactical_train check-gate --manifest <new-dataset-dir>/manifest.json

# 2. 冻结v3-st特征，不碰test tensor做训练/选模

# 3. 先一更新短测，不擅自长训练
python -B -m touhou_rl.tactical_sequence_train --manifest <new-dataset-dir>/manifest.json --cache-index <new-cache-dir>/index.json --baseline third_party/th08/build/rl/runs/v104-v3-E5-s7/policy.pt --out <new-train-dir> --arm N1 --epochs 1 --max-updates 1 --seed 7 --device cuda
```

## 3. 有效性诊断

### 3.1 1,200 条 / 格不是 1,200 个独立样本

同一格内是 4 个窗口 × 300 条，**窗口是固定效应**（§2.1 的窗口表差三倍），同一格内的 1,200 条不是独立同分布。**格级比例不能当 i.i.d. 二项样本来做检验**——这也是本轮不做 Fisher 的理由之一。

### 3.2 完整性是硬门，不是软提示

每格应有 1,200 行；**行数 = 1,200 才进表**。22 个不完整格加 `.partial` 后缀发布，**没有一个数字来自 `.partial`**。`.partial` 格的池化比例受**窗口前缀**影响（L2 900 档只覆盖窗口 11 + 窗口 12 的一部分），**系统性低估**——`RUN.md` §4.3 给了具体反例（同臂窗口 11 是 11.78%、窗口 17 是 35.67%）。

### 3.3 触发可观测性（本轮真正的机制证据）

| 量 | L1（3 px） | L2（5 px） |
| --- | ---: | ---: |
| 触发率（每局） | **0.83%** | **41.4%**（600 档） |
| 触发时的距离 | **2.833–2.996 px** | 上界 4.999 px |
| 死亡局中「最小观测距离始终 > 阈值」的比例 | **98.75–99.83%** | 71.0–77.4%（600）/ 59.7–62.4%（1,200） |
| 最小观测距离中位数 | **5.26–5.38 px** | 5.29–5.46 px |
| 决策粒度 | **2 帧** | **2 帧** |

**读法**：2 帧的采样网格 + ~5.3 px 的典型最近距离 ⇒ **3 px 判据在网格上几乎不出现**；5 px 判据能覆盖到约四成局面，但**仍有一半以上的死亡发生在「从没被采样到 ≤5 px」的局里**。

**一句话的物理图像**：80 px 规则在**危险还没成形**时就放雷（几乎每局第一条决策），所以 600 决策能到 71%；lethal-only 等**采样点上真的出现 ≤5 px** 才放，而 2 帧的网格让这件事只在四成局里发生、且发生时距命中区只剩 0.8–1.0 px。**到 1,200 决策两条规则都撞地板（1.00% / 1.56%），说明 40 s 这个预算是这一段的硬墙，不是放雷方式能绕过的。**

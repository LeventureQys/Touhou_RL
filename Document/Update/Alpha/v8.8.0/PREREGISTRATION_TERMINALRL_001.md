# 预注册 v880-TERMINALRL-001：用**终点化奖励**在线训练 36 动作策略（绕开标签的信用视界问题）

冻结时刻：2026-11-22（Asia/Shanghai），**在任何 v8.8.0 训练之前**。
状态：**FROZEN**。
**本文件是为 v8.7.0「实现受阻」准备的替代路径；若 v8.7.0 成功，本文件留作对照。**

---

## 0. 为什么走这条路

| 证据 | 结论 |
| --- | --- |
| v8.3.0（bombs 恒 3）20 s = 19.44% | 标签教不会留雷 |
| v8.5.0（规则蒸馏）20 s = 15.50%，60/40 px 段**零训练行** | 蒸馏在这批数据上不可能 |
| v8.6.0（bombs∈{1,2,3}）10 s = 99.9%，20 s 同窗口 32%（vs 18.8%） | **状态分布修好，候选头变强**；但三颗雷仍 100% 用光 |
| 逐对比较 48,168 对，**放雷更差 = 0 例** | 标签里没有「不放」的理由 |
| 立刻打光 vs 分阶段：19.44% vs 77.11%（20 s） | **代价真实存在 ~58 pp，但出现在 2 秒之外** |

⇒ 反事实标签的信用视界（H=120）**结构性地**看不见花雷的代价。要学它，必须让**整段回报**进入梯度。

## 1. 设计（单因子：学习信号从「标签」换成「终点回报」）

| 项 | 之前 | **v8.8.0** |
| --- | --- | --- |
| 策略 | `Policy(106,64,36)` | **同结构**，**从 v8.6.0 的 checkpoint 热启动**（行为克隆先验） |
| 动作空间 | 36（18 候选 × bomb） | **不变** |
| 学习信号 | 反事实标签 BCE | **REINFORCE**：`R = survived(1,200 帧) + 0.5 × alive_frames/1,200`，带**移动平均基线**与**熵正则 0.01** |
| 回合长度 | 300 决策（标签）/ 300–900（评测） | **600 决策 = 1,200 帧**（让「花雷的代价」落在回合内） |
| 训练回合数 | — | **每种子 300 回合 × 3 种子 = 900 回合**（12 路并行 ≈ 5–10 min） |
| 优化 | Adam 1e-3 | **Adam 3e-4**（RL 更小步长），batch = 每回合 600 步 |
| 评测 | 300/600/900 决策 | **不变**（同协议、同窗口、同种子） |

> **为什么从 v8.6.0 热启动**：v8.6 的候选头已经比 v8.3.0 强（同窗口 18.8% → 32%），从它出发能省掉重新学躲闪。这也让「单因子」成立：变的是**学习信号**，不是初始化（对照轮 v8.6 已有）。

## 2. 判据

| # | 终点 | 判据 |
| --- | --- | --- |
| **P1（主）** | 600 决策（20 s）活满率 | **> 19.44%**（v8.3.0 最好值）；且 **> 32%**（v8.6 同窗口）才算「RL 有增益」 |
| **P2** | 用雷分布 | **必须出现「只用 1–2 颗」的 episode**（此前 100% 用 3 颗） |
| **P3** | 900 决策（30 s） | 与 v8.3.0（0.61%）、v8.6.0 并排 |
| **P4（诊断）** | 训练曲线：每 50 回合的平均回报/存活率 | 只看趋势，不做检验 |

### 2.1 停止条件

| # | 条件 | 动作 |
| --- | --- | --- |
| **S-flat** | 900 回合后平均回报**无上升趋势**（后 300 回合均值 ≤ 前 300 回合均值） | 判「REINFORCE 信号太弱」；下一轮改**优先经验回放 + 回报加权回归**（离线，用已有标签 + 回报权重） |
| **S-harm** | 20 s 显著低于 v8.6.0（Fisher p<0.05，方向更差） | 判「RL 破坏了 BC 先验」；下一轮加 KL 正则（对 v8.6 的 ckpt） |
| **S-fork** | 保真门失败 | 整轮作废 |
| **S-ok** | P1 与 P2 都成立 | 判「终点回报是关键」；下一轮把回合拉长到 900 决策并扩到 1,000+ 回合 |
| **S-partial** | P1 成立但 P2 不成立 | 判「学会了活得更久、但仍不会省雷」；下一轮加**用雷惩罚项**（每用一颗 −0.1） |

- 不能把 RL 的 on-policy 回报与反事实标签的离线估计混为一谈；

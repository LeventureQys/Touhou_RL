# 预注册 v830-BOMBPOL-001：训练一个「会自己决定何时放雷」的 36 动作策略

冻结时刻：2026-11-22（Asia/Shanghai），**在任何 v8.3.0 标签或训练之前**。
状态：**FROZEN**。

---

## 0. 前提（v8.0.0 / v8.1.0 / v8.2.0 已测到的事实）

| 事实 | 数字 |
| --- | --- |
| 不放雷的冻结策略（20 s） | 484/3,600 = **13.4444%** |
| 放雷规则（80 px，20 / 30 / 40 s） | **100.00% / 95.05%（收尾中）/ 64.51%（收尾中）** |
| 只在 lethal 接触时放（v8.2.0，3 px / 5 px） | 3 px 规则**从不触发**（0 颗雷）；5 px 规则 600 决策只有 **29.17%** |
| 结论 | **放雷必须「早放」**（约 80 px）——留到最后一刻来不及（决策粒度 2 帧 = 33 ms，3 px 的子弹不到 2 帧就命中） |

⇒ 现在要把这个能力**变成策略自己的能力**：动作空间从 18 扩到 **36**（18 个候选 × 放雷/不放雷），用反事实标签训练。

---

## 1. 设计（单因子：动作空间 + 标签）

| 项 | 现状（v4.5.0/v6.0.0） | **v8.3.0** |
| --- | --- | --- |
| 动作空间 | 18（`cand = focus*9 + move`，射击恒开、**放雷恒关**） | **36**（`action = cand*2 + bomb`） |
| 标签 | 每状态 18 个候选，各跑 H=120 帧 | **每状态 36 个动作**，各跑 H=120 帧（bomb=1 时首帧放雷） |
| 数据 | 5,166 状态（`.tmp_v600_obsp/labels_pipe.jsonl` 的同一批状态） | **同 5,166 状态重采 36 路标签**（状态本身不变，只多 18 路） |
| 模型 | `Policy(106,64,18)` | **`Policy(106,64,36)`**（同结构） |
| 训练 | BCE、Adam 1e-3、batch 256、200 epoch、3 种子 | **完全不变** |
| 评测 | 300 决策 / 600 帧 | **300 / 600 / 900 决策**（20 / 40 / 60 s）三档 |
| 对照 | 不放雷 13.4444%；80 px 规则 100%（20 s） | 同 |

> **关键实现点（写死在预注册里）**：`bomb=1` 的标签必须**真的在首帧发 `BTN_BOMB`**，并由引擎决定它是否被接受（无敌帧内会被忽略，v8.0.0 记录延迟 2 帧）。标签器要把 `bombs_used` 与 `bombs_remaining` 一起写进标签行，训练时 `bombs_remaining` 已经在 106 维观测里（第 8 维），所以策略能看见「自己还剩几颗雷」。

## 2. 判据

| # | 终点 | 判据 |
| --- | --- | --- |
| **P1（主）** | 300 决策（600 帧）下活满整段率 | **> 13.4444%**（不放雷基线）；单侧 Fisher + CP95 |
| **P2** | 300 决策下 vs **80 px 脚本规则（100%）** | **≥ 95%** 才算「学会了放雷」；若 < 95%，报差多少 |
| **P3** | 600 / 900 决策的活满率 | 与脚本规则（95.05% / 64.51%，v8.1.0 收尾值）并排 |
| **P4（描述）** | 放雷行为：用雷分布、首次放雷决策的分布、雷耗尽比例 | 只报 |

### 2.1 停止条件

| # | 条件 | 动作 |
| --- | --- | --- |
| **S-label** | 标签器自检（H=600，18/18）失败，或 36 路标签状态 < 4,000 | 整轮作废 |
| **S-fork** | 保真门失败 | 整轮作废 |
| **S-fail** | P1 不成立 | 判「36 动作用反事实标签学不出来」；下一轮改**先验规则 + 学习微调**（只学「放/不放」的二元头，候选动作仍用 18 路策略） |
| **S-learned** | P2 成立（≥95%） | 判「策略自己学会了放雷」；下一轮把段长推到 **900 / 1,200 决策**并与规则对照，同时报告雷的**节约程度**（用雷数是否 < 规则） |
| **S-partial** | P1 成立但 P2 不成立 | 报告写清「学会了但不如规则」；下一轮用**规则蒸馏**（把 80 px 规则的决策当额外监督信号） |

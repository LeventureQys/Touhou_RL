## 复现

图版用系统 Python 加 matplotlib 生成，画布与字号在 `build/figstyle.py` 里统一。改完某一版的数字后，重跑对应的 `build/fig0N.py` 即可。

DOCX 由 `build/make_docx.py` 从 Markdown 转出。它只认这篇文章用到的语法：标题、段落、图片、列表、引用、行内链接与行内代码。

## 口径

- 文中数字取自 `Document/Update/Alpha/` 下的实测记录，出处在每一节正文和文末入口里。
- 标“计划”的是预算量，不是成绩。
- 开发局使用 seed 1000–1099；确认局 61000–61099 一局未动。
- `state.json` 与 `ASSET_SYNC.md` 钉住的暂停快照相差 14 分钟，正文里如实写了这个差异，没有调和。
